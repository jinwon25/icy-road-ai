## 제출 일정과 CSV 규격에 관한 표현 정정

사용자가 문제·평가·제출 형식·데이터 설명을 제공한 뒤 확인 범위를 다시 정리했습니다. **10월 19일에 새 제출 일정이나 CSV 규격을 확인한 사실은 없습니다.** 그날 새로 확인한 것은 일반 Q&A 게시물의 제목·게시일·답변 완료 표시입니다.

일정 별도 공지의 근거는 9월 30일 게시된 공통 [개발결과물 제출 안내564](https://aida.kisti.re.kr/competition/main/selectNotice.do?bbsId=BBSMSTR_AAAAAAAAAAAA&nttId=564)의 10월 16일 보존 본문입니다. 당시 본문이 제출 기간·방법·마감일을 별도로 안내한다고 했으며 실제 날짜를 제시하지 않았습니다. 이 문구를 10월 19일 신규 공지로 해석하지 않습니다.

사용자가 제공한 문제 설명은 구간별 추정값·상관분석 CSV, 결빙 지표 CSV와 10분 예측 제시를 요구합니다. 고정 열 이름·순서·파일명·결측 표현의 템플릿은 제시하지 않으며, **그런 템플릿을 추후 공지한다는 근거도 확인하지 못했습니다.** 따라서 ‘최종 CSV 규격 확정 대기’를 필수 작업 차단 조건으로 두지 않습니다. 현재 요구에 맞는 결과표를 준비하고 지점/구간·시각·단위·결측·집계 정의를 문서화합니다. 추가 공식 양식이 실제 제시되면 그때 맞춥니다.

기존 후보 ZIP은 당시 스냅샷으로 보존하며 이번 정정만으로 모델·예측·후보를 재생성하지 않습니다.

## 사용자 제공 원문과 기존 반영 확인

이후 사용자가 로그인한 화면에서 전달한 Q&A620(10월 7일 배포·결측 안내), Q&A633(10월 13일 F1 답변), Q&A603(10월 7일 목표안개 답변)은 10월 16일 보존 본문·댓글과 내용이 일치합니다. 이번에 추가된 규정으로 분류하지 않습니다. 사용자가 제공한 텍스트의 대조이며 로그인 세션이나 전체 게시판을 직접 재조회한 것은 아닙니다.

- 결측 코드와 목표안개 제공 항목은 [10월 7일 수정본 검증](OFFICIAL_UPDATE_20261007.md)에 이미 반영했습니다. `numeric_observations`는 네 결측 코드를 NaN으로 처리하고, FOG 로더는 위경도·고도·시정을 읽습니다. 노면온도 추가라는 Q&A603 본문은 과거 안내의 인용임을 당시 기록에서 이미 구분했습니다.
- 무결빙일 제외와 미탐일 Precision 제외·Recall/F1=0은 [10월 13일 지표 검증](OFFICIAL_QNA_20261013.md)에 반영했습니다. 현 `qa633_metrics.py`의 계산 및 지표별 평균 분모와 일치합니다. TN은 지표 분모에는 들어가지 않지만 유효 관측량 계산에서는 유지합니다.
- 관련 결측·FOG 분리·미탐일·관측량 검사는 이번에 완료한 281개 테스트 통과 기록에도 포함됩니다. 이 내용을 이유로 코드 수정·재학습·지표 재계산·후보 ZIP 재생성을 반복하지 않습니다.

위 세 게시물에는 10월 19일 새 데모영상 답변이나 결과물 접수 일정이 없습니다. CSV는 요구된 산출 항목을 기준으로 준비하며 별도 고정 템플릿의 존재를 가정하지 않습니다.

## 증거와 후속 우선순위

직접 HTTP 수집 11개는 연결 실패했고 `curl`도 연결하지 못했습니다. 웹 도구는 목록·문제 첨부 표시·대회소개를 반환했지만 제출 안내·문제 Q&A633·문제 탭·HWP 다운로드는 접근 불가였습니다. 로그인·승인 상태, 전체 ZIP 바이트, 새 Q&A 답변을 추정하지 않습니다.

원 수집 실패 영수증과 웹 도구 추출문은 `outputs/private/official_updates_20261019_v1/`에 보존했습니다. `web_observed_surfaces.json`은 웹 도구가 제공한 추출문이며 HTTP 원본이 아닙니다. 최초 수집 요약의 첨부 비교 `false`는 미확인으로 정정하는 `access_clarification.json`을 추가했고, 수집 코드도 접근 실패 시 `null`과 `partial_unverified`를 기록하도록 보완했습니다. 과거 원문·해시는 보존했습니다. [새 확인 설정](../../config/official_requirements_20261019.json)은 직전 전체 확인과 이번 부분 확인을 구분합니다.

1. 다음 접근 가능 시 10월 19일 데모영상 답변·FAQ·제출 안내 본문을 먼저 확인합니다. 운영진에게 문의를 보내지는 않았습니다.
2. 접수 날짜·방식과 부분 날짜·미정의 지점 평균 규약을 확인합니다. CSV는 현재 명시된 산출 항목에 맞춰 열·행키·단위·결측 표현을 문서화하며, 별도 템플릿을 기다리느라 준비를 중단하지 않습니다.
3. 같은 파일명의 데이터 교체 여부는 승인된 파일을 받을 수 있을 때 해시로 확인합니다.
4. 이번에는 포함 자료만으로 실행되는 제출용 노트북을 보완하고 누수·지표·파일 무결성을 검증했습니다. 새 모델 선택이나 공식 평가 결과에 맞춘 튜닝은 수행하지 않았습니다.
