## 새 Q&A 693·716의 직접 적용

[693 답변](https://aida.kisti.re.kr/competition/problem/PROB_000000000004604/detail/commuDetail.do?bbsId=BBSMSTR_000000000319&nttId=693)은 다음을 확정했습니다.

1. 기간 내 실제 결빙이 없는 지점은 평균 F1에서 제외합니다. 임의 0점을 넣지 않습니다.
2. 결과 파일·열 이름은 자유지만 **고속도로명·지점명·10분 예측시간·노면상태 관측자료·결빙 예측값·노면온도 관측자료·노면온도 예측값**을 포함해야 합니다. 기존 예측 전용 CSV는 관측 대조용 CSV와 구분해 보완합니다.
3. 시각 오차 허용은 없고, **다른 학습 지점의 같은 시각 노면상태는 입력으로 사용할 수 없습니다.** 현재 최종 모형은 기상 입력 경로이며 새 후보도 ASOS 기상만 사용합니다.
4. 제공 DEM은 정규화 값으로 미터가 아닙니다. 평야의 일정 값 20은 0으로 보라는 안내입니다. 절대고도·물리 경사도로 직접 해석하지 않으며 외부 고도 자료와 출처·단위를 구별합니다.
5. 별도 곡률 자료 대신 중심선이 제공됩니다. 중심선 기반 곡률은 자체 파생값임을 밝힙니다.

[716 답변](https://aida.kisti.re.kr/competition/problem/PROB_000000000004604/detail/commuDetail.do?bbsId=BBSMSTR_000000000319&nttId=716)은 다음을 추가했습니다.

1. 무양성·오경보 날짜의 Recall은 평균에서 제외합니다. 실제 결빙이 없어 산정할 수 없는 지점은 산출불가로 적고 평균에서 제외합니다. 지점·날짜 수를 반드시 함께 기재합니다.
2. 기존 위험표의 모든 항목을 담을 필요는 없습니다. 외부 공공자료를 출처와 함께 사용하거나, 산정 불가능한 항목을 제외해 가능한 항목을 100점으로 환산할 수 있습니다. 근거 있는 새 요소·기준도 가능합니다.
3. 자체 기후 기준을 쓰려면 최근 10년 겨울의 일최저기온 평균과 일강수량 0.1mm 이상인 날 수(적설일 포함)를 제안했습니다. **보유한 두 겨울 통계를 10년 기후값으로 가장하지 않습니다.** 새 두 겨울 노출 지표는 자체 기준으로 명시합니다.

[633 답변](https://aida.kisti.re.kr/competition/problem/PROB_000000000004604/detail/commuDetail.do?bbsId=BBSMSTR_000000000319&nttId=633)과 [556 답변](https://aida.kisti.re.kr/competition/problem/PROB_000000000004604/detail/commuDetail.do?bbsId=BBSMSTR_000000000319&nttId=556)의 미탐일 Precision 제외·Recall/F1=0, 날짜→지점 평균 규칙도 유지합니다. 부분 날짜의 최소 유효 관측량은 답변에 없으므로 최소1·144 시점 결과를 구분해 보고합니다. 새 규칙으로 숫자가 달라진 부분은 모델 성능 향상과 분리합니다.
