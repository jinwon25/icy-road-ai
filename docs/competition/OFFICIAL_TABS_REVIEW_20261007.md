## 시정 입력과 동일 조건 비교

`src/fog_features.py`, `scripts/build_fog_features.py`에 같은 노선 최근접 목표안개 관측소의 **엄격히 이전 시각·최대 30분** 자료를 결합했다. 시정은 원 단위인 m와 `log1p(m)`를 보존하고 관측 나이·거리도 기록한다. 상대습도로 환산하지 않는다. 유효한 이전 관측이 없거나 같은 노선 관측소가 없으면 결측으로 남긴다.

- 대상 행 483,768개와 원래 정답을 모두 보존했다.
- 시정 연결 345,552행, 결빙 239개 시점 중 187개 시점에 연결됐다. 호남선의 결빙 52개 시점에는 같은 노선의 안개 입력이 없다.
- 연결 거리 1.22–60.79km. 멀리 있는 시정이 타깃 위치의 실제 안개를 뜻하지 않으므로 거리와 지점별 성능을 함께 본다.
- 발표 지연을 30분으로 가정하면 연결 345,502행, 결빙 연결 187개 시점이다. 이는 입력 가용성 점검이며 지연된 모델 성능 검증은 아니다.
- 시정 0m는 공식 결측 코드에 포함되지 않아 유지했다. 운양교 0–40,008m·잠두교 47–15,955m를 관측했다. 상한·하한의 센서 품질표가 없어 임의 상한으로 자르지 않았다.

동일한 14개 외부 관측소 제외·각 3개 내부 관측소 분할, 로지스틱 C=0.1, 내부 OOF 임계값 선택으로 기존 AWS 대체 모델과 비교했다. 전체 483,768행의 지점·시각·라벨, 내부 학습 행 수·결빙 수가 일치함을 확인했다. 유효 정답은 483,629행이다. 결과는 `ice_fog_logistic/`과 `ice_fog_comparison/`에 별도 저장했고 기본 특징·예측 파일을 유지했다.

## 공간자료에서 확인한 제약과 수정

노선명 앞의 공백을 제거해 도로 매칭 오류를 수정했다. 수정본 개발 관측소 14곳은 모두 표기 노선과 최근접 노선이 일치하고 중심선까지 최대 22.31m다.

교량 CSV 453행 중 302행이 완전 중복이고 451행은 시작·끝 좌표가 같다. 터널은 14행 중 7행이 중복이며 전부 시작·끝 좌표가 같다. 교량은 위도→경도, 터널은 경도→위도 순서여서 열 번호로 읽으면 뒤바뀐다. `audit_spatial.py`에 이름 기반 좌표·중복 감사를 추가했다. 현재 정보만으로 중복을 방향별 시설 수로 해석하거나 끝점 차이로 시설 길이를 계산하지 않는다. 실제 시설 범위에는 별도 폴리곤과 출처 시점 검증이 필요하다.

‘곡률 데이터’ 항목의 실제 파일은 `jb_road_center_line`이며 곡률·곡선반경 수치 열이 없다. 선형에서 도출한 곡률 대용 지표는 공식 설계 반경과 구분하고 표본 간격·평활화 민감도를 검증해야 한다. 샘플 그림이 곡률이라고 명명됐다는 이유만으로 별도 곡률 수치가 제공됐다고 기록하지 않는다.

중심선 EPSG:5179·275.889km를 새 작업 폴더에서 최대 1km 도형 467개로 다시 만들고 Shapefile/GPKG 저장·재읽기를 검증했다. 끊어진 선형·분기·방향·본선/램프 확인이 남아 있어 균일한 공식 이정 구간은 아니다. 위험점수는 모두 미산정이다.

DEM은 약 30m 격자이며 명시적 수직 단위 태그가 없다. 도로 종단경사와 주변 지형경사를 혼동하지 않는다. 2026년 8월 접도구역 자료도 포함돼 있으므로 두 겨울 시점에 그대로 존재했다고 단정하지 않는다.

## 기존 결빙취약구간 표 활용

공식 이미지 22곳의 이정·길이·등급을 `official_vulnerable_sections.csv`로 전사했고 모든 행의 종료−시작 길이를 확인했다. 전체 38.57km로 이미지 제목과 일치한다. 대상 3개 노선은 **17곳·30.81km, A 1곳·B 3곳·C 13곳**이다. 나머지 5곳은 호남지선·새만금포항선·순천완주선이다.

이는 지도상의 경계 폴리곤이나 정밀 구간 도형이 아니다. 공식 이정의 원점·방향·좌표 대응표 없이 우리 중심선의 누적 길이에 숫자를 붙이면 위치가 틀어질 수 있다. 대상 노선에 해당한다는 사실만으로 제공 중심선과 실제 겹친다고 단정하지 않는다. 기존 등급은 비교 기준으로 보존하며 결빙 학습 라벨로 사용하지 않는다.

## 남은 결정과 실행 순서

1. 동일 센서 종류의 개발 5곳·노선별 오경보와 미탐을 함께 보고 결빙 후보를 결정한다. 시정 추가가 자동으로 개선을 보장하지 않는다.
2. 구간 입력에서도 이용 가능한 변수로 노면온도·상태를 추정한다. 회귀 예측을 분류에 추가할 경우 학습 지점 실측 온도를 넣지 말고 내부 분할의 추정값으로 만들어 누수를 막는다.
3. 교량·터널, 지형, 수계, 곡률 대용 지표의 품질·시점·공간 연결을 검증한 후 같은 개발 분할로 효과를 비교한다. 관측 연관성과 인과적 위험 기여를 구별한다.
4. 시점별 결빙 판정, 기간별 기상 취약도, 결빙 시 도로·지형 위험 영향을 따로 산출하고 기준의 민감도를 제시한다. 임의 배점이나 사고 확률로 포장하지 않는다.
5. 부분 날짜 채택 기준, 한쪽 Precision/Recall 미정의 처리, 추가 회귀 대상·CSV 스키마, 발표 지연, 공식 이정 대응자료는 운영진 확인 항목으로 유지한다.
6. 모델·기준을 고정한 뒤 보호 3개 지점의 최종 평가, 구간 추정 CSV·위험도 표·지도·재현 매뉴얼·데모를 제작한다.
