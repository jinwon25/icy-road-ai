# 11월 2일 공식 공개 자료 확인 범위

2026년 11월 2일 [공식 문제 페이지](https://aida.kisti.re.kr/competition/main/problem/PROB_000000000004604/detail.do)와 [공식 공지 목록](https://aida.kisti.re.kr/competition/main/notice.do)을 다시 확인했습니다. 문제의 참가신청 기간은 9월 15일–11월 6일이며 전체 데이터 표시는 10월 7일 판입니다. 공지 목록의 최신 게시물은 10월 29일 로그인 오류 안내이고, 10월 27일 결과 제출 안내와 9월 30일 개발결과물 제출 안내가 유지됩니다.

이번 웹 조회에서 [결과 제출 상세 694](https://aida.kisti.re.kr/competition/main/selectNotice.do?bbsId=BBSMSTR_AAAAAAAAAAAA&nttId=694), [개발결과물 상세 564](https://aida.kisti.re.kr/competition/main/selectNotice.do?bbsId=BBSMSTR_AAAAAAAAAAAA&nttId=564), [FAQ 상세 696](https://aida.kisti.re.kr/competition/main/selectQna.do?bbsId=BBSMSTR_BBBBBBBBBBBB&nttId=696), 문제 설명 JSON은 접근에 실패했습니다. 새 마감일·규정 변경이 없다고 단정하지 않습니다. 참가신청 종료일을 결과물 마감일로 바꾸어 기록하지 않으며, 기존에 정한 11월 6일 이전 작업 완료 기준을 유지합니다.

최신 상세·참가서약의 성공한 전체 대조는 [10월 31일 기록](OFFICIAL_UPDATE_20261031.md)입니다. 그때 보존한 참가서약 본문에서 승인받지 않은 제3자 열람·제공 금지, 제공 데이터의 대회 종료 후 폐기, 수상자의 주최 측 코드·문서 전달 조건을 다시 읽었습니다. 양식 자체를 당일 다시 내려받아 동일성을 확인한 것은 아닙니다. 코드 제출 의무와 대회 중 공개 허용은 구분합니다.

후속 실험은 기존 허용 개발 자료만 사용합니다. 보호 3지점과 이미 평가한 별도 4지역 정답을 추가 학습·선택에 사용하지 않고, 외부 연구에는 공개 논문·공식 문서의 방법만 참고합니다. 외부 모델·관측 자료·코드는 반입하지 않았습니다. 대회 업로드·문의 발송·공개 전환은 수행하지 않습니다.
