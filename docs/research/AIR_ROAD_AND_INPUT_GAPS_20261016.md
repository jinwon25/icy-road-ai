# 기온·노면 결합과 관측 공백 후속 검증

> **읽는 범위:** 아래 내용은 해당 문서의 작성·실험 시점 기록입니다. 현재 모델·마감·완료 상태는 [진행 현황](../STATUS.md)을 기준으로 읽고, 약어와 지표는 [처음 읽는 안내](../START_HERE.md)에서 확인합니다.

72개 결합 규칙을 비교했지만 ASOS 기온 기준선을 넘는 후보는 없었습니다. 인접 ASOS 대체도 9곳 모두에서 품질을 유지하지 못해 실행 후보에 반영하지 않았습니다. 이번 결과는 반복 개발 검증이며 새 지점의 독립 성능이나 공식 점수가 아닙니다.

## 결합을 검증한 범위

허용된 첫 겨울 23곳으로 이미 학습한 모델 중 공간 제외 조건을 만족하는 20개만 재사용했습니다. 새 적합은 없습니다. 외부 평가 그룹 G를 선택에서 제외하고, 내부 H의 온도 예측에는 G와 H 전체 지점을 제외한 모델을 사용했습니다. 외부 비교는 개발 9곳·155,257행이며, 상태 유효 행은 155,118개입니다. 보호·이미 개봉한 평가·둘째 겨울 정답은 열지 않았습니다.

| 결합 요소 | 실행 전에 고정한 값 |
| --- | --- |
| 저온 조건의 입력 | ASOS 기온, ASOS 기온과 추정 노면온도의 반반 평균 |
| 임계 온도 | -2, -1, 0°C |
| 수분 조건 | 없음, AWS 습도 80% 이상, 기온·이슬점 차 2°C 이하 또는 강수·적설 |
| 지속 조건 | 현재 1슬롯, 빠짐없이 이어진 과거 포함 3슬롯 |
| 기존 판정 결합 | 사용 안 함, 기존 후보와 OR |
| 전체 | 2 × 3 × 3 × 2 × 2 = 72개 |

습도·이슬점 차·지속 길이는 자체 연구 가설입니다. 아래 문헌이 해당 수치를 보장한다는 뜻이 아닙니다. 시간창은 미래 관측을 쓰지 않으며 10분 관측이 끊기면 지속 조건을 초기화합니다. [설정](../../config/air_road_blending_experiment.json) · [구현](../../src/air_road_blending.py)

## 선택 기준과 결과

기존 기준은 오경보 증가를 허용하지 않습니다. 이것만으로 기온 기준선의 장점을 배제하지 않도록 연구용 비교를 따로 고정했습니다. 두 기준을 섞거나 결과를 본 뒤 유리한 기준으로 바꾸지 않았습니다.

| 선택 경로 | 적격 조건과 부적격 시 처리 |
| --- | --- |
| 연구용 F1 | 144·1슬롯 조건에서 현재·ASOS·항상 결빙의 일별 F1을 모두 초과. FP는 ASOS 이하, 기존 탐지 사건 손실 0, 지점별 TP 비감소. 실패하면 ASOS 기준선 |
| 기존 엄격 기준 | 위 F1 우위에 더해 현재 대비 FP·FN 비증가, 일별 P·R·F1 비악화, 사건·지점 TP 보존. 실패하면 현재 후보 |

네 외부 그룹 모두 내부에서 적격 결합을 찾지 못했습니다. 연구용 경로는 네 곳 모두 ASOS로, 엄격 경로는 네 곳 모두 현재 후보로 돌아갔습니다. 전체 개발 결과를 보고 고른 최고 고정 규칙도 수분·지속·OR 조건이 없는 ASOS ≤0°C 자체였습니다.

| 방법 | 일별 지점 평균 F1 | F1 날짜/지점 | FP | FN | 탐지 사건 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 현재 온도·수분 후보 | 0.030633 | 365/9 | 20,255 | 4,952 | 152/347 |
| 항상 결빙 | 0.055216 | 1060/9 | 148,507 | 0 | 347/347 |
| 추정 노면온도 ≤0°C | 0.063867 | 707/9 | 44,682 | 2,280 | 241/347 |
| ASOS 기온 ≤0°C | 0.071122 | 786/9 | 57,912 | 811 | 296/347 |
| 내부 선택: 연구용 F1 | 0.071122 | 786/9 | 57,912 | 811 | 296/347 |
| 내부 선택: 엄격 기준 | 0.030633 | 365/9 | 20,255 | 4,952 | 152/347 |

일별 F1은 144개 유효 관측이 있는 1,060개 지점일에서 날짜 평균 후 지점 평균입니다. 예정 1,080개 지점일 중 20개는 관측량 부족으로 제외했습니다. 실제·예측 결빙이 모두 없는 날은 F1에서 제외하므로 방법별 날짜 분모가 다릅니다. FP·FN·사건은 부분 날짜를 포함한 전체 유효 행에서 계산했습니다. 최소 관측량은 공식 확정값이 아니어서 130·72·1슬롯도 별도 비교했습니다. 개발 입력 부족 행의 이진 판정 0 관례와 실제 제출 추론의 null 정책은 구별합니다.

ASOS는 현재 후보보다 FN이 4,141행 적지만 FP가 37,657행 많습니다. F1만으로 운영 후보를 바꾸지 않았습니다. 전체 Ice 6,611행 중 95.9%가 33408에 집중된 기존 한계도 그대로입니다. 72개 안에서 개선이 없었다는 결과를 모든 결합·기계학습 방법의 무효로 확대하지 않습니다.

독립 구현으로 규칙 예측 44,714,016값, 저장 모델 온도 1,242,056값, 지표 보고서 788개, 사건 집계 387개, 외부 선택 4개, 일별 30,240행·지점 252행을 검산했습니다. 결과와 감사 영수증은 `outputs/private/air_road_blending_20261016_v1/`에 있습니다. [실험](../../scripts/evaluate_air_road_blending.py) · [독립 검산](../../scripts/audit_air_road_blending.py)

## 인접 ASOS 대체의 품질

원 ASOS가 없을 때 50km 이내이면서 원 관측소보다 추가 거리 30km 이내인 다른 ASOS를 찾았습니다. 목표보다 엄격히 이르고 나이가 60분 이하인 실제 관측만 허용했습니다. 정상 입력은 유지하며 같은 관측소·시각의 기온·적설·나이를 함께 교체했습니다. 이 거리·품질 허용치는 실행 전 고정한 연구 기준입니다.

개발 9곳에서 매월 5·15·25일 정오의 6슬롯을 고정해 최근접 관측소를 제외하는 합성 공백 648행을 만들었습니다. 지점별 최소 36개 온도 비교행, 대체 가능 50% 이상, 원래 대비 MAE 악화 10% 이내, 온도 변화 평균 0.75°C 이하를 모두 요구했습니다.

## 공식 원자료로 확인한 공백 원인

## 새 독립 평가의 진행 조건

10월 10일 고정 위치 선별표의 미사용 후보 32곳과 현재 다운로드 이력 6개를 대조했습니다. 이후 개봉한 23102·23407을 제외하면 30곳입니다. 기존 기상 캐시의 거리 상한 안에 남는 곳은 12208 한 곳이며, 알려진 도로 센서와 거리가 약 11m여서 기존 5km 분리 조건을 통과하지 못합니다. 현재 캐시와 기존 위치 선별 기준에서 새 적격 지점은 0곳입니다. 전국에 새 관측소가 없다는 주장은 아닙니다.

근거: `outputs/private/remaining_station_metadata_20261016_v1/`. [메타데이터 감사](../../scripts/audit_remaining_station_metadata.py)

후속 순서는 다음과 같습니다.

1. AWS 매분자료 서비스의 기존 키 접근 상태를 해결하고, 미사용 지역의 기상 가용성과 최근접 거리·시각 범위를 정답 없이 먼저 확인합니다. 현재 키는 403이므로 접근이 확보되기 전 독립 평가 정답을 새로 수집하지 않습니다.
2. 새 지역·모델·입력·선택 규칙을 고정하고 예측 해시를 봉인한 후 적격 미사용 지점의 정답을 한 번 개봉합니다. 12208의 근접성을 무시하거나 이미 개봉한 지점을 재사용하지 않습니다.
3. 33408의 센서 위치·상태 코드·제설·염분·유지보수 이력을 확보해 기온·노면온도와 Ice가 어긋나는 원인을 구분합니다. 라벨 삭제나 편의적 지점 제외는 하지 않습니다.
4. 최종 CSV와 제출 날짜가 공지되면 공식 내보내기 계약을 추가합니다. 11월 6일은 참가신청 종료일이며 결과물 마감으로 바꾸어 쓰지 않습니다.
