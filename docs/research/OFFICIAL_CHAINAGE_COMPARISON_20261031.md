# 공식 시설 이정으로 보완한 취약구간 비교

공식 암거의 좌표·이정을 새로 확보해 기존에 연결이 불완전했던 취약구간 목록과 500m 도로를 비교했습니다. **843개 중 821개를 외삽 없이 보간했고, 문제 목록 11개·최신 전국 목록 8개의 추정 위치를 표시했습니다.** 위치 추정·공식 지정·기상 노출을 각각 구별합니다. 현재 결빙 분류의 기준선 미달을 지도 상세화로 상쇄했다고 주장하지 않습니다.

원문 확보·이용조건·두 목록의 차이는 [공식 도로 자료 검토](OFFICIAL_ROAD_CONTEXT_20261031.md), 추가 기상 모델의 실패와 검산은 [ERA5-Land 비교](REANALYSIS_INPUTS_20261031.md)에 기록합니다. 로컬 화면은 `outputs/private/official_inventory_viewer_20261031_v1/index.html`이며 인터넷 없이 실행합니다. 대회 원자료가 있어 외부 공개하지 않았습니다.

## 이정 추정과 오차 확인

[한국도로공사 암거 20260514](https://www.data.go.kr/data/15159523/fileData.do)는 CSV와 SHP·DBF·PRJ를 함께 제공합니다. 10,601행에서 원문 속성 116,611개·유효 좌표 10,136개를 교차 대조했습니다. WGS84 좌표를 EPSG:5179 도로에 변환하고 노선별 양방향 선형에 투영합니다. 학습 결과나 결빙 정답은 사용하지 않습니다.

1. 도로와 수직 거리 100m 이하인 시설 541개를 사용합니다. 같은 좌표의 중복 시설은 하나로 묶어 **서로 다른 위치 454개**가 됩니다. 중복 시설 이정은 중앙값으로 요약합니다.
2. 도로 누적거리와 공식 점 이정의 단조성을 확인하고 인접 기준점 사이에서 선형 보간합니다. 기준점 범위 밖은 외삽하지 않으며 기준점 공백 3km 초과도 허용하지 않습니다.
3. 전북 경계로 잘린 도형의 끝점을 원래 도형에 다시 투영합니다. 잘린 조각의 시작점을 원래 500m 구간 시작거리로 잘못 취급하지 않습니다. 단절된 조각을 임의 직선으로 연결하지 않습니다.
4. 같은 좌표를 한꺼번에 빼는 검증과 연속된 5km 블록 제외 검증을 수행합니다. 후자는 훈련점 사이 최대 10km 공백까지 검증하며 양 끝의 외삽 불가능 사례는 별도 집계합니다.

| 점검 | 예측 가능 / 대상 | 절대오차 평균 | 95백분위 | 최대 |
| --- | ---: | ---: | ---: | ---: |
| 좌표 하나씩 제외 | 896 / 908 | 27.90m | 80.11m | 105.54m |
| 5km 연속 블록 제외 | 823 / 908 | 28.81m | 78.01m | 134.26m |
| 별도 CCTV 후보 자료 대조 | 150 / 152 | 292.56m | 1,538.46m | 2,334.07m |

908개는 같은 시설을 양방향에 투영한 기록이며 독립 위치 908곳이 아닙니다. 암거 내부 검증은 별도 측량 검증이 아닙니다. CCTV는 기존 공식 목록과 ROADPLUS 좌표를 고유 이름으로 결합한 후보라 명칭·이정 불일치 가능성이 있습니다. 이 자료에 맞춰 암거 보간을 튜닝하지 않고 진단으로 남겼습니다. 원 CCTV 좌표·명칭을 새 화면에 재배포하지 않으며 인접 1km의 250m 초과 불일치 여부만 표시합니다.

500m 구간 821개가 전체 보간 가능하며 나머지 22개는 미확정입니다. 보간 가능한 조각 길이는 양방향 합계 409.702km, 전체 419.637km의 약 97.63%입니다. 이는 도로별 예측 정확도나 결빙 위험의 검증률이 아닙니다. `official_chainage_verified=False`를 유지합니다.

## 본부 관할과 전북 경계를 구별한 목록 비교

문제 표는 전북본부의 22개 중 대상 3노선 17개, [최신 20260907 전국 목록](https://www.data.go.kr/data/15102132/fileData.do)은 전북본부의 대상 3노선 11개입니다. 본부 관할에는 전북 밖 도로도 포함되어 표의 모든 구간을 전북 지도 안에 배치하지 않습니다.

| 목록 | 전북 경계 안 보간 도로와 명목상 중첩 |
| --- | --- |
| 문제 표·기준일 미상 | 17개 중 11개 |
| 2026-09-07 전국 목록 | 8개. 전북본부 7개와 광주전남본부 1개 |

전국 목록을 확인해 **호남선 115.4–117.0km, 광주전남본부 광주지사 구간의 일부**를 추가했습니다. 전북본부만 걸렀다면 놓치는 경계 비교 대상입니다. 문제 목록에서 현재 목록에 없는 호남선 129–130·173–174·180–181·186–187km도 서로 다른 시점의 사실로 함께 보여 줍니다. 지정 해제·위험 감소·공사 완료를 추정하지 않습니다. 최신 CSV에는 등급이 없어 과거 A/B/C를 현재 등급으로 복사하지 않았습니다.

각 도로 조각의 명목상 교집합과 100·250·500m 확장 범위의 교집합을 CSV로 제공합니다. 주 화면은 ±250m를 고정합니다. 843개 중 현재 목록 안 30개, 경계 민감 51개, 범위 밖 740개, 보간 불가 22개입니다. 이 오차 띠는 분석자의 민감도 조건이며 공식 허용오차나 확률적 신뢰구간이 아닙니다. 지도는 500m 조각의 끝점 이정을 선형 환산해 잘라낸 추정 오버레이입니다.

## 넓은 기상 노출 구간을 현장 확인 단위로 묶기

보존된 v7의 두 겨울·500m 1,686행을 그대로 연결합니다. 저온·수분 노출은 유효 10분 추정 중 기존 결빙 v2 조건을 만족하는 비율이며 실제 Ice 관측 빈도·사고확률이 아닙니다.

노선별 길이 가중 75백분위 이상의 노출이 두 겨울 모두 유지되고, 최신 목록과 ±250m에서도 겹치지 않는 구간을 연구용 확인 후보로 정했습니다. 같은 값의 동률은 모두 포함하므로 **정확히 상위 25%를 고르는 규칙이 아닙니다.** 실제 문턱 이상 도로 길이는 서해안 33.70%, 통영–대전 64.05%, 호남 41.99%입니다. 겨울별 기상 입력 조합은 각각 31·13·24개이며 보고 구간 843개보다 훨씬 적습니다.

후보는 318개·양방향 합계 159km지만 인접한 구간을 묶으면 방향별 8개 연속 구간입니다. 서해안 약 59.8–89.3km, 통영–대전 약 134.4–155.3km, 호남 약 117.5–131.5·133.4–148.6km의 양방향으로, 세밀한 위험 위치 발견이 아니라 **추가 관측과 현장 조사의 넓은 우선 검토 범위**입니다. 방향별 끝점 차이를 보존하며 동일한 기상값을 500m마다 독립 근거로 세지 않습니다.

초안 `vulnerability_map_comparison_20261031_v1/inventory_comparison.png`의 하단 ‘상위 25%’ 표기는 동률을 생략한 표현입니다. 원본은 보존하고, 동률·연속 구간·입력 해상도를 명시한 새 오프라인 화면을 검토 산출물로 사용합니다. 최신 화면은 선택 구간의 두 겨울 비율·시간·유효 분모·목록 관계·CCTV 불일치 표지를 보여 줍니다.
