# 공간·기상 이력 후속 실험의 고정 계획

11월 2일 후속 연구는 **현재 69특성 풍속 모형에 과거 입력을 더하면 미관측 지역의 오차가 추가로 줄어드는지** 확인합니다. 단일 후보·12회 적합으로 범위를 정했습니다. 완료 결과는 두 검증 모두 악화해 미채택이며 [후속 점검의 수치·검산](../delivery/FOLLOWUP_REVIEW_20261102.md#공간기상-이력의-완료-결과-미채택)에 정리했습니다. 고정 계획·해시는 `outputs/private/weather_network_history_20261102_v1/plan.json`에 있으며 아래는 그 방법을 설명합니다.

## 기존 작업과 다른 점

앞선 실험은 최근접 ASOS·AWS의 이력만 추가하거나, 현재 시점의 주변 AWS 통계만 추가했습니다. 이번에는 두 정보를 결합합니다. 가까운 AWS 최대 4곳·50km·거리 제곱 역수·엄격한 과거 15분이라는 기존 공간 정의를 유지합니다. 공간 반경·이웃 수·학습 설정·손실·검증 분모를 다시 탐색하지 않습니다.

| 입력 | 열 수 | 정의 |
| --- | ---: | --- |
| 현재 ASOS·AWS·시간·거리·태양 | 34 | 현재 채택 풍속 모형과 동일 |
| 현재 주변 관측망 | 35 | 5변수 각각의 IDW·표준편차·범위·최근접 대비 차이·개수·가중 거리·유효 개수 |
| 기존 기상 이력 | 48 | 8변수 × 2창 × 평균·현재차·가용률 |
| 주변 관측망 이력 | 30 | 5변수 IDW × 2창 × 평균·현재차·가용률 |
| 합계 | 147 | 도로의 과거 실제 풍속·노면온도·결빙·지점 ID·연도는 입력에 넣지 않음 |

창은 `(t-3h,t]`, `(t-24h,t]`이며 현재 기상도 도로 시점보다 과거에 관측한 값입니다. 10분 달력 18·144슬롯에서 유효 입력 6·48개 이상일 때 평균을 제공합니다. 가용률은 유효 입력 슬롯의 비율로 독립 관측 횟수가 아닙니다. 창마다 독립 합산해 추가 과거 문맥에 따른 부동소수점 상태를 없앱니다. 누락 시각·기상은 결측이고 도로·겨울 경계를 넘겨 채우지 않습니다.

## 참고한 자료와 적용 한계

1. [Baïle & Muzy, 인근 관측소를 이용한 풍속 예측](https://arxiv.org/html/2207.14679v2): 인근 지점의 과거 정보가 주는 추가 가치를 통제 비교하는 설계를 참고했습니다. 원문은 관측 지점의 시간 예측이며 풍향과 해당 지점의 과거 풍속을 사용합니다. 이번 과제는 미관측 도로의 현재 추정이므로 도로 과거 정답·풍향 벡터·원문의 성능 수치를 가져오지 않았습니다. 원문의 시간 분할과 이번 공간·겨울 제외 분할도 다릅니다.
2. [openAMUNDSEN 공식 기상 지역화 문서](https://doc.openamundsen.org/des/meteo): 거리 가중 공간 입력의 근거로 대조했습니다. 고도 추세와 관측 높이 보정은 별도 정보가 필요하므로 이번 구현에 적용하지 않았습니다. 앞선 11월 1일 공간 보간을 유지한 비교입니다.
3. [scikit-learn 1.6.1 LeaveOneGroupOut](https://scikit-learn.org/1.6/modules/generated/sklearn.model_selection.LeaveOneGroupOut.html): 평가 그룹을 학습에서 제외한다는 원칙을 대조했습니다. 실제 구현은 기존 프로젝트와 같은 명시적 지역·겨울 마스크이며 설치 버전은 1.6.1입니다.
4. [RoadSurf 1.1 원 논문](https://gmd.copernicus.org/articles/17/4837/2024/): 결빙 후속 방향을 검토했습니다. 열수지·수분 저장을 다루고, 평가 예제에서는 관측으로 48시간 초기화합니다. 노면온도 관측을 이용하는 결합 보정도 설명하지만 관측이 없을 때 기온으로 초기화하는 경로도 있습니다. 이번 입력으로 원문의 초기화·복사·지표 성능을 재현했다고 주장하지 않습니다. 당장 같은 개발 정답에 물리계수를 맞추기보다 입력 가용성과 도로 수분·제설·센서 정보를 먼저 대조할 필요가 있다는 판단의 참고 자료입니다.

외부 라이브러리·모형·관측 자료를 내려받아 실행하지 않았으며 자체 구현만 추가했습니다. 방법 참고와 원 연구 재현을 구분합니다.

## 검증과 채택 조건

기존 허용 개발 자료에서 같은 유효행을 사용합니다. 지역 전체 제외 4회와 지역·겨울 동시 제외 8회, 총 12회 적합합니다. 기준선은 이미 채택한 69특성 관측망 모형입니다. 예전 34특성 모형과 비교해 추가 효과를 크게 보이게 하지 않습니다.

두 검증 각각에서 전체 MAE 2% 이상 감소, 두 겨울 비악화, 각 지역 악화 10% 이내, ASOS 기온 ±3°C 구간 비악화, 7일 날짜 블록 2,000회 재표집 차이의 97.5백분위 0 미만을 모두 요구합니다. 날짜 재표집은 고정 개발 자료의 날짜 구성 민감도이며 새 지역 모집단 신뢰구간이 아닙니다. 역방향 겨울 비교는 사후 전이 검증으로 미래 예측으로 설명하지 않습니다.

전체 12회 결과를 본 뒤 창·입력·손실·문턱을 조정하지 않습니다. 보호 3곳과 이미 평가한 별도 4지역 정답은 읽지 않습니다. 입력 조건별·관측 풍속별 사후 표는 기술적 진단이며 후보 선택이나 새 독립 평가에 사용하지 않습니다.
