# 결빙 전이·임계값 연구에 참고한 논문과 공개 구현

이번 검토는 **결빙이 시작되고 지속되는 시간적 구조를 학습하면 오경보와 미탐을 함께 줄일 수 있는지**를 확인하기 위한 것입니다. 논문의 성능을 가져오는 대신, 우리 대회에서 허용된 입력과 지역 제외 검증으로 같은 아이디어가 유효한지 시험합니다. 결과는 [전이 모델 비교](ICING_TRANSITION_REVIEW_20261025.md)에 기록합니다.

Wind Energy 연구는 도로 센서의 Ice 판정과 목표·관측 체계가 다릅니다. 우리는 기상 조건에 따라 비결빙에서 결빙으로, 결빙에서 결빙으로 이어지는 점수를 자체 분류기로 학습합니다. 원 논문의 베타 방출분포를 사용하는 숨은 마르코프 모형을 재현한 것이 아닙니다. 가중 학습 점수는 보정된 실제 결빙 확률이라고 주장하지 않습니다.

검토한 저자 경보 함수는 목표 탐지율을 만족하는 임계값을 이분탐색합니다. 우리 목적은 일별 지점 F1이므로 그대로 복사할 수 없습니다. F1은 임계값에 대해 단조롭지 않습니다. 자체 구현에서는 내부 검증 자료의 서로 다른 점수를 모두 지나며 날짜·지점의 합계를 갱신하고, 실제 가능한 경계 중 최적값을 찾습니다. 같은 점수를 가진 행을 중간에서 나누지 않습니다.

## 대회 규정과 연결한 선택

최신 공식 답변·참가서약을 직접 확인한 뒤 기존 허용 기상자료만 사용했습니다. 새 외부 정답·사진·공개 파생자료·가중치를 가져오지 않았고 대회 자료를 외부 예측 API에 보내지 않았습니다. 문헌이 공개되어 있다는 사실만으로 해당 데이터나 모델까지 사용할 수 있다고 판단하지 않습니다.

학습 때 직전 Ice를 사용한다는 말은 **학습 지점 안의 전이 정답을 만든다**는 뜻입니다. 외부 평가 지역의 두 겨울은 해당 모델의 학습에서 모두 빠집니다. 실행 함수는 지점·시각, 두 가상 상태에 대한 모델 점수와 입력 가용성만 받고, 실제 Ice·노면온도 열이 들어오면 거부합니다.

실험 조건은 [전이 모델 계획](../../config/icing_transition_20261025.json), 경계 선택은 [임계값 정확 탐색 계획](../../config/icing_threshold_refinement_20261025.json)에 결과를 보기 전에 기록했습니다. 기존 결빙 채택 기준을 유지하고 같은 가용 입력의 ASOS 기온 기준선도 넘어야 하도록 했습니다. 이 자체 기준을 공식 수상 기준이라고 표현하지 않습니다.
