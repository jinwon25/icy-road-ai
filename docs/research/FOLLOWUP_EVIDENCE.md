## 독립 거리 구간 검증과 반복 선형 제한 — 2026-10-09

독립 검증에서 서해안 원본 링크 3190009600의 선형이 단순하지 않음을 확인했다. 원본 길이 15,593.252868m와 노딩한 선형 집합 길이 15,592.602368m 사이에는 0.650500m의 반복이 있었다. 최근접 거리 투영만으로는 일부 반복 조각의 위치가 모호해 첫 가정 검사가 실패했다. 실패 소스·실제 투영 사례는 원본 `outputs/private/bridge_direction_failed_distance_projection_20261009/`에 보존했다.

원본 도형은 수정하지 않고, 검증에서만 노딩한 단순 선형 조각의 거리 구간을 사용했다. 원본과 검증용 집합의 Hausdorff 거리는 0이지만 해당 링크의 엄격한 위상 동등성 검사는 실패했다. 이를 별도로 기록했으며 좌표 대조 허용 오차는 1e-8m다.

실제 교차 조각 1,038개의 거리·좌표 대응을 검증한 뒤 이벤트법으로 배타 클래스 길이 3,600개를 별도 계산했다. 폴리곤 배타 분할 계산과의 최대 차이는 2.20e-10m였고 24개 집계도 일치했다. 이 계산 일치가 실제 도로 구조·시설 시점·원본 반복 선형의 최종 승인을 뜻하지는 않는다. 전북 경계를 확정한 뒤 새 구간 버전에서도 해당 링크의 추적·중첩·방향을 다시 검토한다.

## 도로교 장축·국지 도로 방향 민감도 — 2026-10-09

실제 도로교와 나란하지 않은 수평 중첩을 분리할 필요를 확인했다. 도로교 275개 중 79개는 장축 비율이 2 미만이며, 링크·시설 조합 567개 중 216개는 12가지 검토 설정에 따라 방향 분류가 바뀐다. 도로교 30m 합집합 중첩에서 ‘나란함만’의 비중은 56.55–75.69%, ‘수직에 가까움만’은 5.03–11.36%다. 이 값은 실제 교량 차로의 정답 비중이나 상하 교차 검증이 아니다. 범위 끝점들은 서로 다른 설정에서 나온 값일 수 있다. 방향·축의 모호성을 구분해 추후 시설 확인의 우선순위를 정할 근거로 보존한다.

짝별 중첩 길이는 합산하지 않는다. 개별 교차 선분을 합칠 때 3060643100의 길이가 125.289883m로 부풀어 기존 104.684537m와 달랐고 검사를 통과하지 못했다. 실패 소스를 보존하고 폴리곤의 합집합·배타 분할을 먼저 수행한 뒤 원본 선형과 교차했다. 이후 길이 검사 3,600개가 기존 도로교 중첩과 일치했다. 기하 검사를 결빙 모델의 검증으로 읽지 않는다.

## 제공 설명서 기반 도로교·보도교·철교 구분 — 2026-10-09

수평 시설 중첩에서 도로교·보도교·철교를 구분할 수 있는 제공 원문을 확보했다. 국토지리정보원 DB 설계서 v5.1.1(2014-12-30)21쪽과 원본 FID/UFID/좌표 대조로 30m 이내 278개가도로교 275·철교 2·보도교 1임을 확인했다. 단순 이름·폭 추정으로 시설 종류를 분류하지 않았다. 도로교만의 중첩을 별도 계산해 일반 코드 000의 30m 비중 15.9737%→15.7050%, 영향 500m 9개/1km 8개를 추적했다. 원래 전체 시설 중첩과 코드 004 불일치는 보존한다.

종류·재질 코드의 의미 확인과 현재 해당 차로의 시설 소속 확인은 별개다. XML생성일·수정일은 20230215/20240419이나 실제 시설 기준 시점은 미확정이고 설치 연도 106개가비어 있다. FMTA는 제작 정보 참조 일련번호여서 날짜로 변환하지 않았다. 재질별 열효과와 완충 거리의 위치 정확도를 추정한 결과도 아니다. 모델·임계값은 변경하지 않는다.

## 시설 폴리곤 중첩·원본 속성 불일치 검토 — 2026-10-09

원본 코드만으로 구조물을 해석하는 위험을 실제 사례에서 확인했다. 서해안선 3070564600/3070564700은 원본 코드 004이나 금강대교 폴리곤과 98.37%/98.33% 직접 중첩하고 원본 끝점 이름에도 금강대교가 있다. 속성 조인 오류는 발견되지 않았으므로 `source_code_vs_named_polygon_conflict_not_reclassified` 플래그를 보존한다. 영향 500m 5개·1km 3개 후보를 추적할 수 있다. 원본 코드를 임의로 교량으로 고치거나 현재 고정 모델에 넣지 않는다.

0·10·30m 중첩 민감도와 합집합 길이 보존 12개 검사를 완료했다. 교량 코드 링크의 중첩은 75.21/76.29/99.90%, 터널 코드 링크는 19.01/44.67/77.16%다. 일반 코드 000 링크에도 폴리곤이 겹치지만, 고가 교차·인접 차로·소규모 시설·자료 시점을 구분하지 못하므로 ‘누락 교량’이라고 부르지 않는다. 수평 중첩 비중은 환경 기술 후보이며 실측 결빙 확률·위험 배점이 아니다. 실제 구조와 자료 시점 확인이 선행되어야 한다.

### 지형·복사 특성의 품질 확인

- 제공 DEM 유효값은 0–0.8865979이고 수직 단위·역정규화 계수가 없다. 이 값을 미터로 간주한 경사·음영을 만들지 않았다. 정규화 방식은 운영진 질문에 추가했다.
- 독립 DSM과 같은 도형 중점 465개를 대조하면 순위 상관은 0.943이다. 그러나 탐색적 강건 회귀의 잔차 중앙값이 약 10.6m이며 서로 다른 표면·시기·격자 자료다. 회귀 계수를 공식 역정규화 계수로 쓰지 않는다.
- 공개 Copernicus GLO-30의 높이는 공식 설명서에서 미터·EGM2008임을 확인했다. 14개 개발 지점과 최대 1km 도형 467개에 높이, 500m 상대고도, 16방위·3km 지평선과 sky-view 근삿값을 생성했다. 지형은 DSM이며 도로 경사·공식 차광 실측이 아니다.
- NOAA 수식으로 태양 고도·방위각을 계산하고 DSM 지평선과 결합했다. 방위 해상도·3km 절단·대기 굴절 미보정 때문에 일조 여부도 검증 전 후보 특성이다.
- NASA POWER 복사량은 두 겨울·4개 고정 격자로 수집하고 UTC→KST, 시간 구간 종료 후 결합, Wh/m² 단위를 명시했다. 공개 지연 때문에 **사후 미관측 위치 추정용**이며 실시간 예보 성능으로 보고할 수 없다.
- 개발 타깃 노면온도는 입력으로 사용하지 않았다. 사후 라벨 진단에서 Ice 239개 중 48개가 0°C 초과여서 임의의 `온도>0 → 비결빙` 규칙으로 정답을 바꾸지 않았다.

## 실행된 후속 입력 감사

`python scripts/audit_aws_fallback.py`는 비공개 `outputs/private/weather_features/features.parquet`에서 개발 RWIS의 **지점·시각·기존 AWS 기온 가용 여부**만 읽고, 원본 ZIP의 AWS 기온과 감사된 지점 좌표를 결합한다. 노면온도와 Ice 정답은 읽지 않는다. 사용한 AWS 값은 목표 시각보다 엄격히 이전이며 60분 이내다. 2일 작은 실행은 `--smoke`다. 지점별 연결률과 거리·관측 나이는 Git 제외 경로 `outputs/private/aws_fallback/`에 있다.
