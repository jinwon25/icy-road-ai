## 사전 고정한 비교

기존 허용 23지점 794,545행 중 가용 입력·유효 이진 정답 792,335행이 학습 후보입니다. 결빙 6,926행 중 6,340행이 33408의 첫 겨울에 집중됩니다. 해당 정답을 수정·삭제하지 않습니다. 개발 평가 9지점은 유효 309,712행·결빙 6,687행·완전 날짜 2,056개이며 모든 후보가 같은 가용 범위를 사용합니다.

ASOS 13변수와 이슬점 차이 2개, 사전 설정한 구간 선형 특성 10개를 사용했습니다. 학습 자료로만 중앙값·평균·표준편차를 적합하고 결측 표시 25개를 더합니다. 지점 ID·겨울·날짜는 분할·손실 가중치에만 사용합니다. 과거 목표 노면 관측이나 보호 지점 12410·33411·23402, 이미 평가한 별도 33402·33406·12213·23411의 정답은 입력·학습·선택에서 제외합니다.

모델은 0 초기화 선형 계수의 `delta=2*tanh(Xw+b)`, `logit=(delta-ASOS기온)/2`입니다. 보정 폭 2°C는 실험을 제한하는 설계값이며 물리 임계값이나 실제 노면온도가 아닙니다. Adam 160단계·학습률 0.03·L2 0.001을 고정했습니다. 동일 입력의 연산을 공유하되 각 원래 행의 정답·손실 비중은 유지합니다.

| 손실 | 고정한 정의 |
| --- | --- |
| `bce_day` | 지점·겨울·날짜·해당 날짜에 존재하는 클래스의 균형 BCE |
| `focal_day` | 같은 비중에 gamma=2의 Focal loss |
| `soft_station` | 0.5 BCE + 0.5 양성이 있는 지점·겨울의 soft F1 |
| `soft_day` | 0.5 BCE + 0.5 양성이 있는 완전 날짜의 soft F1. 지점·겨울별 동일 비중 |

무양성 그룹은 soft F1 항에서 제외하고 BCE에 유지합니다. 한 지역 전체 제외 4세트·두 지역 전체 제외 6세트에 네 손실을 적용했습니다. 각 모델의 보정값에 −0.5·0·0.5°C를 더하는 12정책과 기온 상수 5정책을 비교합니다. 주 선택은 내부 F1 최대, 보조 선택은 기준선 Recall의 90% 이상·두 겨울 F1 비악화입니다. 각 손실의 내부 최적 정책도 따로 보고합니다. 외부 성능으로 학습 중단·반복 수·정책을 고르지 않았습니다.
