# 누적 기상 조건의 추가 가치 검증

**누적 이력을 더한 후보는 지역 내부 선택에서 한 번도 채택되지 않았습니다.** 주 선택의 일별 F1은 0.035632로 기온 기준선 0.036601보다 낮았고, 기존 탐지 사건 60개를 잃었습니다. 순간 입력까지만 허용한 대조 선택과 결과가 같아 이 실험에서 누적 조건의 추가 이득을 확인하지 못했습니다. 원래 실행 모델과 보호 평가를 유지합니다.

## 최신 연구를 적용한 범위

[Yi & Seo, 2026년 9월 27일 사전공개 논문](https://arxiv.org/abs/2609.33528)은 실제 노면온도·습도 이력으로 냉각·수증기·동결융해 누적을 계산하고 미래 결빙 시작을 연구합니다. [저자 코드](https://github.com/yunam-seo/road-icing-forced-threshold/tree/5552934b22dc25be07839fc53fe757a7d136b072)의 고정 커밋과 MIT 라이선스, 논문 수식 및 구현 차이를 대조했습니다. 논문은 Ice와 Snow/Ice를 합치고 노면온도에 따른 사건 제외도 적용하므로 대회와 정답·평가 대상이 다릅니다.

여기서는 누적 조건이라는 가설만 자체 구현했습니다. 실제 노면온도 대신 ASOS 기온·지면온도와 AWS 기온을 사용하며, **대회의 Ice 단독 정답을 유지합니다.** 기온·노면온도가 높다는 이유로 정답을 지우지 않았습니다. 원 논문 성능을 재현하거나 미관측 도로에 옮겨 입증한 결과가 아닙니다. 외부 R 코드·모델·사건 자료는 실행하거나 학습 입력에 반입하지 않았습니다.

[기상청 500m 격자 자료 안내](https://apihub.kma.go.kr/apiList.do?seqApi=971)도 확인했습니다. 허용 개발점 한 곳의 한 시간 입력만 시험 요청했지만 현재 인증키에서 HTTP 403이었습니다. 실제 격자 값은 확보하지 못했으며 보유 기상으로 진행했습니다. 응답·인증정보를 제외한 요청 설정은 `outputs/private/forcing_source_probe_20261031_v1/receipt.json`에 보존했습니다.

## 사전 비교 설계

[계획](../../config/antecedent_forcing_20261031.json)과 입력·코드 해시를 고정한 뒤 새 모델 20개를 적합했습니다. 기존 목적함수 실험의 ASOS BCE 10모델도 같은 행에서 재추론했습니다. 이미 본 9개 개발 지점의 반복 연구이며 새 독립 검증이 아닙니다. 공식 보호 3곳 및 개봉된 별도 4곳의 정답은 읽지 않았습니다.

| 비교 요소 | 고정한 조건 |
| --- | --- |
| 학습·공간 분리 | 허용 23곳, 4지역 단일 제외와 6쌍 제외. 같은 학습행 |
| 입력 대조 | 기존 ASOS 25변수 / 순간 기상 40변수 / 누적 이력 포함 64변수 |
| 학습 | 동일 날짜 균형 BCE, 160단계, 학습률 0.03, L2 0.001 |
| 출력 | 기온 문턱의 최대 ±2°C 보정, 같은 고정 오프셋 3개 |
| 내부 선택 | 평균 일별 F1 최대. 보조는 재현율·겨울 조건 추가 |
| 누적 이득 대조 | 누적 후보만 제외하고 같은 내부 선택 수행 |
| 외부 평가 | 완전한 144슬롯 날짜, 기존 지표 분모·정답 유지 |

순간 입력에는 기존 ASOS, 과거 15분 이내 AWS 5관측, 서리점·온도 대비, ERA5-Land 토양-기온 차이·적설·토양수분을 넣었습니다. 이력 입력은 세 온도 대리변수의 30분·6시간 감쇠 냉각·수증기 조건·부호 전환, 1시간 변화, 연속 이력 길이를 추가합니다. 온도 누적은 시간상수로 나누어 °C 척도로 사용하며 실제 노면 열량이나 결빙 확률이 아닙니다.

관측은 목표 시각보다 엄격히 이전에 연결된 값입니다. 이력은 정답 필터링 전의 지점·겨울 전체 시간순에서 계산하고 경계마다 0으로 초기화합니다. 15분 초과 공백에는 감쇠만 하며, 0°C 값은 부호를 바꾸지 않습니다. ASOS 시간 자료의 반복 연결과 사후 재분석을 독립적인 10분 현장 관측이나 실시간 서비스로 표현하지 않습니다.

## 완료 결과

| 내부 선택 절차 | 일별 F1 | Precision | Recall | 기준선 날짜 고정 F1 |
| --- | ---: | ---: | ---: | ---: |
| 기온 0°C 기준선 | 0.036601 | 0.033386 | 0.966799 | 0.036601 |
| 순간 입력까지 허용한 대조 | 0.035632 | 0.040592 | 0.904897 | 0.032076 |
| 누적 입력까지 허용한 주 선택 | 0.035632 | 0.040592 | 0.904897 | 0.032076 |
| 재현율 보호 보조 선택 | 0.036135 | 0.034466 | 0.965378 | 0.035809 |

주 선택은 호남에서 기온 +0.5°C, 서해안·서상에서 기존 ASOS BCE +0.5°C, 금산에서 기존 ASOS BCE 0°C 오프셋을 골랐습니다. 새 순간 입력과 누적 입력은 최종 선택되지 않았습니다. 386개 관측 사건 중 기준선은 330개, 주 선택은 272개를 탐지했고 기존 사건 60개 손실·새 사건 2개 탐지가 있었습니다. 보조 선택도 기존 15개 사건을 잃었습니다.

주 선택의 첫 겨울 F1은 0.065054로 기준선 0.071179보다 낮고, 둘째 겨울도 0.001376으로 기준선 0.001444보다 낮습니다. 채택 조건 9개 가운데 정밀도만 통과했습니다. 보수적인 모든 조건을 요구하지 않더라도, 이 비교의 주 목적이었던 F1과 누적 입력의 추가 가치는 개선되지 않았습니다.

7일 블록 2,000회 재표집한 주 선택과 기준선 F1 차이의 2.5·50·97.5 백분위는 -0.004049·-0.001069·+0.002544이며 양의 차이 비율은 25.8%입니다. 이는 이미 계산한 개발 예측의 날짜 민감도로, 새 지역의 신뢰구간이 아닙니다. 사후 최고는 기존 ASOS BCE 후보였으며 새 누적 모델의 성과로 세지 않습니다.

## 재현·검산과 실패 기록

실험 결과는 `outputs/private/antecedent_forcing_20261031_v2/`에 있습니다. 첫 체크포인트 v1은 입력 특성과 한 모델을 저장한 상태에서 외부 지표를 계산하기 전 중단했습니다. 기준선 일별 표가 만들어지기 전에 참조하는 보고서 순서 오류를 발견했기 때문입니다. 원 코드·설정·출력은 보존하고, v2에서 검증된 특성 캐시를 재사용하여 20모델을 다시 적합했습니다. 학습·선택 조건은 바꾸지 않았습니다.

```powershell
python scripts/evaluate_antecedent_forcing.py
python scripts/audit_antecedent_forcing.py
python scripts/check_notebook.py notebooks/antecedent_forcing_review_20261031.ipynb
```

완료 결과를 덮어쓰지 않습니다. 재적합은 새 연구 노트북의 `RUN_REFIT=True`에서 예제 한 지역을 실행하거나, 별도 출력 경로를 가진 새 계획으로 수행합니다. 최초 v1 특성 구축 코드는 v1 폴더의 `evaluate_antecedent_forcing.original.py`에 보존되어 있고 계산 함수는 [누적 입력 구현](../../src/antecedent_forcing.py)에 있습니다.

검산 도구는 기상 이력을 누락 시각이 포함된 10분 격자의 별도 선형 필터로 계산합니다. **50,850,880개 특성 값, 새 20모델·기존 10모델의 3,729,324예측, 대표 2모델 재학습, 내부 선택 12건, 지표 1,281건, 사건 17조합, 채택 조건 9개와 블록 재표집 4,000회를 모두 대조했습니다.** 특성 계산의 최대 차이는 5.51e-14, NumPy와 PyTorch 추론 차이는 3.71e-6이며 판정값은 일치했습니다. `independent_verification.json`은 `passed`이고 요약 해시는 `452b5a3fa53a3a8ea2f2abd707a330e2ee4c5fb9274b90eb46726b7443f3e657`입니다. 단위 검사 6개는 미래 입력의 과거 영향, 정답·노면온도 입력 배제, 지점·겨울 경계, 긴 공백·0°C 부호 처리 등을 확인합니다.

이 결과는 기상 대리변수만으로 해당 물리 가설을 이식한 제한된 비교의 실패입니다. 실제 노면온도 이력·노면 수분·염분·제설 상태까지 무용하다는 결론으로 확대하지 않습니다. 이후 성능 연구는 더 많은 임계값 탐색보다 입력의 현장 대표성, 센서 상태 및 당시 이용 가능한 운영 정보를 보완하는 데 우선순위를 둡니다.
