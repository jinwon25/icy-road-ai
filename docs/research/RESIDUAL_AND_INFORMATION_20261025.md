# 기온 시작값·관측 지연 보정과 입력 정보량 진단

기온 기준선을 학습 시작점으로 사용하는 30모델·49정책, 과거 두 시간의 기온 변화로 관측 지연을 보정하는 10정책을 비교했습니다. 안정적인 개선 조건을 통과한 방법은 없었습니다. 같은 기상 입력에 상반된 도로 상태가 붙는 정도를 새로 수치화했고, 최신 연구를 설명하는 2쪽 요약과 실행 검사 도구를 v6 검토 묶음에 추가합니다.

## 무엇을 보완하려고 했는가

앞선 직접 분류기는 기온 기준선의 유용한 정보를 충분히 유지하지 못했고, 경보를 추가하기만 하는 방법은 오경보가 크게 늘었습니다. 이번에는 기온 기준선을 학습식 자체의 시작값으로 주면 작은 보정만으로 개선할 수 있는지 확인했습니다. 기상은 시간별인데 도로 판정은 10분 간격이라는 차이도 별도 축으로 검토했습니다.

모델 크기만 키우는 대신 **입력으로 구별할 수 없는 관측이 얼마나 있는지** 진단했습니다. 이 결과는 추가 센서·제설·국지 환경 정보의 필요성을 설명하는 근거이며, 실패한 모델을 정당화하는 최종 성능 한계로 사용하지 않습니다.

## 1. 기온 기준선을 학습 시작값으로 제공

[고정 계획](../../config/residual_icing_20261025.json)의 학습 시작 마진은 `b = -ASOS 기온 / 2`입니다. 마진이 0 이상이면 결빙으로 보는 경우 기존 `ASOS ≤ 0°C`와 같습니다. XGBoost가 배우는 추가 부분을 `r`로 두고, 최종 기온 보정은 `clip(2r, -상한, +상한)`으로 제한했습니다. 이 마진은 검증된 실제 결빙 확률이나 물리적 노면온도가 아닙니다.

| 조건 | 사전 고정한 내용 |
| --- | --- |
| 자료 | 기존 허용 23곳·두 겨울, 같은 API 형식 ASOS. 공식 보호 3곳과 이미 개봉한 새 4곳 제외 |
| 입력 | 기상 13변수와 기온-이슬점·지면온도-이슬점 차이, 합계 15변수. 도로 정답·지점 ID 입력 없음 |
| 학습 대조 | 기온 시작값+날짜 균형, 기온 시작값+행 균등, 시작값 0+날짜 균형 |
| 모델 | 설치된 XGBoost 3.0.1, 깊이 2, 학습률 0.03, 최대 80회. 20회·80회 결과는 동일 학습 경로의 두 시점 |
| 정책 | 보정 상한 0.25·0.5·1·2°C, 양방향 또는 경보 제거만 허용. 48정책+기온 기준선=49 |
| 분할 | 개발 9곳을 네 지역으로 분리. 외부 한 지역 제외 4세트, 내부 선택을 위한 두 지역 제외 6세트. 3모델×10세트=30적합 |
| 주 선택 | 내부 F1 1% 개선, 정밀도·재현율·두 겨울·각 지점 F1 비악화. 후보가 없으면 기준선 복귀 |
| 최종 채택 | 외부 주 선택 결과에서도 F1 1% 개선·겨울/지역/지점 비악화·정밀도/재현율 비악화·기존 사건 손실 0 |

내부에서 선택한 기록을 저장한 뒤 외부 점수를 집계했습니다. 같은 개발 지역을 반복 활용했으므로 새 독립 평가가 아닙니다. 입력·정답·결측 범위를 후보별로 바꾸지 않았습니다.

사후 최고 고정 정책의 F1 상대 증가는 약 2.25%지만, 첫 겨울 F1은 0.071179 → 0.070151로 낮아지고 기존 탐지 47사건을 놓쳤습니다. TP는 5,870 → 5,252, FP는 117,723 → 94,756, FN은 817 → 1,435입니다. 오경보 감소가 미탐 증가를 동반했습니다.

주 선택은 금산을 제외한 내부 지역에서 보정폭 0.25°C의 직접 학습 정책을 골랐지만 금산 외부 평가에서는 11사건을 놓쳤습니다. 나머지 세 지역에서는 기준선으로 복귀했습니다. **내부 기준을 통과했다는 사실이 새로운 지역에서의 안정성을 보장하지 않았습니다.** 사후 최고를 다시 골라 주 결과로 바꾸지 않았습니다.

## 2. 과거 기온 변화로 관측 지연 보정

[별도 고정 계획](../../config/causal_trend_20261025.json)은 최근 과거 ASOS 기온에 `보정계수 × 직전 한 시간 기온 변화 × 경과분/60`을 더합니다. 계수 0.25·0.5·1과 보정 상한 0.5·1·2°C의 9조합, 기준선까지 10정책입니다. 외부 지역을 제외한 세 지역에서 선택하고 남은 지역에서 비교했습니다. 학습 모델은 없습니다.

관측 시각이 예측 시각보다 반드시 이른지 검사했습니다. 이전 관측이 정확히 한 시간 전이고 변화가 10°C 이내인 경우만 보정합니다. 경과 시간이 0분 초과 60분 이하인지 확인하며, 이전 시간 누락·겨울 사이 단절에서는 기존 기온으로 복귀합니다. 미래 관측 보간이나 다음 시간의 관측은 사용하지 않습니다.

개발 9곳의 입력 가용 309,907행 중 309,603행에서 이전 시간 변화가 존재했습니다. 주 선택은 네 지역 모두 기준선으로 돌아갔습니다. 내부 F1 최대 선택의 외부 F1은 0.036478로 기준선 0.036601보다 낮고 FP가 14행 늘었습니다. 고정 정책 중에서도 기준선이 가장 높았습니다. 따라서 관측 지연을 단순 선형 외삽으로 보정하는 방식을 채택하지 않았습니다.

## 3. 같은 기상 입력으로 서로 다른 상태를 구분할 수 있는가

유효 정답이 있는 기존 자료만 사용해 **15변수 값이 모두 같은 행**을 묶었습니다. NaN은 같은 항목의 결측으로 일관되게 취급했고 값을 반올림하지 않았습니다. 동일 입력만 받는 결정적 분류기는 그 묶음 안의 모든 행에 같은 판정을 내려야 합니다.

| 범위 | 유효 행 / 결빙 행 | 고유 기상 입력 | 결빙·비결빙이 함께 있는 묶음 | 그 묶음에 속한 행 | 결빙 전량 보존 시 최소 FP |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 23곳 전체 | 792,335 / 6,926 | 34,480 | 1,532 | 73,306 | 66,380 |
| 개발 9곳 | 309,712 / 6,687 | 22,962 | 1,356 | 31,214 | 24,527 |

15변수만 쓴 경우 결빙 행 전부가 비결빙과 입력을 공유합니다. 이를 센서 오류라고 단정할 수 없습니다. 같은 시간별 기상을 공유하는 다른 도로와 10분 시각을 이 입력만으로 구별하지 못한다는 의미입니다.

정보를 더 구분하는 가상 진단도 수행했습니다. 아래는 **모델 학습이나 성능 평가가 아니라 입력 묶음의 분해**입니다.

| 개발 9곳의 구분 기준 | 혼합 묶음의 결빙 행 | 결빙 전량 보존 시 최소 FP | 정답을 알고 묶음별 판정했을 때 전체 행 F1 최대 |
| --- | ---: | ---: | ---: |
| 기상 15변수 | 6,687 | 24,527 | 0.392692 |
| 기상 + 관측 경과분 | 6,665 | 19,369 | 0.408454 |
| 기상 + 지점 식별자 | 1,131 | 1,543 | 0.945771 |
| 기상 + 지점 식별자 + 경과분 | 0 | 0 | 1.000000 |

마지막 행에서는 309,712개의 입력이 전부 서로 달라집니다. 1.0은 정답을 외우는 것이 가능해졌다는 계산이며 새 지점에서 예측할 수 있다는 뜻이 아닙니다. 지점 식별자를 새 모델에 넣지 않았습니다. 이 상한은 **현재 표본의 전체 행을 합친 F1**에만 해당하고, 공식 방식인 일별 지점 F1이나 미래 분포의 한계로 적용할 수 없습니다. 기준선 FP 117,723은 이 진단의 최소 FP 24,527보다 여전히 크므로, 정보 중복만으로 현재의 낮은 성능을 모두 설명할 수도 없습니다.

필요한 후속 입력은 새 지역에도 적용 가능한 위치별 노면·미세 기상·제설·센서 정의입니다. 지형 정보를 추가한 과거 분류 비교도 안정적 개선에 실패했으므로, 단순히 지점 ID를 넣거나 동일 기상 묶음의 정답을 조회하는 방식으로 대체하지 않습니다.

## 5. 검산과 제출 검토 개선

학습 30개를 별도 가중치 계산으로 재적합하고 저장 모델의 20·80회 마진 전량을 대조했습니다. 원 학습과 별도 재학습의 60회차 점수는 같은 환경에서 정확히 일치했습니다. 내부 지표 2,303건·선택 8건도 검산했습니다. 시작 마진 유무의 차이는 float32로 나무 출력을 누적하므로 연산 수 기반 반올림 한계로 확인했습니다. 초회 감사의 고정 `1e-5` 항등식 허용치는 최대 `1.86e-5`의 누적 차이에서 중단돼, 모델을 바꾸지 않고 감사의 수치 오차 검사를 수정했습니다. 기록은 별도로 보존합니다.

관측 지연 입력은 별도 시각 사전 조회로 310,777행을 다시 계산했고 내부 지표 470건·선택 8건이 일치했습니다. 두 실험 모두 최종 지표·사건과 이전 봉인의 보존을 확인했습니다. 전체 테스트 388개·하위 검사 7개가 통과했습니다.

입력 중복은 Python 튜플별 계수로 다시 집계했습니다. 전체 23곳·개발 9곳 각각 네 구분 기준, 총 8조합의 72개 수치가 일치합니다. 미래 기상 변경 불변성·시간 단절·다른 지점 분리·입력 중복의 작은 전수 경우 비교와 묶음 파일 변조·경로 이탈 검사를 테스트에 추가했습니다.

이번에 모델 자체의 성능 향상은 확인하지 못했지만 결과물 검토 경로를 개선했습니다. [v6](../delivery/REVIEW_BUNDLE_V6_20261025.md)는 기존 모델·예측·8쪽 보고서·노트북·데모를 보존하면서 2쪽 핵심 요약, 최신 연구·원문 품질 진단, 무결성과 예측 재현을 확인하는 한 명령을 추가합니다. 수치의 분모·새 평가와 반복 개발의 차이·미확보 자료를 앞에서 설명합니다.
