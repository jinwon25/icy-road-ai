# ERA5-Land 추가 입력의 실질적 가치 검증

도로 위치별 지표면 열·수분·적설 정보를 새로 확보해 추가 입력의 가치를 통제 비교했습니다. **온도 8회·결빙 분류 30회 모두 채택 기준을 통과하지 못했습니다.** 저장 모델 전량 추론·대표 재학습·별도 지표 계산의 검산을 완료했습니다. 온도 v3·결빙 v2와 기존 제출 ZIP은 유지합니다.

## 자료와 문헌 근거

[2026년 ILES 원 논문](https://gmd.copernicus.org/articles/19/9035/2026/)은 노면온도 이력과 재분석 입력을 결합합니다. 도로 자체 관측 이력을 이용한 연구 성능을 미관측 도로의 성능으로 가져오지 않고, 여기서는 도로 정답 없이 얻을 수 있는 외부 지표면 상태의 추가 가치만 확인합니다. [ERA5-Land 원 논문](https://essd.copernicus.org/articles/13/4349/2021/)과 [Copernicus 자료 설명](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land-timeseries?tab=overview)을 대조했습니다.

[Open-Meteo 역사 기상 API](https://open-meteo.com/en/docs/historical-weather-api)에서 `models=era5_land`, `timezone=Asia/Seoul`, `cell_selection=nearest`, `elevation=nan`을 지정했습니다. 기본 혼합 모델이나 자동 고도 보정 대신 명시한 재분석 격자의 값을 받았습니다. 이용 범위는 무료 비상업 연구이며 [이용조건](https://open-meteo.com/en/terms)과 CC BY 4.0 출처표시를 기록했습니다. 새 인증정보·유료 서비스·외부 모델 가중치는 사용하지 않았습니다.

| 내용 | 실제 확보·검증 |
| --- | --- |
| 위치 | 기존 허용 RWIS 23곳의 도로 좌표. ASOS 좌표와 구별 |
| 기간 | 각 겨울 직전 10월 25일~다음 해 2월 28일, 2개 겨울 |
| 분량 | 46개 응답, 140,208시간, 17개 서로 다른 격자 |
| 원변수 | 기온·상대습도·이슬점, 0–7cm/7–28cm 토양온도·토양수분, 적설 깊이 8개 |
| 이력 | 기온·얕은 토양온도·얕은 토양수분·적설의 6·24·72시간 평균 12개 |
| 시간 연결 | 목표보다 엄격히 이전인 관측, 최대 60분. 계절·시간 공백을 가로질러 평균하지 않음 |
| 보존 | 기존 794,545행과 모든 기존 열이 정확히 동일. 입력 부족으로 평가 분모를 줄이지 않음 |
| 독립 입력 검산 | 원문 1,121,664값, 연결 변수 15,890,900값. 독립 NumPy 이력 계산 최대 차이 7.11e-15 |

약 0.1도 격자의 토양·적설 상태를 500m 도로 관측이나 노면 수막·제빙 상태로 표현하지 않습니다. 재분석 발표 지연이 있어 **사후 역사 분석용**이며 당시 실시간 이용 가능한 예보의 성능이 아닙니다. 격자를 공유하는 도로가 있어 도로별로 독립적인 관측이 추가된 것도 아닙니다.

## 온도: 같은 v3 설정에서 입력만 추가

[고정 계획](../../config/reanalysis_temperature_20261031.json)은 현재 v3의 63변수, HGB 절대오차 손실·1,200회 학습·4지역 제외를 유지합니다. 원변수만 추가한 71변수가 주 비교, 이력까지 추가한 83변수는 별도 보조 비교입니다. 외부 지역 결과를 보고 주 후보를 바꾸지 않았습니다.

| 후보 | 같은 310,091쌍 MAE °C | RMSE °C | BIAS °C | 사전 채택 기준 |
| --- | ---: | ---: | ---: | --- |
| 현재 온도 v3 | 1.145698 | 1.602392 | +0.304301 | 기준 |
| ERA5-Land 원변수 8개 추가 | 1.227861 | 1.756106 | +0.356137 | 실패 |
| 원변수와 과거 이력 20개 추가 | 1.222635 | 1.723839 | +0.384237 | 실패 |

주 후보는 결빙점 부근 오차 조건만 통과했고, 평균·지점·겨울·지역 기준에서 실패했습니다. 이력 후보는 여섯 기준 모두 실패했습니다. 추가 자료의 유용성을 일반적으로 부정하는 결과가 아니라, 명시한 자료·설정·반복 개발 지역에서 기존 v3를 개선하지 못한 결과입니다. 저장 모델 8개·621,554예측 전량 추론, 대표 1개 재학습, 지표 581건의 별도 잔차 집계가 일치했습니다.

## 결빙: 같은 분류기와 내부 지역 선택

[고정 계획](../../config/reanalysis_icing_20261031.json)은 ASOS 15변수, ERA 원변수 추가 23변수, 이력 추가 35변수를 같은 HGB 250회·학습 가중치로 비교합니다. 4개 단일 지역 제외와 6개 지역 쌍 제외로 30개를 적합합니다. 평가할 지역을 내부 선택용 학습에서도 제외하고, 내부 예측의 모든 서로 다른 점수를 임계값 후보로 검사합니다.

주 선택은 일별 지점 F1이며 최악 겨울 F1은 보조 선택입니다. 단순 ASOS 0°C와 같은 분류기의 ASOS 전용 선택을 함께 대조합니다. 입력 추가에 따른 변화와 분류기 변경의 효과를 구별합니다. 날짜 분모·겨울·지역·지점·사건 손실·날짜 블록 민감도를 함께 보고합니다. 별도의 점수별 누적 계산법으로 임계값 선택을 검산합니다.

공식 보호 3곳과 앞서 개봉한 별도 4곳은 새 학습·선택·평가에 사용하지 않습니다. 기존 9개 개발지점을 반복 사용한 결과이므로 새 독립 평가라고 부르지 않습니다.

| 선택 절차 | 일별 지점 평균 F1 | 기존 탐지 사건 손실 / 추가 |
| --- | ---: | ---: |
| 단순 ASOS 0°C | 0.036601 | 0 / 0 |
| 같은 HGB의 ASOS 전용 내부 선택 | 0.003400 | 218 / 0 |
| ERA 추가를 포함한 주 내부 선택 | 0.004359 | 206 / 1 |
| 최악 겨울 F1을 목표로 한 보조 선택 | 0.005416 | 319 / 0 |

주 절차는 호남·서해안·서상 지역에서 기온 기준선, 금산 지역에서 ERA 이력 후보를 선택했습니다. 같은 HGB 대조군보다는 높지만 단순 기온 기준선보다 크게 낮고, 사전 채택 조건 9개 중 대조 HGB 대비 F1 조건만 통과했습니다. 평균 정밀도 0.008356, 평균 재현율 0.873222, TP 350·FP 96,863·FN 6,337입니다. 지점·날짜 평균과 전체 행 합산 지표는 분모가 달라 섞어 해석하지 않습니다.

고정 예측에 대한 7일 날짜 블록 재표집 2,000회에서 기준선 대비 F1 차이의 2.5·50·97.5백분위는 −0.039077·−0.032312·−0.024498이었습니다. 이는 같은 개발 자료의 날짜 민감도이며 새 지역 일반화 신뢰구간이 아닙니다. 내부 선택의 이득이 제외 지역에 전이되지 않는 문제를 새 자료만으로 해결하지 못했습니다.

분류 모델 30개·3,729,324점수 전량 재추론, 대표 2개 재학습, 별도 누적법의 279,055임계값·내부 선택 16건·지표 843건·사건 11조합·채택 조건 9개·블록 재표집 2,000회를 검산했습니다. 저장 예측과 최대 차이는 0입니다. 기존 47+549봉인과 개봉한 4지역의 예측 봉인을 보존했습니다.
