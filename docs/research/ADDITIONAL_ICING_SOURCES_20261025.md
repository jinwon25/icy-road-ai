제설 자료는 가장 직접적인 추가 설명 후보지만, **일자별 실적 전체를 그날 아침의 입력으로 사용하면 미래 정보를 섞을 수 있습니다.** 작업 시각이 없으면 다음 날 이후에만 사용하는 보수적 시차나 원인 분석 전용 사용을 먼저 설계해야 합니다. 적설·결빙 때문에 제설이 시행되는 관계도 있으므로 제설량과 결빙의 상관을 처리 효과로 해석하지 않습니다. 목록의 `_20241231`은 실제 파일의 관측 기간 검증을 대신하지 못합니다.

대회가 공개 기상자료를 허용한다는 답변을 제설 행정자료·외부 결빙 정답의 포괄 승인으로 확대하지 않습니다. 제설 자료는 실제 파일과 사용 범위를 확보한 뒤 문제 범위·참가서약에 대조하고, 허용이 불명확한 사용은 운영진의 명시적 확인이 필요한 후보로 남깁니다. 운영진 문의를 발송하지 않았습니다.

## Hugging Face와 원 저자 조건이 다른 사례

[RSCD Hugging Face 복제본](https://huggingface.co/datasets/rezzzq/RSCD-1million)의 데이터 카드는 MIT를 표시합니다. 반면 [원 저자 다운로드 페이지](https://thu-rsxd.com/dxhdiefb/)는 **CC BY-NC와 비상업용 조건**을 명시합니다. 복제본의 표시만으로 원 자료의 권리를 바꿀 수 있다고 판단하지 않았습니다.

[저자 설명](https://thu-rsxd.com/rscd/)의 RSCD는 베이징에서 촬영한 노면 영상 자료입니다. 현재 과제의 기상·도로환경 입력과 종류도 다릅니다. 이 자료를 받거나 학습하지 않았으며, 참가·수상 이후 활용까지 포함한 권한이 확인되지 않은 상태에서 적격 자료로 분류하지 않습니다. 비상업용 조건 자체가 모든 대회 참가를 일률적으로 금지한다는 뜻도 아닙니다.

## 2026년 문헌을 읽은 범위

[Research progress of pavement icing status recognition and icing sensor](https://doi.org/10.1016/j.jtte.2024.09.016)는 출판사에 2026년 7월 온라인 공개로 안내된 리뷰입니다. [출판사 페이지](https://www.sciencedirect.com/science/article/pii/S2095756426001066)의 검색에 노출된 초록·주요 내용은 확인했지만 전체 본문 직접 접근은 실패했습니다. 센서·인식 방식의 차이를 검토할 근거로만 사용하며, 우리 지점의 센서 오류나 정답 수정 근거로 삼지 않습니다.

최신 문헌이라고 해서 우리 입력·평가 방식에 맞는 것은 아닙니다. 공개 노면 영상과 현장 노면온도 이력을 필요로 하는 방법은 보호 지점의 입력 제한과 맞지 않을 수 있습니다. 논문에 실린 AUC·영상 정확도를 이 프로젝트의 일별 지점 F1과 직접 비교하지 않습니다.

## 확인 기록과 재사용 범위

공개 페이지 6개의 응답·본문 해시는 `outputs/private/additional_icing_sources_20261025_v1/receipt.json`에 기록했습니다. 도로공사 제공기관 페이지에 실제 접속했으며 단순 검색 결과만 보고 접근 실패로 남기지 않았습니다. 페이지가 불러오는 공개 `view.js`에서 로그인·이용자 정보 입력을 요구하는 다운로드 절차도 확인했습니다. 계정 로그인·프로필 제출·자료 요청·데이터 업로드는 하지 않았습니다.

원 HTML·스크립트는 근거 보존용 비공개 폴더에만 있습니다. 제3자의 코드를 프로젝트 구현으로 편입하지 않았으며 GitHub에는 이 출처·적용 판단과 자체 구현만 반영합니다. 실제 도입한 추가 관측의 연결 정확성과 새로운 방법의 성능은 [실험 보고서](ICING_GAP_AND_SYNOPTIC_20261025.md)에서 별도로 확인합니다.
