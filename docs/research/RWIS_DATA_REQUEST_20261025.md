# 센서 위치·정비·제설 자료 요청 초안과 수령 조건

현재 모호한 원인을 제공기관이 재현하고 답변할 수 있도록 질문과 필요한 필드를 정리했습니다. **아래는 발송하지 않은 초안입니다.** 계정 가입·인증키 신청·주최 측 문의·기관 연락을 대신 실행한 기록이 아닙니다. [분석 결과](RWIS_CAUSE_AND_ADDITIVE_20261025.md) · [규정](../competition/OFFICIAL_UPDATE_20261025.md)

## 기상청 API 담당자에게 확인할 내용

**제목: 도로 기상 12213 좌표와 33406 동일 시각 SFS 중복·TM=0 응답 확인 요청**

도로 기상 API `road_stn_obs.php`와 공식 관측지점 목록을 비교하다 아래 차이를 확인했습니다. 관측지점 식별·시각·상태 코드의 원본 정의를 확인하고 싶습니다. 요청 시 인증키는 제거한 매개변수와 원문 일부만 별도 첨부할 수 있습니다.

1. **성암교 12213**: 공식 관측지점 PDF는 위도 34.8028·경도 126.3675, API는 34.9733·126.4961입니다. 2024-11-01 00:10과 2026-02-28 23:50을 각각 조회해도 같은 차이가 있습니다. 각 좌표의 기준 시점·좌표계와 실제 설치 위치·이전 이력, 노선·방향·이정, PDF 수정 이력을 받을 수 있을까요? 과거 관측 API의 LAT/LON이 관측 당시 위치인지 현재 메타데이터인지도 확인 부탁드립니다.
2. **진천터널외부 33406**: 2026-02-13 00:10 KST, `mode=1`, `var=33406`, `tm1=tm2=202602130010`, `help=1`에서 같은 시각에 SFS -999와 2의 두 행이 반환됩니다. `disp=1`과 `disp=0` 모두 같고 TR1은 -1.3으로 동일합니다. 두 행의 장비·수집 채널·원천 레코드 구분, SFS 결측과 유효값이 함께 발생하는 이유, 공식 중복 처리 규칙을 확인 부탁드립니다.
3. **시각 없는 결측 행**: 33406의 2025-11-30 12:00과 12-15 12:00 단일 시각 요청에서 HTTP 200이지만 TM=0인 행이 반환됩니다. 무관측·통신 장애·DB 미수집 중 무엇을 뜻하는지, 복구 가능한 원시 관측과 품질 플래그가 있는지 확인 부탁드립니다.
4. 33406의 장비 제조사·모델·펌웨어·광학/접촉 측정 방식·설치 차로·측정 영역, 2025년 11월–2026년 2월의 교정·교체·통신 장애 이력과 상태 코드 변환표를 받을 수 있을까요? 개인정보나 보안상 제한되는 항목은 제외하고 관측 해석에 필요한 범위만 요청합니다.

공개 [API 안내](https://apihub.kma.go.kr/apiList.do?seqApi=971&seqApiSub=293)의 공식 문의 경로를 사용합니다. 특정 제조사 모델을 이미 사용하는 것으로 전제하지 않습니다. 원본 파일 전체나 인증키를 공개 게시판에 올리지 않습니다.

## 도로공사 제설 자료 담당자에게 확인할 내용

**제목: 공개 일자별 제설 자료의 작업 시각·구간 식별과 과거 파일 제공 범위 확인**

[일자별 제설작업 자료](https://www.data.go.kr/data/15045677/fileData.do)와 [공식 T5 제공 페이지](https://data.ex.co.kr/portal/fdwn/view?type=ETC&num=T5&requestfrom=dataset)의 2024/2025년 파일 목록을 확인했습니다. 다음 조건의 원자료와 설명서를 받을 수 있는 정상 이용 절차를 확인하고 싶습니다.

| 구분 | 필요한 필드·범위 | 필요한 이유 |
| --- | --- | --- |
| 기간 | 2024-11-01–2025-02-28, 2025-11-01–2026-02-28 | 두 겨울을 동일 조건으로 비교. 2026년 1·2월 제공 가능 여부 별도 확인 |
| 위치 | 공식 노선번호, 방향, 시작·끝 이정, 적용 차로, 좌표계, 지사·작업구간 ID | 동명이교·반대 방향·다른 이정 체계의 오결합 방지 |
| 시각 | 실제 작업 시작·종료, 최초 기록·수신, 수정 시각, KST 여부 | 미래 작업이나 사후 입력을 과거 결빙 예측에 사용하는 누출 방지 |
| 조치 | 예방/사후 살포 구분, 염화칼슘·소금·혼합액 등 종류, 단위·투입량, 반복 살포 | 제설 행위와 강설·차량 동원 같은 배경 항목 구분 |
| 누락·품질 | 기록 없음과 미작업의 차이, 취소·중복·수정 이력, 제공 지사 범위 | 빈 값을 ‘제설 없음’으로 오해하지 않기 |
| 이용 조건 | 대회 학습·검증·집계 발표 허용, 원본 재배포 제한, 출처 표기·보유 기한 | 데이터 이용허락과 대회 규정을 함께 지키기 |

실제 다운로드에 필요한 계정·이용자 정보는 공식 절차에서 처리해야 합니다. 별도 EX OpenAPI가 있다면 현재 유효한 서비스명·명세·키 신청 경로를 확인하며, KMA 인증키를 재사용하지 않습니다. 사람·차량 식별 정보는 요청하지 않습니다.

## 대회 주최 측에 확인할 내용

**제목: 제설 행정자료·센서 메타데이터의 활용 범위와 최종 제출 일정 확인**

공개 기상자료와 별도로, 도로공사 공개 제설 행정자료 및 제공기관이 확인해 준 센서 위치·교정 메타데이터를 사용할 수 있는지 확인하고 싶습니다. 아래 용도를 구분해 허용 여부를 부탁드립니다.

- 비보호 개발 지점의 센서 품질 진단 및 관측 해석.
- 제공기관이 정정한 좌표·품질 플래그를 사용하는 절차와 공개되지 않은 답변의 제출 첨부 범위.
- 예측 시점에 실제 가용한 제설 작업 기록의 입력 사용. 일자 합계·사후 작성 자료는 과거 시점 입력에서 제외하는 조건.
- 공식 보호 3지점의 온도·상태 정답을 취득·참조하지 않는 범위의 메타데이터 사용.
- 결과물 접수 시작·마감 날짜·마감 시각·업로드 경로와 제출 형식의 최종 공지 위치.

## 수령 후 모델에 넣기 전 통과해야 할 조건

받은 자료는 먼저 `outputs/private/`의 별도 폴더에 원본·수신일·해시·설명서·이용조건과 함께 보존합니다. **파일을 받았다는 사실만으로 학습 허용으로 처리하지 않습니다.**

1. 제공기관·공식 출처·이용조건·대회 허용 범위를 문서로 확인합니다. 보호 지점의 정답이 섞이면 해당 정답을 열람·학습하지 않는 분리가 먼저 필요합니다.
2. 노선·방향·이정·좌표계·설치 유효기간이 일치하는지 확인합니다. CCTV 2026년 시설 목록을 두 겨울의 장비 설치 이력으로 대신 쓰지 않습니다.
3. 센서 원시 값·상태 변환·교정·품질 플래그를 구분합니다. 현재 평가에서 유리한 쪽으로 충돌 정답을 선택하지 않습니다.
4. 작업 시각과 당시 이용 가능 시각을 모두 만족해야 예측 입력에 연결합니다. 일자만 있는 자료는 우선 사후 원인 분석에 한정합니다.
5. 기존 봉인 평가를 보존합니다. 새 후보는 개발 범위에서만 고르고, 새 독립 평가가 필요하면 미열람 지역·기간에서 별도 계획과 예측을 먼저 고정합니다.

현재 필요한 핵심은 모델 규모보다 관측 의미·시점·위치를 확인할 증거입니다. 문의 발송과 비공개 자료 제공 동의는 아직 완료되지 않았습니다.
