# 최신 문헌·공개 구현의 적용 및 규정 검토

2026년 10월 24일 사용자 요청에 따라 노면온도·결빙 연구와 GitHub·Hugging Face 공개 자료를 추가 검토했습니다. 문헌을 읽은 것, 코드를 실행한 것, 학습 데이터·가중치를 도입한 것을 구별합니다. 현재 확장 실험은 기존에 확보한 허용 기상자료와 로컬에서 새로 학습한 모델을 사용합니다. 이 문서는 운영진의 승인을 대체하지 않습니다.

## 대회 조건과 확인 범위

현재 웹으로 확인한 [대회 소개](https://aida.kisti.re.kr/competition/main/overview.do)는 저작권 문제가 해결된 자료·도구 사용, 수상작 공개 예정, 지적재산권 침해 시 수상 취소를 명시합니다. **전체 일정·시상식은 11월 25일로 표시됩니다.** 사용자가 알고 있는 11월 말은 결과물 제출 마감으로 확정하지 않습니다. 11월 6일은 문제 페이지의 참가신청 종료일입니다.

10월 16일 원문·서명이 보존된 [문제별 Q&A 588](https://aida.kisti.re.kr/competition/problem/PROB_000000000004604/detail/commuDetail.do?bbsId=BBSMSTR_000000000319&nttId=588)은 공개 공공 기상자료를 출처·활용 근거와 함께 쓸 수 있다고 답변했습니다. 평가 대상 12410·33411·23402의 추정 대상 실측값을 외부에서 확보해 학습·예측 입력 또는 제출 예측으로 쓰는 것은 금지합니다. 같은 글의 초기 목표안개 노면온도 제공 설명은 후속 답변에서 위경도·고도·시정 제공으로 정정되었으므로 초기 답변만 인용하지 않습니다.

보존된 [결과물 안내 564](https://aida.kisti.re.kr/competition/main/selectNotice.do?bbsId=BBSMSTR_AAAAAAAAAAAA&nttId=564)는 외부 데이터·코드·모델·라이브러리의 저작권과 이용조건 확인, 실행환경·학습 및 평가 방법·AI 사용과 검토 과정 기록을 요구합니다. 제출 안내에 외부 API 설정 기재 항목이 있다는 사실만으로 특정 문제의 외부 AI 예측 API가 허용된다고 해석하지 않습니다. 기존 참가 서약의 승인 없는 제3자 제공 금지와 종료 후 폐기 조건도 유지합니다.

10월 24일 상세 Q&A·공지·빈 참가서약의 최신 바이트 재조회는 실패했고, 연결된 브라우저도 없습니다. 따라서 마지막으로 완전히 확인한 10월 16일 보존본과 현재 읽힌 공개 소개·목록을 구분합니다. 최신 상세 규정이 불변이라고 단정하지 않으며, 공개 사전학습 가중치의 포괄적 허용이나 발표된 별도 사용 마감일도 확인하지 못했습니다. 문헌·코드의 공개 날짜는 기록하되 확인되지 않은 공개 시점 제한을 임의로 만들지 않습니다.

10월 24일 다시 읽은 [공지 목록](https://aida.kisti.re.kr/competition/main/notice.do)은 올해 FAQ 10월 12일·결과물 안내 9월 30일을 표시합니다. [일반 Q&A 목록](https://aida.kisti.re.kr/competition/main/qna.do)에는 10월 24일 녹조 문제 문의 2건과 10월 23일 참가신청 문의가 추가로 보입니다. 이는 우리 문제의 규정 변경을 확인한 근거가 아니며, 10월 19일 데모영상 문의의 답변 본문도 여전히 미확인입니다. 검색 결과의 목록 캐시는 직접 연 목록보다 이전 상태였으므로 게시물 총건수를 합산하지 않았습니다.

## 실험에 연결한 내용

[확장 실험 계획](EXTENDED_SEARCH_20261024.md)의 18개 회귀 후보·8개 열 입력 후보, [12개 후속 대조](../../config/thermal_refinement_20261024.json)를 시작으로 총 71개 회귀 설정과 19개 고정 평균을 비교했습니다. 학습 길이·나무 크기·규제, 지역 균등 가중치, 지면온도 제거 및 단독 추가, 과거 1·3·12시간 지면온도·일사·운량의 평균을 포함합니다. 과거 노면온도와 보호 정답은 입력에 없습니다. 시간창은 현재 시각을 제외하고, 결측을 미래 값으로 채우지 않습니다. 사전 채택 기준을 완화하지 않았습니다. [완료 결과와 실제 제출 실행](../delivery/EXTENDED_UPGRADE_20261024.md)

열 입력 개선의 원인이 특정 자료 연결 오류가 아닌지 확인하기 위해 공공 AWS·ASOS 원천에서 별도 조회 방식으로 재구성하는 [검산 코드](../../scripts/audit_thermal_weather_inputs.py)도 추가했습니다. 확장 탐색은 반복 개발 평가이며 새 독립 평가나 공식 성적이 아닙니다. 자료가 부족한 노면별 미세환경과 제설 이력까지 논문만으로 채워 넣지 않습니다.

현재 연구에서 사용한 scikit-learn·CatBoost·LightGBM·XGBoost는 설치된 로컬 라이브러리입니다. 외부 사전학습 가중치·타 대회 정답·보호 노면 실측·비공개 중국 관측자료는 도입하지 않았습니다. 최종 채택 모델의 의존성과 라이선스 고지는 v3의 `licenses/`에 실제 파일과 버전 기준으로 포함했습니다. CatBoost·XGBoost는 연구 비교에만 사용했고 최종 추론 의존성은 아닙니다.

실제 설치한 연구 의존성 10종의 버전·라이선스 메타데이터와 발견된 고지 파일을 `outputs/private/research_license_inventory_20261024_v1/`에 해시와 함께 보존했습니다. CatBoost·XGBoost의 설치 배포에서는 완전한 LICENSE 파일을 찾지 못해 메타데이터 확인과 구분했습니다. 아직 해당 패키지 코드를 제출 묶음에 복사하지 않았습니다. 자체 MLP 비교에는 설치된 PyTorch 2.7.1 CPU를 사용하며 PyTorch의 LICENSE·NOTICE도 보존했습니다.

## 공개 지형 자료의 추가 대조

[Copernicus 공식 설명](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM)과 [AWS 공개 자료 등록부](https://registry.opendata.aws/copernicus-dem/)는 GLO-30의 공개 이용과 라이선스 적용을 설명합니다. 보존된 `eula_F.pdf`의 제4조는 복제·배포·공중 전달·가공 및 결합을 허용하고, 제6조는 출처·가공 고지·책임 제한과 공식 보증으로 오인시키지 않을 의무를 규정합니다. 원문 SHA256은 `32049914c37f14e7d53b48d13d74a49e77c030236e2acc7a0df426f9344feba2`입니다. 가공 결과에 필요한 출처·책임 고지를 함께 저장했습니다.

새 다운로드 없이 기존 2026년 10월 7일 확보한 공개 DSM 4개 타일에서 허용 개발 23곳의 고도·주변 상대 높이·하늘 가림과 16방위 지평선을 계산합니다. DSM은 건물·수목을 포함하므로 도로 바닥 높이·교량·터널·포장·제설 상태의 정답으로 해석하지 않습니다. 태양 위치 근사와 차폐 지표는 실제 복사량 실측이 아닙니다. 기존의 사후 NASA 복사량 자료도 이번 입력에는 넣지 않습니다. 지형 추가와 태양 위치만 추가한 경우를 기존 22·52개 기상 입력에 각각 대조합니다. [사전 설정](../../config/terrain_thermal_search_20261024.json)

이는 공개 외부 자료의 이용조건과 대회의 출처·재현 요구에 맞춰 실시하는 개발 대조입니다. 운영진이 이 특정 가공 방법을 별도로 승인한 것처럼 기록하지 않습니다. 보호 지점의 노면 정답은 읽지 않았으며, 지형 효과도 다른 후보와 같은 지역 제외 기준을 통과해야 채택합니다.

태양 위치의 계산 근거는 [NOAA의 태양 위치 근사식](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)으로 재확인했습니다. 연중 일수·윤년·시각·동경·UTC+9 시간대에서 균시차·태양 적위·시간각을 구하며, 대기 굴절은 보정하지 않습니다. 별도 사전학습 모델이나 외부 예측 API가 아닙니다. 태양 위치를 더한 54개 입력에서 개선이 보여, 지점 좌표와 연결된 ASOS 좌표를 각각 쓴 대조 및 과거 열 상태와의 결합을 추가했습니다. [후속 설정](../../config/solar_memory_search_20261024.json)

ASOS 좌표 방식은 같은 원천 기상을 공유하는 위치끼리 입력을 정확하게 공유할 수 있습니다. 지점 좌표 방식과의 MAE 차이가 0.5% 이내이고 기존 채택 기준을 통과하면 이 방식의 재현·제출 규모 이점을 우선하도록 비교 전에 정했습니다. 좌표 차이를 무시한 채 지점 태양 위치를 같은 값으로 복제하지 않습니다.

## v3 이후 추가 열람과 실제 대조

[Karsisto·Hieta·Kämäräinen, JAMC 2026](https://journals.ametsoc.org/view/journals/apme/65/6/JAMC-D-25-0189.1.xml)은 5월 27일 온라인 공개된 FMI 노면온도 예측 보정 연구입니다. 검색 도구가 제공한 저자 원문에서 가중식·분할 한계·자료 공개 범위를 확인했으며 직접 페이지 열기는 403으로 실패했습니다. 실제 관측 온도와 선행시간으로 학습 가중치를 정하고, 최소 0.1·최대 1을 둡니다. 저자는 학습·검증의 관측소가 겹친다는 한계와 일반 온도 모델·결빙점 모델의 결합이 미해결임을 명시합니다.

우리는 보호 정답과 외부 자료 없이 허용 훈련 정답만으로 결빙점 가중 HGB를 대조합니다. FMI XGBoost·내부 RoadSurf 실행기·비공개 전체 자료의 재현이 아니며 저자의 개선율을 우리 결과로 사용하지 않습니다. [RoadSurf v1.5.1](https://github.com/fmidev/RoadSurf/tree/v1.5.1)은 논문이 지목한 공개 버전이지만 이번 직접 저장소 조회는 실패해 코드를 가져오지 않았습니다. 논문의 AMS 재이용 조건을 코드의 자유로운 복사 허용으로 해석하지 않습니다.

[Li et al., GMD 2026](https://gmd.copernicus.org/articles/19/9035/2026/)의 24시간 입력창 설명을 다시 확인하고 기존 12시간보다 긴 기상 이력을 시험합니다. 원 연구의 과거 노면온도 입력·지점별 적합은 가져오지 않습니다. [RoadSurf 1.1의 저장 항·동결·융해 설명](https://gmd.copernicus.org/articles/17/4837/2024/)은 순간 판정의 짧은 지속 가설에 참고했습니다. 단순 상태 규칙을 에너지 수지·얼음 양·마찰·제설의 물리 재현으로 표현하지 않습니다.

해당 가중치·이력 구현은 기존 설치된 [scikit-learn 1.6.1의 HGB](https://scikit-learn.org/1.6/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)와 자체 과거 관측 집계를 사용합니다. 최종 63개 입력의 LightGBM L1/L2도 별도로 대조했습니다. 추가 논문 코드·모델 가중치·영상·비공개 외국 자료를 복사하거나 외부 API에 대회 자료를 보내지 않았습니다. MSTF-Net의 PMC 페이지는 여전히 브라우저 확인 화면이어서 이를 우회하지 않았습니다. [후속 계획과 완료 상태](EXTENDED_SEARCH_20261024.md#v3-이후-후속-연구--완료)

알고리즘·입력 결합의 미검토 범위를 확인해 [LightGBM 4.6.0 공식 매개변수](https://lightgbm.readthedocs.io/en/v4.6.0/Parameters.html)의 L1·L2 목적, CPU 결정성 설정과 고정 반복 수를 추가 대조에 적용했습니다. 현재 설치본의 MIT 고지는 기존 라이선스 기록에 보존되어 있습니다. 외부 평가 정답으로 학습을 조기 종료하지 않습니다.
