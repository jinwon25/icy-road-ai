# 비선형 결빙 모델과 오경보 분석 — 2026-10-02

비선형 모델과 결빙 판정 기준을 바꾸었을 때 적중·오경보가 어떻게 달라지는지 비교합니다. 일평균 점수 상승에도 오경보가 크게 늘어 최종 모델로 확정하지 않았습니다.

## 판단

이번 고정 HistGradientBoosting 모델은 **최종 모델로 확정하지 않는다**. 일평균 F1로 임계값을 고른 변형은 대회 집계에 가까운 개발 지표를 개선했으므로 다음 실험의 비교 후보로 보존한다. 다만 기상 입력의 비선형 관계를 모델링해 결빙 적중 지점을 늘리는 동시에 오경보도 크게 늘렸다. 기존 로지스틱과 새 모델 모두 실사용에는 부적합하다. 대회 지표 개선과 운영상 경보 품질을 구별한다.

20260915 구버전 개발 데이터로 수행했으며 공식 보호 지점 12410·33411·23402는 사용하지 않았다. 수정 데이터 배포 후 전처리부터 재검증해야 한다.

## 실험 설계

- 기존과 동일한 14개 기상·시각 특징, 14개 외부 LOSO, 외부 학습 지점 내 3개 내부 관측소 그룹을 사용했다. 타깃 지점의 노면온도·노면상태·과거 정답은 입력하지 않았다.
- 전체 483,805개 시점, 유효 라벨 483,652개, Ice 239개를 유지했다. 다수 클래스 다운샘플링은 하지 않았다. Ice 118개가 12210에 집중되고 3개 개발 지점은 Ice가 0개다.
- 모델 설정은 실행 전에 `config/ice_nonlinear_experiment.json`에 고정했다. 100회 부스팅, 학습률 0.05, 최대 잎 15개, 최소 잎 표본 100개, L2=10, 클래스 균형 가중치, 시드 20260923을 사용했다. 임의의 행 분할이 생기지 않도록 내부 조기종료를 껐다.
- 임계값은 내부 관측소 OOF만 사용했다. 외부 정답으로 임계값이나 모델 설정을 변경하지 않았다. 첫 두 외부 지점의 smoke 실행도 전체 학습 행을 유지했다.
- 정책 1은 기존과 같은 전체 10분 F1 최대화다. 정책 2는 0–1을 0.01 간격으로 탐색해 지점별 일평균 F1을 최대화한다. **목적함수와 후보 임계값 집합이 함께 달라지므로 차이를 목적함수 하나의 효과로 해석하지 않는다.**
- 일별 144개 유효 관측 조건과 Precision/Recall 각각의 미정의 처리는 여전히 잠정이다. 무결빙·무예측일 제외와 지점별 평균 후 평균 구조는 확인된 Q&A를 따른다.

모델의 결측 처리·균형 가중치·조기종료 설정은 [scikit-learn 1.6 공식 문서](https://scikit-learn.org/1.6/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)를 확인했다. 클래스 가중 점수를 보정된 결빙 확률로 해석하지 않는다.

## 동일 정답 행의 비교

| 모델 / 내부 임계값 정책 | TP | FP | FN | Precision | Recall | 10분 F1 | 결빙 적중 지점 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 대체 AWS 로지스틱 / 전체 10분 F1 | 21 | 955 | 218 | 2.152% | 8.787% | 0.03457 | 1/11 |
| 비선형 HGB / 전체 10분 F1 | 22 | 20,363 | 217 | 0.108% | 9.205% | 0.00213 | 5/11 |
| 비선형 HGB / 지점별 일평균 F1 | 112 | 68,513 | 127 | 0.163% | 46.862% | 0.00325 | 8/11 |
| 항상 비결빙 진단 기준 | 0 | 0 | 239 | 미정의 | 0% | 0 | 0/11 |

지점 수의 분모 11은 실제 Ice가 있는 개발 관측소다. 높은 재현율과 더 넓은 지점 적중을 얻더라도 경보 대부분이 오경보인 결과를 개선으로 단정할 수 없다. ‘항상 비결빙’은 불균형 데이터의 진단 기준일 뿐 제안 모델이 아니다.

### 대회 집계와 고정 분모 진단

| 모델 | 지점별 일평균 F1 | F1 정의 날짜 / 지점 | 같은 Ice 날짜의 F1 (지점 균등) | 무결빙일 오경보 | 적중 사건 / 전체 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 로지스틱 / 10분 F1 | 0.001087 | 240 / 14 | 0.002074 | 130 | 18 / 215 |
| HGB / 10분 F1 | 0.001298 | 595 / 13 | 0.023107 | 485 | 19 / 215 |
| HGB / 일평균 F1 | 0.005694 | 1,455 / 14 | 0.035251 | 1,345 | 105 / 215 |

일평균 F1 정책의 개발 지표 개선은 사실이다. 동시에 분모가 모델 예측에 따라 달라지므로 같은 실제 Ice 날짜 110개를 고정한 진단도 함께 제시한다. 완전 날짜 3,308개에 포함된 양성은 236개이며, 부분 날짜 정책 때문에 양성 3개가 일별 집계에서 빠진다. 부분 날짜도 포함하면 3,360일, 실제 Ice 날짜 112개가 되며 HGB 일평균 지표는 0.005614다. 이 민감도 분석으로 공식 충족률 조건을 임의 확정하지 않는다.

고정 Ice 날짜의 지점균등 F1 차이를 재표집한 탐색적 95% 구간은 HGB/10분 정책 +0.00243–+0.04346, HGB/일평균 정책 +0.01656–+0.05079다. 이 구간은 **무결빙일 오경보 비용을 포함하지 않는 조건부 지표**에 대한 것이므로 전반적 우수성이나 실사용 적합성의 근거로 사용하지 않는다.

HGB/일평균 정책에서 33412는 실제 Ice 1개 대비 FP 19,497개, 실제 Ice가 없는 23204는 FP 9,014개다. 최장 예측 경보는 540개 연속 시점이며, 총 경보 사건 5,390개 중 실제 Ice와 겹치지 않은 사건이 5,311개다. 희소 사건의 재현율만 보고 이 경보 부담을 숨기지 않는다.

## 추가 진단과 해석 원칙

`outputs/private/ice_nonlinear_comparison/`에 다음을 기록한다.

- `summary.json`: 일평균·지점 평균과 정의된 날짜 수, 같은 실제 Ice 날짜를 고정한 비교, 무결빙일 오경보, 날짜 충족률 민감도, 사건 단위 재현율, 겨울별 진단, 지점 재표집 결과.
- `station_metrics.csv`: 지점별 혼동행렬·평균 정밀도(AP)·고정 Ice 날짜 F1.
- `daily_metrics.csv`: 날짜별 정답·예측·분모와 제외 여부.
- `raw_state_errors.csv`: 원시 노면상태별 오경보. 원시 코드를 모델 입력이나 임의 재라벨링에 사용하지 않는다.
- `tradeoffs.png`: 적중 수·오경보·고정 Ice 날짜 F1 비교 그림.

사건은 같은 지점에서 10분 간격으로 이어지는 실제 Ice 구간이며, 그 안의 예측 적중 여부만 계산한다. 관측 공백·미정의 라벨은 사건을 끊는다. 예측 경보 구간의 길이와 오경보 사건 수도 별도 기록한다. 이 사건 지표는 공식 평가가 아니다.

고정된 실제 Ice 날짜의 지점별 F1 차이에 대해 2,000회 지점 재표집 구간을 계산한다. 관측소 수가 적고 LOSO 학습 집합이 겹치므로 독립 확인이나 유의성 검정으로 주장하지 않는다. 겨울별 결과도 두 겨울을 함께 학습한 공간 검증의 층별 진단이며 미래 겨울 검증이 아니다.

## 데이터·재현 점검

캐시 입력의 AWS/ASOS 시각은 모두 타깃보다 과거였다. 미정의 상태 153건은 `0` 98건, `-999` 40건, `-999.0` 1건, `12.1` 11건, `13.1` 3건이며 비결빙으로 채우지 않았다. 자정 Ice 9건은 원래 라벨대로 유지했다. 자정 변환 오류가 예고되었으므로 이 값이 정정본에서도 유지된다고 단정하지 않는다.

입력·분할·설정 해시, 학습/검증 지점 목록, 내부 임계값 탐색 기록을 보존했다. `input_audit.json`에 별도 입력 감사와 실행환경을 저장했다.

```powershell
python -m unittest discover -s tests -v
python scripts/baseline_ice_nonlinear.py --smoke
python scripts/baseline_ice_nonlinear.py
python scripts/compare_ice_nonlinear.py
python scripts/check_notebook.py
```

노트북 실행 목록의 `ice_nonlinear`는 전체 재학습, `ice_nonlinear_comparison`은 비교 재생성이다. 기본 노트북 실행은 저장된 전체 결과를 확인한다.

검증 완료: 단위 테스트 25개, 실제 Jupyter 커널 코드 셀 25개 통과. 전체 모델 14개 외부 fold 및 42개 내부 fold 완료. 워크플로 37단계, 노트북 저장 출력 0개. 비교 그림을 렌더링해 수치·라벨 표시도 확인했다.

## 다음 실험의 우선순위

1. 정정 데이터의 자정·상태 코드·추가 RWIS를 재감사하고 동일 분모의 기준 결과를 다시 생성한다.
2. 과거 주변 RWIS의 수분·노면 상태 정보와 결빙 사건의 공간 동시성을 개발 지점에서 먼저 감사한다. 물리적으로 가까운 입력에 신호가 있는지 확인한 뒤 특징을 만든다.
3. 학습형 주변 RWIS 특징에는 외부 제외 지점뿐 아니라 내부 제외 지점도 참조에서 제거한다. 단순히 다른 모델을 더 복잡하게 만드는 것보다 입력의 실제 관측 가능성과 정보량을 먼저 확인한다.
4. 부분 날짜·미정의 지표 규칙을 확정하고, 모델/임계값을 고정한 후에만 보호 3개소 최종 평가를 연다. 결빙 예측을 확률 위험 지도처럼 표현하는 단계는 아직 이르다.
