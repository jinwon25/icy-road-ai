## 연구 질문과 사전 고정 설계

주변 AWS·ASOS 기상으로 도로 종합관측소의 기온(°C), 상대습도(%), 1분 풍속(m/s)을 추정할 때, 관측값을 그대로 전달하는 것보다 체계적으로 나아지는지 확인합니다. 10월 7일 수정 대회 배포본의 허용 14곳과 기존에 수집한 개발 9곳의 두 겨울을 사용합니다. 보호 3곳과 이미 개봉한 독립 4곳은 새 정답·학습·선택에서 제외합니다.

첫날 표본에서 개발 9곳 중 종합관측소 4곳에 세 기상 변수가 있고 다른 5곳에는 없음을 확인했습니다. 전체 겨울의 관측 수와 정답 없는 행을 먼저 집계합니다. 세 변수의 평가 지점 수를 노면 상태가 있는 9곳으로 부풀리지 않습니다. 데이터 준비는 지점 번호 열을 먼저 읽고, 허용되지 않은 CSV 행을 건너뛴 후 기상 목표 열만 읽습니다. 노면 상태와 노면온도는 읽지 않습니다.

모형은 지역별 전체 지점을 두 겨울 모두 제외하는 4회 검증입니다. 기온·습도·풍속 각각 고정 HGB 잔차 모형과 직접 회귀를 4회씩, 총 24개 적합합니다. 주 후보는 AWS 우선 기준선의 잔차를 학습하는 모형입니다. 외부 지역 결과로 최적 모형이나 변수를 고르지 않습니다. 학습 지점·겨울의 총 가중치를 같게 맞춥니다.

기준선은 ASOS 단독과, 15분 이내의 엄격한 과거 AWS가 있으면 AWS·없으면 60분 이내 과거 ASOS를 쓰는 방법입니다. 모든 모형과 기준선은 목표별 동일한 유효 행에서 비교합니다. ASOS·AWS 기상, 출처의 시간차·거리, 시간·계절 주기, 태양 위치와 기상 변수 차이를 사용합니다. 지점 ID·연도·RWIS 목표 기상·노면온도·결빙 정답·사후 ERA5는 입력하지 않습니다.

주 성공 조건은 AWS 우선 대비 전체 MAE 5% 이상 감소, 두 겨울 각각 악화 없음, 모든 지역의 악화가 10% 이내, 날짜 7일 블록 재표집 2,000회의 MAE 차이 97.5백분위가 0 미만입니다. 습도 출력은 0–100%, 풍속 출력은 0 이상으로 제한합니다. 행 수·BIAS·MAE·RMSE·상관계수·R²를 함께 기록합니다. 날짜 재표집은 현재 네 지역에 조건부인 민감도이며 새 지역 일반화 신뢰구간이 아닙니다.

## 결빙으로의 전이는 실패

기온 정확도 개선을 결빙 성과로 대신하지 않기 위해, 별도 계획 `config/transferred_air_icing_20261031.json`에서 **예측 기온 ≤0°C**라는 단일 정책을 고정했습니다. 기온 학습에서 해당 지역을 제외한 4모델을 개발 9곳 전체에 적용하고 예측을 봉인한 뒤 기존 개발 결빙 정답과 비교했습니다. 정답으로 새 임계값을 고르지 않았습니다.

일별·지점별 집계 F1은 ASOS 0.036601에서 0.035825로 하락했습니다. 두 겨울 F1은 각각 0.071179→0.069764, 0.001444→0.001191입니다. 정밀도 0.035541·재현율 0.930436이며 TP 5,417·FP 124,813·FN 1,270입니다. 386사건 중 기준선 탐지 330건에서 후보 탐지 300건으로 줄고, 기존 탐지 38건을 잃고 8건을 얻었습니다. 날짜 블록 F1 차이 구간 [−0.002133, +0.000817]은 0을 포함합니다.

따라서 이 고정 정책은 미채택입니다. 기온·습도·풍속 추정의 개선은 별도 성과이고 기존 노면온도 v3·결빙 v2를 유지합니다. 더 정확한 지역 기온만으로 노면 상태·수분·제설 등의 영향을 모두 설명할 수 있다는 주장을 하지 않습니다.
