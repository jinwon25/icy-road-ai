## 설계

14개 개발 지점을 하나씩 제외한다. 제외 지점의 두 겨울 자료는 회귀 학습에 사용하지 않고, 나머지 지점의 2024-11–2025-02만 학습한다. 2025-11–2026-02의 제외 지점 241,201행을 평가한다. 결측 보정·표준화도 학습 자료에서만 적합한다.

기상 Ridge α=100과 기존 1:1 혼합 가중치를 고정했다. 튜닝하지 않았다. 같은 노선의 가장 가까운 다른 개발 RWIS 노면온도를 엄격한 과거 관측으로 사용한다. RWIS가 없으면 기상 예측으로 대체해 지연 시나리오 간 평가 분모를 고정했다. 관측 최대 나이는 60분이며, 0·10·30·60분 발표 지연을 비교했다. 보호 3개 지점은 타깃·학습·참조 어디에도 사용하지 않았다.

0분도 동시각 관측을 금지하므로 10분 주기의 이번 자료에서는 10분 지연과 결과가 같다. RWIS 연결 행은 각각 241,186 / 241,186 / 241,149 / 241,028이며 나머지도 기상 대체 예측으로 평가에 남긴다. 기본 혼합 MAE 감소는 약 24.0%다.

지연 30분에서 12210·23203, 60분에서 12210·12409·23203은 기상만보다 MAE가 악화한다. 전체 평균 개선만으로 모든 지점에서 지연에 견고하다고 해석하지 않는다.

이는 주변 관측을 활용할 근거를 강화하지만 실제 발표 지연은 확인되지 않았다. AWS/ASOS의 기존 과거 입력 정책은 그대로이며 이 실험은 RWIS 지연만 변화시킨다. 다음 겨울 타깃 시점보다 앞선 다른 지점 관측을 얻을 수 있다는 운영 가정이 필요하다. 결빙 분류 개선이나 1km 미관측 구간의 일반화를 입증하지 않는다.

## 재현 및 확인

`python scripts/evaluate_neighbor_transfer.py --smoke`로 처음 두 지점을 확인하고, 옵션 없이 전체 실행한다. 결과는 `outputs/private/neighbor_transfer/`에 저장한다.

- `summary.json`: 같은 분모의 시나리오 요약, 입력 특징 SHA256, 한계.
- `station_metrics.csv`: 지점별 BIAS·MAE·RMSE·결빙점 부근 MAE.
- `fold_manifest.json`: 제외 지점, 실제 학습 지점, 학습·평가 기간, 참조 관측소.
- `predictions.parquet`: 예측 및 참조 관측·가용 시각을 포함한 추적 자료.

테스트는 동시각·미래 관측 차단, 지연 경계, 최대 나이, 지점·겨울 분리, 보호 지점 표기 변형 차단, 참조 시각 중복 차단을 확인한다. 학습형 주변 RWIS 모델을 추가할 경우 내부·외부 제외 지점을 모든 참조 특징에서도 배제해야 한다. 이번은 학습형 혼합이 아니라 고정 혼합이다.

최종 확인: 단위 테스트 22개 통과. `python scripts/check_notebook.py --run-stage neighbor_transfer`로 새 단계 재실행과 실제 Jupyter 커널 코드 셀 24개가 통과했다. 등록 단계 35개, 노트북 저장 출력 0개. 실행 환경의 요구 패키지 버전은 requirements.txt와 일치하며 상세는 `outputs/private/neighbor_transfer/environment.json`에 있다.
