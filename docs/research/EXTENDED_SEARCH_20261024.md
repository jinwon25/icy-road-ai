최종적으로 회귀 설정 71개·고정 평균 19개, 분류 모델 60개·기상 규칙 648개를 비교했습니다. 선택한 63개 입력 모델의 개발 MAE는 1.145698°C로 v2보다 13.66% 감소했고 결빙 판정은 v2를 유지합니다. 기존 v2와 실패·중간 기록은 보존했습니다. [최종 선택·개선 둔화·산출물 검산](../delivery/EXTENDED_UPGRADE_20261024.md)

## v3 이후 후속 연구 — 완료

사용자가 1등을 목표로 후속 검토를 요청해, 기존 탐색에서 충분히 비교하지 않은 긴 열 이력·결빙점 가중 학습·판정의 시간 상태를 추가 대조했습니다. 온도 11개 설정·조합과 새 결빙 상태 정책 14개 중 모든 기준을 통과한 방법은 없었습니다. v3 모델을 유지하고 구간 탐색·실제 조작 영상·검산 근거를 v4에 통합했습니다. 아래는 고정한 계획과 실행 범위이며 [최종 수치·미채택 이유·검증](../delivery/FOLLOWUP_UPGRADE_20261024.md)을 함께 확인합니다.

[고정 온도 계획](../../config/followup_temperature_20261024.json)은 24시간 평균 4개, 24·48시간 평균 8개, 기온 대비 잔차, 결빙점 가중 목적의 4가지를 같은 600회 모델과 비교합니다. 여섯 기준을 통과한 최대 두 후보와 별도 기준을 통과한 결빙점 후보만 1,200회로 연장하도록 학습 전에 정했습니다. 마지막 비교 기준은 현재 v3의 1,200회 모델입니다. 중간 개발 점수로 후보를 선택하는 것이며 새 독립 평가라고 주장하지 않습니다.

학습 가중치는 훈련 노면온도에만 `clip(exp(-(T/3)^2), 0.1, 1)`을 적용합니다. 미래 예측 선행시간 항은 없는 같은 시각 추정입니다. 가중 모델을 실행할 때 노면 정답을 요구하지 않습니다. 24·48시간 특징도 현재 시각을 제외한 과거 기상만 사용하고, 기대 슬롯의 80% 미만이면 결측으로 둡니다. 미래 수정 불변성·다른 위치 분리·배치 맥락 일치·시각 단절과 결측을 검사했습니다.

[결빙 시간 상태 계획](../../config/icing_state_memory_20261024.json)은 기존 순간 판정의 연속 확인 1·2·3슬롯, 지속 0·30·90분, 해제 0·1°C를 고정한 새 정책 14개입니다. 결측·10분 격자 단절은 상태를 초기화합니다. F1뿐 아니라 Precision·Recall·두 겨울·모든 지점·기존 탐지 사건을 함께 검토하며 기존 채택 기준은 완화하지 않습니다.

기존 LightGBM 비교는 22개 열 입력 또는 42개 기상 이력 입력까지였으므로 [최종 63개 입력의 L1·L2 1,200회 대조](../../config/followup_algorithm_20261024.json)도 별도로 고정했습니다. 같은 지역 제외 기준으로 현재 v3 및 사전에 정한 1:1 평균과 비교합니다. 새 가중치·라이브러리 다운로드는 하지 않습니다.

평균 방향성 오차를 줄일 수 있는지 [지역 이중 제외 보정](../../config/followup_offset_20261024.json)도 고정했습니다. 외부 지역 G와 보정용 지역 H를 함께 제외한 6개 모델로 H의 오차를 얻고, G의 상수 보정은 다른 지역의 잔차만으로 정합니다. 전체 잔차 중앙값과 지점별 중앙값의 중앙값 두 정책을 ±0.5°C로 제한합니다. 최종 전체 학습 모델용 상수를 외부 지역 평가에 되돌려 쓰지 않습니다.

결빙 시간 상태 비교는 완료했습니다. 새 정책 14개 중 모든 기준을 통과한 방법은 없습니다. 최고 평균 F1 0.027119는 기존 대비 약 2.13% 높지만 기존 탐지 사건 4개를 잃고 1개를 새로 찾았으며 Recall·두 겨울 기준에 실패했습니다. 15개 정책의 전체 출력 4,661,655값과 일별 F1 45건을 서로 다른 구현으로 검산했습니다. 기존 결빙 판정을 유지합니다.

긴 이력 특징 8개의 전체 6,356,360값도 원시 행 누적합과 별도의 정규 격자 rolling으로 정확히 일치했습니다. 새 합성 검사 9개를 포함한 테스트 334개와 하위 검사 7개가 통과했습니다. 동결 코드의 pandas 향후 변경 경고 1건은 보존합니다.

추가로 500m·1km의 1,266개 구간, 두 겨울 2,532개 속성, 일별 16,560행을 담은 오프라인 구간 탐색 화면을 만들었습니다. 48개 구간 선택·144개 날짜·지도 클릭·지표 전환·CSV 다운로드를 실제 브라우저에서 검산했고, 모바일 지도 글씨 수정 후 데스크톱·모바일을 다시 확인했습니다. 이 화면은 새 성능평가나 검증된 위험등급이 아니라 현재 결과의 탐색·검토 도구입니다.

이번 확인에서 공식 문제의 10월 7일 자료 표시·11월 6일 참가신청 종료와 공지·일반 Q&A 목록은 재확인했습니다. 공지 564와 문제별 Q&A 588·633 상세는 웹 도구에서 열리지 않았습니다. 최신 참가서약·결과물 마감·데모 답변 본문 확인 상태는 승격하지 않습니다. 보호 정답·외부 사전학습 가중치·새 외부 관측 자료는 사용하지 않습니다.

## 탐색 당시의 비교 계획과 채택 원칙

첫 단계는 비보호 23곳·두 겨울에서 회귀 알고리즘 4계열, 깊이·학습 길이, 기온 대비 노면온도 차이, 강건 손실, 과거 기상 이력, 지역 집합 균등 가중치를 비교합니다. 같은 4개 공간 그룹을 두 겨울 모두 제외하고 조기 종료에 평가 정답을 사용하지 않습니다. [사전 설정](../../config/extended_search_20261024.json)

현재 모델 대비 통합 MAE 0.5% 이상 개선, 지점 균등 MAE 개선, 각 겨울 악화 2% 이내, 각 지점 악화 5% 이내, 실측 -2~2°C MAE 비악화, 네 지역 중 세 지역 이상 비악화를 요구합니다. 이는 개발상 선택 기준이며 공식 성능 기준이 아닙니다. 18종 결과를 본 뒤 기준을 유리하게 완화하지 않습니다.

별도 기상 규칙은 ASOS·AWS·평균 기온, 9개 온도 문턱, 8개 습도·이슬점·과거 강수 조건, 1·3·6슬롯 지속조건의 648개를 비교합니다. 외부 지역 G의 정답을 제외한 다른 지역에서 일별 지점 F1 또는 두 겨울 중 낮은 F1로 규칙을 선택합니다. 모든 비교에 같은 입력 가용 범위를 적용하고 결측을 음성으로 바꾸지 않습니다. [규칙 설정](../../config/extended_ice_rules_20261024.json)

두 번째 입력 축은 기존에 확보한 ASOS 지면온도·일사·운량·강수·적설 등을 두 겨울에 연결합니다. 보호 정답이나 주변 노면 관측 열은 읽지 않습니다. 기존 첫 겨울 열·수분 실패 결과를 두 겨울에서의 실패로 간주하지 않고, 거리 정보 포함 여부와 기상 이력 추가를 별도로 대조합니다.

## 참고 자료의 적용과 제외

- [LightGBM 4.6.0 공식 설정](https://lightgbm.readthedocs.io/en/v4.6.0/Parameters.html): 설치 버전과 맞춰 L1/L2 손실·나무 크기·정규화를 비교하며 CPU 결정론 설정과 열 방향 계산을 고정합니다.
- [CatBoost 공식 학습 설정](https://catboost.ai/docs/en/references/training-parameters/common): 대칭 나무 계열과 MAE·RMSE·Huber 손실을 비교합니다. 범주형 지점 ID나 목표 통계는 사용하지 않습니다.
- [XGBoost 3.0 계열 공식 설정](https://xgboost.readthedocs.io/en/release_3.0.0/parameter.html): 절대오차·Pseudo-Huber 목적을 비교합니다. 설치 버전은 3.0.1입니다.
- [Karsisto, EMS 2025](https://meetingorganizer.copernicus.org/EMS2025/EMS2025-188.html): 노면온도 오차를 직접 보정하는 접근을 참고했습니다. 원 연구는 물리 예보의 사후 보정이고 이번 기온 대비 잔차 학습과 동일한 재현 실험은 아닙니다.
- [Li et al., GMD 2026](https://gmd.copernicus.org/articles/19/9035/2026/): 과거 열 상태와 다중 시간척도 특징의 의미를 검토했습니다. 논문은 관측 지점의 과거 노면온도 및 지점별 재학습을 사용하므로 그 입력·점수를 미관측 위치 문제에 옮기지 않습니다. 이번에는 사용 가능한 기상 이력만 비교합니다.
- [FHWA 관측소 배치 지침](https://ops.fhwa.dot.gov/publications/ess05/ess0503.htm), [NWS 서리·결빙 설명](https://www.weather.gov/safety/winter-ice-frost): 기온과 표면온도의 차이 및 수분·그늘·미세환경을 구분하는 근거입니다. 자체 문턱값의 공식 보증으로 해석하지 않습니다.
- [RoadSurf 1.1](https://gmd.copernicus.org/articles/17/4837/2024/): 열 상태와 수분 저장량의 분리를 참고했습니다. 기상 강수 이력을 도로 위 물·염분의 실측량으로 표시하지 않습니다.

공식 [문제 페이지](https://aida.kisti.re.kr/competition/main/problem/PROB_000000000004604/detail.do)와 [공지 목록](https://aida.kisti.re.kr/competition/main/notice.do), [Q&A 목록](https://aida.kisti.re.kr/competition/main/qna.do)을 다시 확인했습니다. 문제 페이지는 참가신청 9월 15일~11월 6일, 공지 목록은 9월 30일 개발결과물 안내와 10월 12일 FAQ를 표시합니다. 상세 답변과 첨부는 별도로 실제 접근 결과를 기록합니다.

## 포화 판단의 범위

추가로 [최신 공개 자료와 이용조건 검토](OPEN_SOURCE_REVIEW_20261024.md)를 진행했습니다. 공식 대회 소개의 시상식은 11월 25일로 표시되므로 사용자 답변의 11월 말 무렵을 결과물 마감으로 확정하지 않습니다. 실제 마감이 확인되기 전에도 기존 검증된 제출 후보를 보존합니다.

초기 열 입력 MAE600 후보에서 개발 MAE 1.2028156440°C를 얻어 v2의 1.3268902852°C보다 약 9.35% 개선했습니다. 아직 최종 채택·포화 판단이 아닙니다. 이 결과를 바탕으로 별도 소스·설정을 고정한 12개 국소 대조를 추가했고, 첫 26개 탐색의 설정·코드는 수정하지 않았습니다. 국소 대조는 v2 채택 기준과 함께 초기 열 입력 후보 대비 추가 개선을 따로 보고합니다.

원천 기상 재구성 19,069,080값의 첫 검산에서 둘째 겨울 원 대회 학습용 113행·540값의 AWS 결측 처리 차이를 발견했습니다. 열·수분 추가 열과 외부 9곳의 입력은 일치했습니다. 원 자료와 실패 감사는 보존하고 `canonical_thermal_data_20261024_v1`에서 기상 원천 선택을 통일했습니다. 재검산은 절대 허용오차 1e-10에서 불일치 0개이며 보호 정답·노면 정답 열을 읽지 않았습니다. 정정 학습본의 기준 2종·열 입력 2종을 재학습하고, 600회 모델을 같은 학습행에서 1200·2400회로 연장하는 고정 대조도 준비했습니다. 작은 합성 대조에서 연장 학습과 처음부터 동일 길이로 학습한 결과의 일치를 확인했습니다.

표 형식 신경망의 보완 가능성은 외부 가중치 없이 자체 학습하는 일반 MLP 3종으로도 비교합니다. CPU 2스레드·고정 40회 학습·학습 부분에서만 표준화하며 외부 평가로 조기 종료하지 않습니다. TabM 또는 RealMLP의 구현·점수를 재현했다고 하지 않습니다. [신경망 설정](../../config/local_mlp_20261024.json)

중간 비교는 `extended_comparison_20261024_v1`에 기록했습니다. 열 입력 MAE1200의 MAE는 1.190202°C이나, 기존에 탐지한 사건 178개 중 4개를 놓치고 7개를 새로 탐지했습니다. 일별 지점 F1도 0.026554에서 0.025812로 낮아졌습니다. 온도 개선을 결빙 개선으로 표현하지 않습니다. 고정 지점에서 겨울별 7일 날짜 블록을 쌍으로 재표집한 민감도는 공간 일반화·후보 선택의 불확실성을 포함하지 않습니다. 기존 판정과 새 온도 판정의 고정 결합도 F1·Precision·Recall·겨울별·지점별 비악화와 기존 사건 보존 기준으로 별도 비교하며 공식 점수나 독립 평가로 주장하지 않습니다.

서로 다른 알고리즘·입력 표현·학습 목적과 유망 후보 주변의 추가 대조에서 개선이 반복되는지 봅니다. 재학습 시드와 날짜 블록 불확실성, 기존 사건의 손실 및 지역별 분모도 확인합니다. 이 절차로 판단할 수 있는 것은 현재 입력·검증 집합에서 탐색한 방법의 실용적 포화입니다. 새로운 관측·제설 정보·정답 품질 개선까지 포함한 모든 개선 가능성이 없음을 증명할 수는 없습니다. 새 독립 평가와 반복 개발 결과도 구분합니다.

## 입력 일치 검증 이후의 후속 대조

열 입력 8개 대조가 완료되었습니다. 원 입력의 열·과거 기상 MAE600은 1.177295°C로 현재 가장 낮지만 정정 입력의 최종 수치와 구분합니다. [정정 입력 4개 이력 모델](../../config/canonical_history_search_20261024.json)은 MAE·MSE, 600·1200회, 잎 31·63개를 사전 고정해 비교합니다. 별도 [지형·태양 대조 4개](../../config/terrain_thermal_search_20261024.json)는 같은 23개 개발 지점의 공개 DSM 및 태양 위치만 추가하며 보호 정답을 사용하지 않습니다.

정정 학습본의 22개 열 입력 모델은 MAE600에서 1.207644°C, MSE600에서 1.218035°C입니다. 저장 모델 16개를 다시 실행하고 출력·학습 지점 제외·회귀 합계를 검산했습니다. 일반 MLP의 MSE 후보는 지점·지역 기준을 통과하지 못했고, MAE 후보는 1.270567°C로 통과했으나 현재 기상 이력 모델보다 오차가 큽니다. 알고리즘 명성이나 논문의 점수만으로 채택하지 않습니다.

정정 학습본의 52개 입력 MAE600은 1.177451°C, 겨울별 1.116582·1.238470°C, 결빙점 부근 1.036453°C로 기존 6개 기준을 통과했습니다. 이력 없는 22개 입력에 태양 위치만 더하면 1.194603°C였지만, DSM까지 더한 1.289027°C 후보는 일부 지점 기준에 실패했습니다. 공개 자료라고 해서 무조건 추가하지 않습니다. 지면온도·운량·일사의 선행 평균 9개를 기상 이력에 합친 [61개 입력 대조](../../config/combined_thermal_history_20261024.json)도 별도 고정 계획으로 실행합니다.

노면 정답 열을 받지 않는 실행용 전처리에서 허용 개발 자료의 22개 입력 17,479,990값과 52개 입력 41,316,340값이 연구용 전처리와 정확히 일치했습니다. 새 실행 계약은 온도 추정값과 결빙 판정에 사용한 기준 온도·모델을 별도 열로 표시하도록 구현했습니다. 새로운 온도 모델을 채택해도 결빙 성능이 검증되지 않으면 기존 판정을 보존할 수 있으며, 한 온도값에서 모든 결과가 직접 도출되는 것처럼 표시하지 않습니다. 입력 이력 부족도 별도 상태로 표시합니다.

648개 규칙의 17,496개 지점·기간 점수, 1,944개 TP/FP/FN 합계, 지역별 선택 8건을 다른 pandas 구현으로 검산했습니다. 절대 오차 1e-12 내 일치하며 `extended_ice_rules_audit_20261024_v1`에 보존합니다. 제출용 추가 기상은 `extended_delivery_inputs_20261024_v2`에서 138그룹·2,384,640행을 준비했고 v2 핵심 입력 33,384,960값의 일치를 확인했습니다. 첫 준비에서 관측소 매핑 자료구조 비교 오류로 중단한 기록은 v1 실패 영수증으로 남겼으며 기존 제출물은 바뀌지 않았습니다. 입력 가용성 표는 `extended_input_coverage_20261024_v1`입니다.

61개 결합 이력 MAE600은 1.166611°C, 태양 위치를 더한 54개 입력 MAE600은 1.163871°C로 개선이 이어졌습니다. 각각 저장 모델 4개와 개발 예측 310,777행을 재실행해 일치를 확인했습니다. 61개 연구·실행 입력 48,467,245값도 별도 구현에서 정확히 일치했습니다. 정정 52개 입력의 세 시드 MAE는 1.177451·1.177330·1.180672°C이며 세 시드 모두 기존 기준을 통과했습니다. 이 시드 결과를 아직 실행하지 않은 다른 구조의 시드 결과로 표현하지 않습니다.

태양 위치의 지점 좌표와 연결 ASOS 좌표를 구분하는 [3개 후속 대조](../../config/solar_memory_search_20261024.json), 결합 이력의 고정 1200·2400회 연장 비교도 진행합니다. 이력 없이 학습 길이만 늘린 22개 입력 MAE는 600회 1.207644, 1200회 1.194274, 2400회 1.186121°C였습니다. 가장 큰 모델이 가장 좋은 입력을 대신하지는 않았습니다.

새 열 입력을 결빙 직접 분류에도 적용하는 [4개 분류 후보](../../config/thermal_classification_20261024.json)는 별도 가설입니다. 22개 및 63개 입력, 무가중 및 양성 가중치 20을 사전 고정하고 4개 단일 지역 제외·6개 두 지역 동시 제외 문맥에서 총 40개 모델을 적합합니다. 임계값과 후보 선택에는 평가 지역을 학습에서도 배제한 다른 지역 예측만 씁니다. 기존 v2와 같은 입력 가용 범위로 비교하고, 온도 정답으로 적합한 같은 행의 예측값을 분류 특징에 넣지 않습니다. 온도·수분 임계 규칙 실험과 이 직접 분류 실험을 구분합니다.
