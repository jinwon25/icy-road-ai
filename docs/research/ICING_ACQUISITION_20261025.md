## 1. 제설 파일: 2025년까지 제공 목록 확인

[공공데이터포털 일자별 제설 목록](https://www.data.go.kr/data/15045677/fileData.do)은 제목에 `_20241231`을 표시하지만, 연결된 [한국도로공사 제공 화면](https://data.ex.co.kr/portal/fdwn/view?type=ETC&num=T5&requestfrom=dataset)의 공개 조회는 2025년 파일도 반환했습니다. 목록 제목을 실제 최신 기간의 상한으로 쓰지 않습니다.

| T5 연도 | 제공 파일 | ZIP 크기 | CSV 크기 | 생성일 |
| --- | --- | ---: | ---: | --- |
| 2024 | `ETC_일자별 제설작업 조회_1년_1년_2024.zip` | 17,387바이트 | 106,938바이트 | 2025-01-02 |
| 2025 | `ETC_일자별 제설작업 조회_1년_1년_2025.zip` | 17,849바이트 | 110,017바이트 | 2026-01-02 |

이는 **파일 목록의 메타데이터**이며 다운로드 후 내용까지 검증한 값이 아닙니다. 2026년 파일은 조회 목록에 없었습니다. 2024·2025년 파일만으로 둘째 겨울의 2026년 1–2월까지 덮는다고 말할 수 없습니다.

제공 화면이 사용하는 공개 연도·파일 목록 요청을 재현했습니다. 실제 파일 받기는 로그인과 이용자 정보 입력이 필요해 진행하지 않았습니다. 서버 내부 저장 경로를 직접 열거나 다운로드 권한 절차를 우회하지 않았습니다. 목록에는 무료·이용허락범위 제한 없음이 안내돼 있지만, **자료의 이용허락과 대회의 사용 허용은 별도**입니다. [T7 집계 목록](https://www.data.go.kr/data/15045675/fileData.do)도 같은 원칙으로 구별합니다.

원자료에서 우선 확인할 항목은 노선 식별자, 방향, 시·종점 거리표, 작업 시작·종료 시각과 시간대, 자재 종류·투입량·단위, 실적 등록 시각입니다. 일자별 강설·최저기온·총 사용량을 같은 날 이른 시각 예측에 넣으면 미래 정보가 섞일 수 있습니다. 작업 시각·당시 가용 시점이 없으면 원인 진단에만 쓰거나, 실제 공개 지연을 확인한 뒤 보수적 시차를 적용해야 합니다. 단순히 하루 뒤로 미루는 것만으로 가용성이 보장되지는 않습니다.

## 2. 센서 자료는 무엇을 요청해야 하는가

33408에 결빙 양성이 집중되거나 양의 노면온도와 함께 기록된다는 관측만으로 센서 오류를 확정하지 않습니다. 필요한 것은 해당 장비의 **설치·판정 체계와 기간별 품질 근거**입니다.

| 확보 대상 | 확인할 질문 | 성능 개선에 연결하는 방법 |
| --- | --- | --- |
| 설치·장비 메타데이터 | 지점·차로·방향·높이·관측 각도, 접촉/비접촉 방식, 제조사·모델, 설치·이전일 | 다른 센서 체계로 일반화되는지 분리 진단. 실제 대상 지점에서 알 수 있는 정보만 입력 후보로 사용 |
| 상태 코드 정의 | 원시 판정과 제공 `04`의 대응, 펌웨어·임계값 변경 시점, 집계 간격 | 정답 정의를 임의 수정하지 않고 공급기관의 공식 설명과 대조 |
| 품질·정비 이력 | 교정·청소·렌즈 오염·고장·교체·통신 이상 시각, QC 플래그 | 특정 기간 문제를 확인하되 사후 고장 판정을 실시간 설명 변수처럼 사용하지 않음 |
| 도로 관리 이력 | 제설·염수 살포, 노면 재포장·배수·차로 통제 시각 | 수분·빙점 차이의 설명 후보. 결빙 때문에 제설한 역인과와 구분 |

[ELP 노면센서 제품 설명](https://www.elovep.co.kr/sub/sub03_01.php?cat_no=12)에서 온도·습도·이슬점 및 Black ice/Ice 판정 항목을 확인했습니다. **우리 관측소에 이 장비가 설치됐다는 증거는 없습니다.** 제조사 일반 정확도를 33408의 보증 오차로 적용하지 않았습니다.

[천안논산고속도로 운영사](https://cneway.co.kr/main.do?s=cneway)는 천안·정안·공주·논산의 현재 도로 기상 화면을 제공합니다. 별도 지역 자료를 문의할 수 있는 단서지만 과거 원자료 다운로드·재사용 허가·대회 정답과의 코드 대응은 확인하지 못했습니다. 현재 웹 화면을 두 겨울의 독립 평가 자료로 사용하지 않았습니다.

기계판독 가능한 작업·정비 이력은 [공공데이터 제공신청](https://www.data.go.kr/tcs/dor/insertDataOfferReqstProcssView.do) 경로에서 제공 여부를 요청할 수 있습니다. 전자화 데이터 제공 요청과 보고서 열람 목적의 정보공개 청구는 포털에서 구별합니다. 공개 안내의 심의는 10일 이내, 부득이한 경우 추가 10일 범위이며 실제 확보 날짜를 보장하지 않습니다. 운영기관이 해당 기록을 보유하는지부터 확인해야 합니다.

## 3. 추가 검증 지역: 기존 기상 캐시 범위를 확대

기존 ‘적격 미사용 지점 0곳’은 **기존 전북 주변 기상 캐시와 당시 거리 기준**에 한정된 결과였습니다. 전국에 미사용 관측소가 없다는 뜻이 아닙니다.

[기상청 관측소 API 설명](https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=317)에 따라 당시 지점 목록을 요청했으나 4회 모두 403이었습니다. 대신 로그인 없이 제공되는 [기상자료개방포털 관측지점정보 CSV](https://data.kma.go.kr/tmeta/stn/selectStnList.do?pgmNo=123)를 받았습니다. 여러 관측망에서 같은 번호를 쓰는 문제를 피하려고 종관기상관측 분류 `SFC01`만 사용했고, 두 겨울 전체를 포함하는 단일 위치 이력을 요구했습니다.

[사전 위치 선별 설정](../../config/expanded_icing_validation_20261025.json)은 기존 대상 3개 노선·상태 관측 가능 유형·대회 밖 지점 중, 과거 요청한 모든 도로 지점을 제외합니다. 알려진 도로 지점과 5km 이상, ASOS와 30km 이내인 곳을 통과시키고, 기존 지점으로부터 먼 순서로 서로 50km 이상 떨어진 최대 4곳을 고릅니다. 거리 기준은 자체 가정이며 관측 품질·기상 대표성·정답 존재의 보장이 아닙니다.

미사용 30곳 중 거리 조건 통과는 **25곳**입니다. 정답이나 날씨를 보고 고르지 않은 최종 후보는 다음과 같습니다.

| 도로 후보 | 노선 | 연결 ASOS | ASOS 거리 | 가장 가까운 기존 도로 지점과 거리 |
| --- | --- | --- | ---: | ---: |
| 이천휴 33402 | 통영–대전중부 | 이천 203 | 10.14km | 64.79km |
| 진천터널외부 33406 | 통영–대전중부 | 청주 131 | 18.72km | 63.66km |
| 성암교 12213 | 서해안 | 목포 165 | 2.06km | 38.11km |
| 쌍암천교 23411 | 호남 | 순천 174 | 3.98km | 36.18km |

첫 선별 실행은 대상 노선 필터가 빠져 전국 후보를 포함했습니다. 정답 요청 전 검산에서 발견해 대상 노선 조건을 명시하고 새 `v2`에 다시 선별했습니다. `v1`은 보존하되 후속 수집에 사용하지 않았고, 대상 외 노선·기존 조회·대회·보호 지점을 제외하는 회귀 검사를 추가했습니다.

[공식 ASOS 기간 조회 API](https://apihub.kma.go.kr/apiList.do)를 31일 이하 10개 요청으로 사용해 131·165·174·203의 2024년 11월–2025년 2월, 2025년 11월–2026년 2월과 각 시작 전 1시간을 받았습니다. 총 23,048행은 예상 시간 격자와 전부 일치합니다. 원문 46필드의 **1,060,208값**도 저장본과 대조했습니다. 이 중 결측 코드가 있는 관측을 유효한 학습 입력으로 확정한 것은 아닙니다.

현재 단계는 **기상 입력 확보 완료, 도로 정답 미조회, 독립 성능 평가 미실시**입니다. 다음에는 필드·품질·엄격한 과거 연결을 검산하고, 비교할 후보·학습 범위·전체 예측·지표·중단 조건을 해시로 고정한 뒤 정답을 한 번 수집해야 합니다. 보호 12410·33411·23402는 계속 제외합니다. AWS가 필요한 현재 제출 모델의 전체 검증에는 AWS 권한 또는 적격 대체 입력도 필요합니다.

## 4. 발송하지 않은 요청 초안

아래 문구는 실제 문의를 준비할 때 사용할 초안입니다. 기관이나 운영진에게 발송하지 않았고 대회 원자료·정답·인증키를 외부로 전달하지 않았습니다.

**자료 제공기관용**

> 고속도로 미관측 구간의 결빙 추정 연구를 위해 2024년 11월–2025년 2월 및 2025년 11월–2026년 2월의 제설·염수 살포 이력과 노면 관측 장비 메타데이터 제공 가능 여부를 문의드립니다. 노선·방향·구간 시종점, 작업 시작·종료 시각, 자재 종류·사용량·단위, 실적 등록 시각이 있는 CSV와 필드 설명을 희망합니다. 장비 모델·설치/교체·교정/정비 시각 및 상태 코드 변경 이력의 제공 범위도 부탁드립니다. 미보유·비공개 항목은 구분해 주시고 연구·대회 사용, 결과 공개, 파생 통계·모델의 활용 조건을 안내해 주시면 감사하겠습니다.

**대회 운영진용**

> 공개 기상자료 허용 범위와 별도로 한국도로공사의 공개 제설 이력 및 외부 비대회 지점의 센서 설치·품질 메타데이터를 원인 분석 또는 모델 입력에 사용할 수 있는지 확인 부탁드립니다. 보호 대상 3곳의 추정 대상 실측값은 사용하지 않고, 예측 시각 이후의 작업 실적·사후 품질 판정도 입력에 넣지 않을 계획입니다. 사용 가능 범위와 출처·허가·AI 활용 기록에 필요한 증빙을 안내 부탁드립니다.

제설 행정자료와 외부 센서 정답은 공개 기상자료 허용 답변의 포괄 승인으로 확대하지 않았습니다. 문의 답변이 오기 전 도입이 불명확한 자료는 학습에 넣지 않습니다.
