## 상세 연구와 과거 기록

`research/`에는 연구별 입력·분할·비교·미채택 이유를, `competition/`에는 시점별 공식 원문 대조를 보관한다. `delivery/`의 날짜·버전이 붙은 문서는 당시 제출 후보의 재현 근거다. 현재 결과는 위 최종 보고서를 따른다. 과거 점수의 분모·입력 범위·평가 규칙을 현재 점수와 혼용하지 않는다.
