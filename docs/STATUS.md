## 현재 결과

참가팀은 **로드투인사이트**입니다. 최종 보고서의 수치는 공식 채점 결과가 아닌 로컬 관측 대조와 개발 검증 결과입니다.

학습 제외 3지점의 노면온도 MAE 평균은 0.978°C이며, 같은 관측쌍에서는 기본 12특성 회귀보다 MAE가 14.6% 낮았습니다. 결빙의 날짜별 평균 정밀도 0.0195·F1 0.0326은 낮은 수준이며 자동 경보 성능에 한계가 남습니다.

추가 계측 기준에 남은 대상은 3구간·2개 범위입니다. 공개 목록의 명목 중첩 64구간과 ±250m 위치 여유를 포함한 81구간을 함께 대조했으며 기존 지정을 모형으로 해제하지 않습니다. 현장 기록은 미측정 상태이고 계측·사고 감소 효과를 검증한 것은 아닙니다.

## 제출 당시 완료한 검증

- 평가 3지점을 학습에서 제외했고 필수 CSV의 10분 시각·관측·예측 열과 지표별 날짜·지점 분모를 확인했습니다.
- 로컬 제출 ZIP의 압축 해제본에서 전체 온도·결빙 예측 103,680행과 예제 144행을 정확히 재현했습니다.
- 목록 대조, 현장 확인 계획, 고정 온도 규칙 비교와 ASOS·AWS 단기 이력 연구의 지표 48행을 재계산했습니다.
- 분석 Notebook 12개 코드 셀을 실제 실행했고 14쪽 PDF의 렌더·책갈피·이동 링크와 데모의 키보드 조작·작은 화면 배치를 확인했습니다.
- 단기 이력 후보 두 가지를 40회 학습했으나 채택 조건을 충족하지 못해 모형과 필수 예측값을 유지했습니다. 평가 지점의 정답으로 문턱을 다시 고르지 않았습니다.

위 결과는 제공 원자료와 중간 산출물이 있던 제출 당시의 검산 기록입니다. 현재 공개본에서는 [합성 자료 테스트와 저장소 검사](../README.md#프로젝트-실행)를 실행할 수 있습니다.

## 공식 안내 확인 범위

11월 6일 마무리 단계에 공통 심사 기준·공지·질의응답 목록과 참가 서약을 다시 대조했습니다. 일부 상세 답변은 저녁에 재접속되지 않아 당일 15:35 KST에 확보한 공식 본문을 기준으로 검토했습니다. [기준과 답변별 적용](competition/OFFICIAL_RULES_AND_RUBRIC_20261106.md)

11월 21일에는 대회 개최·결과물 제출·발표 평가 공지를 다시 확인하고 공개 전 검토를 수행했습니다. 제공 자료의 제3자 열람·제공 제한과 대회 종료 후 폐기 조건을 계속 따릅니다.

11월 25일 저장소를 공개하고 프로젝트 폴더의 제공 데이터와 관측값이 포함된 학습·검증 자료를 폐기했습니다. 제출 보고서와 모델은 보존했고, 비공개 데이터가 없는 별도 체크아웃에서 테스트 502개와 하위 검사 7개가 통과했습니다. [공개·폐기 검토 기록](../.github/PUBLICATION.md)
