## 현재: 결빙 기준선 차이 분석·추가 ASOS 실험, 기존 v5 유지

기온 기준선이 찾은 결빙 중 현재 판정이 놓친 4,158행을 분해했습니다. 2,668행은 수분 조건, 1,490행은 노면온도 조건에서 제외됐고, 33408의 F1 하락이 6개 지점의 개선을 넘어 전체 평균을 낮췄습니다. [원인·일별 지표 분모·전체 실험](research/ICING_GAP_AND_SYNOPTIC_20261025.md)

제공 ASOS의 미사용 8관측, 24·72시간 수분 이력, 날짜별 학습 비중, 단조·상호작용 제한을 추가해 50개 모델과 고정 6규칙을 비교했습니다. 새 최고 규칙 F1은 0.027704로 현재 0.026554보다 약 4.33% 높지만, 기온 기준선 0.036601에 못 미칩니다. 둘째 겨울·정밀도가 악화하고 기존 탐지 사건 하나를 잃어 채택하지 않았습니다. 학습 모델도 기온 기준선을 넘지 못했습니다. 온도 v3·결빙 v2를 유지합니다.

전체 테스트 354개·하위 검사 7개가 통과했습니다. 학습 재개 시 행 번호가 달라지는 문제를 수정하고 50개 저장 모델의 전체 예측·20행 비교·선택이 최초 실행과 같은지 확인했습니다. 새 자료의 연결·모델 재추론·수분 상태·학습 가중치·지표·선택은 최신 연구의 검산 기록으로 추적합니다.

도로공사 일자별 제설 자료는 공식 목록과 제공 페이지에 접속했지만 실제 다운로드는 로그인과 이용자 정보 입력이 필요합니다. 기간·작업 시각·구간 연결·대회 적용 조건도 남아 있습니다. RSCD의 Hugging Face MIT 표시와 원 저자의 비상업용 조건 차이도 확인해 사용하지 않았습니다. [자료별 실제 사용·보류 이유](research/ADDITIONAL_ICING_SOURCES_20261025.md)

공식 응답 48개·빈 참가서약을 14:27 KST에 재확인했고 변경은 없었습니다. **결과물 제출 날짜·경로는 계속 별도 공지 예정**입니다. 이번 연구는 기존 v5 ZIP 밖의 별도 연구 결과이며, 이미 봉인한 제출 자산을 덮어쓰지 않았습니다. 현재 개발 자료만 반복 탐색하기보다 적격 독립 지역·센서와 시각별 제설 근거 확보가 다음 우선순위입니다.
