## 남은 작업

1. 공식 최종 CSV 열·행키·결측 표현·파일명과 제출 날짜를 확인하고 내보내기 형식을 맞춥니다. 11월 6일은 참가신청 종료일로 안내돼 있으며 결과물 제출 마감으로 간주하지 않습니다.
2. 최초 시각·기상 공백을 과거 관측으로 보완할 근거를 확보합니다. 개발 입력 부족 21행과 보호 예측 부족 18행을 구별하며 보호 정답으로 채우지 않습니다.
3. 33408의 Ice 집중·양의 노면온도 동시 기록을 센서 위치·제설·유지보수 이력과 대조합니다. 원인을 확정하지 않습니다.
4. 아직 사용하지 않은 적격 지점에서 현재 고정 후보를 평가합니다. 이미 개봉한 지점을 다시 독립 평가로 쓰지 않습니다.
5. 공식 이정·시설 범위·센서 이력과 최종 위험등급의 근거를 보완합니다.
