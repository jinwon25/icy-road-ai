# 분석 결과와 검증 범위

**2026년 11월 21일 기준: 1차 심사가 끝났고 발표 평가 대상에는 선정되지 않았다.** [발표 평가 공지](https://aida.kisti.re.kr/competition/main/selectNotice.do?bbsId=BBSMSTR_AAAAAAAAAAAA&nttId=822)를 확인했으며 이후 모형·결과는 수정하지 않는다. 공개 범위는 [공유 범위](../.github/PUBLICATION.md)를 따른다.

참가팀은 **로드투인사이트**다. [최종 보고서](delivery/FINAL_ANALYSIS_REPORT.md)의 수치는 공식 채점 결과가 아닌 로컬 관측 대조와 개발 검증 결과다.

학습 제외 3지점의 노면온도 MAE 평균은 0.978°C이며 같은 관측쌍에서는 기본 12특성 회귀보다 MAE가 14.6% 낮았다. 결빙의 날짜별 평균 정밀도 0.0195·F1 0.0326은 낮은 수준이며 자동 경보 성능에 한계가 남는다.

추가 계측 기준에 남은 대상은 3구간·2개 범위다. 공개 목록의 명목 중첩 64구간과 ±250m 위치 여유를 포함한 81구간을 함께 대조하며 기존 지정을 모형으로 해제하지 않는다. 현장 기록은 미측정 상태이고 계측·사고 감소 효과를 검증한 것은 아니다.

## 완료한 검증

- 평가 3지점을 학습에서 제외했고 필수 CSV의 10분 시각·관측·예측 열과 지표별 날짜·지점 분모를 확인했다.
- 로컬 제출 ZIP의 압축 해제본에서 전체 온도·결빙 예측 103,680행과 예제 144행을 정확히 재현했다.
- 목록 대조, 현장 확인 계획, 고정 온도 규칙 비교와 ASOS·AWS 단기 이력 연구의 지표 48행을 재계산했다.
- 분석 Notebook 12개 코드 셀을 실제 실행했고 14쪽 PDF의 렌더·책갈피·이동 링크와 데모의 키보드 조작·작은 화면 배치를 확인했다.
- 단기 이력 후보 두 가지를 40회 학습했으나 채택 조건을 충족하지 못해 모형과 필수 예측값을 유지했다. 보호 지점의 정답으로 문턱을 다시 고르지 않았다.

이 검증에는 Git에서 제외한 원자료·모형·출력이 필요하다. 저장소 복제본의 합성 검사와 전체 분석 재현을 같은 의미로 쓰지 않는다. 실행 기록은 로컬 `outputs/private/competition_submission/submission_receipt.json`에 있다.

## 공식 안내 확인 범위

11월 6일 마무리 단계에 공통 심사 기준·공지·Q&A 목록과 참가 서약을 다시 대조했다. 일부 상세 답변은 저녁에 재접속되지 않아 당일 15:35 KST에 확보한 공식 본문을 기준으로 검토했다. [기준과 답변별 적용](competition/OFFICIAL_RULES_AND_RUBRIC_20261106.md)을 따른다.

문서자료·모델자료 ZIP 두 개는 로컬 제출 경로에 준비했다. 이 작업에서 대회 사이트 업로드나 제출 버튼 클릭은 수행하지 않았으며 실제 접수 상태는 마이페이지 제출 이력에서 확인해야 한다. 제공 자료의 제3자 열람·제공 제한과 종료 후 폐기 조건을 유지한다.
