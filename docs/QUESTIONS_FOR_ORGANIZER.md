3. 필수 회귀 변수, 제출 CSV 열·행 키·결측 표기·파일명.
4. 주변 RWIS·기상 입력의 동시각 또는 과거 관측 허용 범위와 발표 지연.

### 운영진 확인 질문

2026-09-23 현재 [공식 문제 페이지](https://aida.kisti.re.kr/competition/main/problem/PROB_000000000004604/detail.do)와 로컬 데이터 패키지에서 다음 세부 답변을 확인하지 못했다. 메시지는 발송하지 않았다. 답변 전에도 데이터 감사·보호 지점 분리·후방 시각 결합 기반 작업은 계속할 수 있다. 해당 규칙에 따른 점수는 **잠정 평가**로만 표시한다.

| 우선 | 질문 | 답변이 좌우하는 결정 |
| --- | --- | --- |
| 높음 | ‘일별 F1·Precision·Recall’은 하루의 10분 시점 144개를 대상으로 계산하는가, 하루 한 개의 이진값으로 집계하는가? | 주지표 함수·임계값 |
| 높음 | 실제와 예측 모두 Ice가 없는 날짜에서 세 지표를 어떻게 처리하는가? | 날짜 평균의 분모와 점수 |
| 높음 | 노면상태 결측/미정의 시점과 144개보다 적은 날짜의 평가·제출 처리는 무엇인가? | 유효행·날짜 채택 |
| 높음 | 일별 점수의 최종 평균은 모든 날짜 통합, 지점별 평균 후 통합, 노선별 평균 후 통합 중 어느 방식인가? | 모델 선택 |
| 높음 | 관측값 추정의 필수 변수 전체와 각 변수 단위, 제출 CSV의 열·행 키·결측 표기·파일명은 무엇인가? | 회귀 타깃·최종 산출물 |
| 높음 | 같은 시각의 ASOS/AWS 및 주변 RWIS 관측값을 미관측 지점 추정 입력으로 사용할 수 있는가? 관측 발표 지연은 고려하는가? | 입력 가용성·시각 정렬 |
| 중간 | 코드 13(결빙시작)과 15(물·얼음 판별 불가)는 ‘04 이외 비결빙’ 평가에 그대로 포함되는가, 15만 제외하는가? | 분류 정답 분모 |
| 중간 | ASOS `시간`은 KST인가? `풍향(16방위)` 값의 0–360 표기는 도 단위인가? | 시간·풍향 전처리 |
| 중간 | 제공 목록에 언급된 곡률 shapefile이 실제 전체 ZIP에 없는데 별도 제공 예정인가? | 도로 곡률 특징 |
| 중간 | 교량·터널 CSV의 동일 시작/끝 좌표와 중복 행은 방향별 시설인가, 점 대표 좌표인가? | 정적 공간 특징 |
| 중간 | DEM의 수직 고도 단위와 명시적 좌표계, 2026-08 접도구역 자료의 기준 시점은 무엇인가? | 지형·역사 시점 적합성 |
| 중간 | 기존 결빙취약구간 지정 자료와 평가 기준표 원본 이미지 또는 항목별 배점표를 제공하는가? | 기존 평가와 비교·새 위험도 기준의 차이 설명 |
