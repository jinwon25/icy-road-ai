## 자주 나오는 용어

코드·원본 변수·모델 이름은 재현을 위해 원문을 유지합니다. 본문에서는 아래 뜻으로 읽으면 됩니다.

| 용어 | 쉬운 설명 |
| --- | --- |
| 노면온도 | 공기의 온도인 기온과 구별되는 도로 표면의 온도 |
| RWIS | 도로기상 관측자료. 노면온도·노면상태 등 도로 주변의 관측값 |
| ASOS / AWS | 각각 종관기상 / 방재기상 관측자료. 기온·강수·풍속 등을 제공하는 기상 관측망 |
| DEM | 수치표고모형. 지형의 높이를 격자로 표현한 자료 |
| 보호 지점 | 최종 평가를 위해 학습·모델 조정·주변 참조에서 제외한 3개 관측소 |
| LOSO | 관측소 한 곳을 학습에서 빼고 그 지점을 평가하는 방식. 개발 지점 14곳을 번갈아 제외 |
| 내부 / 외부 검증 | 내부 검증은 학습 지점 안에서 설정을 고르는 과정, 외부 검증은 제외한 지점에서 결과를 확인하는 과정 |
| fold(분할 회차) | 어떤 지점이 학습용이고 평가용인지 정한 한 번의 분할 |
| OOF 예측 | 해당 관측소를 학습에 쓰지 않은 모델의 예측. 학습 자료를 다시 예측한 결과와 구별 |
| 특징 / 타깃 | 모델에 넣는 입력 정보 / 모델이 맞히려는 정답 |
| MAE / RMSE | 온도 예측 오차 지표. MAE는 절대 오차 평균, RMSE는 큰 오차에 더 큰 영향을 주는 제곱 오차 기반 지표. 작을수록 좋음 |
| BIAS | 예측−관측의 평균. 양수면 온도를 높게, 음수면 낮게 예측하는 경향 |
| 지점 평균(macro) | 지점별 지표를 먼저 구하고 모든 지점을 같은 비중으로 평균. 전체 행을 한꺼번에 평균한 값과 다를 수 있음 |
| Ice / 양성 | 원본 노면상태 코드 `04`에 해당하는 결빙 클래스. 양성 예측은 모델이 결빙으로 판정한 경우이며 실제 결빙과 다를 수 있음 |
| TP / FP / FN | 맞힌 결빙 / 얼지 않았는데 결빙으로 경보한 경우(오경보) / 실제 결빙을 놓친 경우(미탐) |
| Precision / Recall / F1 | 정밀도: 경보 중 실제 결빙 비율 / 재현율: 실제 결빙 중 찾은 비율 / F1: 두 지표의 균형을 요약한 점수 |
| 임계값 | 모델 점수를 결빙·비결빙으로 나누는 기준. 모델 점수가 곧 검증된 결빙 확률은 아님 |
| Ridge / 로지스틱 / HGB | 각각 선형 온도 예측 모델 / 결빙 분류 기준 모델 / 여러 결정트리를 결합하는 비선형 모델. HGB는 회귀·분류 모두 사용 |
| QC / QA / 자료 감사 | 자료의 값·시간·단위·위치·파일 구성을 점검하는 품질 검토 |
| 고정 / 봉인 | 평가 전에 모델·입력·임계값·예측을 정하고 해시를 기록하는 절차. 이후 정답을 보고 바꾸지 않음 |
| 별도 코드 검산 / 독립 감사 | 기존 산출물을 별도 코드로 재계산해 일치 여부를 확인하는 절차. 새로운 지점·기간의 독립 성능 평가와 구별 |
| 사건 / 단일 시점 사건 | 연속된 10분 결빙을 묶은 사례 / 한 시점만 결빙인 사례. 여러 시점의 적중을 여러 사건으로 세지 않음 |
| SHA256 | 파일 내용의 식별값. 원본이나 설정이 바뀌었는지 확인하는 데 사용 |
| EPSG:5179 | 이 프로젝트의 도로·시설 자료에서 사용하는 좌표계 식별자 |
