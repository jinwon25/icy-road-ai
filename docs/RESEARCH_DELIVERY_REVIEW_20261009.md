## 로컬 인계물

작업 루트의 `outputs/private/research_delivery_20261009_v2/`은 참가자 본인의 비공개 검토·연구 재현용 폴더다. 기존 약 4.97GB 제출 초안과 서명된 수정본을 덮어쓰지 않는 별도 결과물이다.

| `training/`, `models/` | 첫 겨울 23지점 기상 회귀 학습 표·새 HGB·기존 분류/Ridge 기준 모델 |

인계물은 원본 제공 데이터에서 파생된 학습 표·정답·모델을 포함해 **Git에 올리지 않는다**. `secret.env`·인증키·원본 ZIP·보호 정답·기존 다음 겨울 9지점 정답·인증된 API 요청 원문은 넣지 않는다. 참가 서약의 승인 없는 제3자 제공 금지·대회 종료 후 폐기와 각 원천의 이용 조건을 따른다. [공유 범위](../.github/PUBLICATION.md)

패키지 단독 실행은 첫 겨울 회귀 재적합, 저장 기준 모델 추론, 고정 8지점 예측과 분류·온도 지표 재현까지다. 전 구간 GIS 재구축과 API 원천 수집 감사에는 원본 작업 공간의 캐시·서명된 자료가 필요하다. Git clone만으로 데이터 없는 합성 테스트·저장소·Markdown 검증을 수행할 수 있으며 전체 성능을 재현한다는 뜻은 아니다.

```powershell
python -X utf8 scripts/reproduce_research_delivery.py --delivery outputs/private/research_delivery_20261009_v2
```

이미 `reproduction_receipt.json`이 있으면 재현 완료 기록을 보존한다. `--verify-only`로 패키지 해시만 다시 확인한다. 재현은 이미 열린 정답의 검산이며 새 블라인드 평가가 아니다.

전체 합성 테스트146개,추적파일281개,Markdown38개 로컬GFM렌더·링크·앵커 검사를 통과했다. 패키지 내부코드로 첫겨울 회귀를 재적합하고 고정138,240행 추론·지표를 재현했다. 초안v1의재현기록을 보존하고,원천입력서명·수집메타데이터·실제요청간격기록까지 추가한최종v2를 별도로 만들었다. 계산감사통과는 수집간격편차나 모델성능실패가 사라졌다는 뜻이 아니다.

## 다음 연구의 구체적 우선순위

1. **관측 대표성 확인:** 실제 온도·상태 센서 모델, 관측 영역·설치 위치, 시각 처리, 제빙·점검 이력을 확보한다. 따뜻한 온도에서 Ice가 관측된 원인을 단정하지 않으며 기존 정답을 임의 수정하지 않는다.
2. **지점별 온도 편향을 줄이는 개발 가안:** 첫 겨울 23지점만으로 기온 대비 노면온도 편차 회귀와 확인된 도로환경 상호작용을 공간 그룹 제외 구조에서 비교한다. 새 8지점의 사후 평균 오차로 지점 보정치를 만들지 않는다.
3. **분류와 물리 노출 분리:** 공식 04 탐지기는 지점별 Precision/Recall·실제 결빙일·단일 사건을 함께 목표로 하고, 열·수분 노출은 환경 조사 우선순위의 설명 변수로 유지한다. 손으로 만든 위험등급을 Ice 정답으로 학습하지 않는다.
4. **새 독립 평가:** 후보·입력·매개변수·임계값·지점/기간·분모를 먼저 고정하고, 아직 요청하지 않은 별도 정답으로 FP·FN·지점 악화와 사건 손실을 함께 확인한다. 보호 3지점·개봉된 다음 겨울 9지점·이번 8지점은 새로운 블라인드 자료가 아니다.

이번 단계는 결과물 생성·검산·인계까지 마감한다. 낮은 결빙 성능과 추가 자료가 필요한 원인을 명시하고, 같은 정답에 무제한 반복 튜닝해 완성도를 과장하지 않는다.
