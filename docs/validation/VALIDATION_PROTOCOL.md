### 검증 규약 — 현재 구현

이 프로젝트의 주된 질문은 보류한 RWIS 지점의 같은 시각 도로 상태를 주변 기상 및 도로·지형 정보로 추정할 수 있는가이다. 별도 예보 시점이 정해지지 않았으므로 조기예보 성능으로 해석하지 않는다.

### 보호와 분할

공식 최종 평가용 RWIS ID 12410(부곡교), 33411(삼봉), 23402(해전)는 원시 ID가 `.0`로 끝나는 경우까지 정규화해 개발 자료에서 제외한다. 데이터 감사에는 파일 완전성·형식·시각·정적 메타데이터만 포함한다. 상태 분포, 지연값, 공간 보간 참조값, 특징 선택, 임계값 탐색에 사용하지 않는다.

나머지 14개 RWIS를 외부 검증에서 한 관측소씩 보류하는 LOSO 14회로 구성했다. `outputs/private/validation/splits.json`에 각 회차의 학습 지점·보류 지점·내부 3분할을 고정했다(결정적 시드 20260923). 내부 분할에는 각 회차에서 결빙 사례가 있는 학습 지점이 3–4곳씩 들어가도록 했다. 외부 보류 지점의 목표값이나 지연·집계 목표값은 입력 또는 보간 참조값으로 사용할 수 없다. 외부 보류 지점의 좌표·고도 같은 배포 가능 정적 속성은 사용할 수 있다.

외부 검증은 두 겨울 모두에서 공간 일반화를 본다. 첫 겨울 학습→둘째 겨울 검증은 별도의 시간 일반화 보조 실험으로 기록하며 공간 검증 점수와 섞지 않는다. 전처리·특징 선택·보정·분류 임계값은 각 외부 학습 지점 안의 내부 분할에서만 정한다. 노면온도 중간 추정값을 분류기에 쓰는 모델은 대상 지점을 제외한 OOF 추정값으로 학습하고 외부 보류 지점은 중간 추정기 학습에서도 제외한다.

### 타깃과 지표

노면상태 04만 Ice 양성이다. 코드표에 정의된 나머지 상태(13·15 포함)는 현재 잠정 음성이다. `0`, `-999`, `12.1`, `13.1` 및 빈 값은 정의되지 않은 정답으로 따로 둔다. `4.0` 등 정수 코드의 소수점 표기만 안전하게 정규화한다. 원본 정답을 임의 수정하지 않는다.

회귀 오차 부호는 **BIAS = 예측 − 관측의 평균**이다. MAE와 RMSE는 같은 유효 쌍에서 계산한다. 분류는 10분 예측행을 기본으로 한다. `src/validation.py`에는 다음 후보가 구현돼 있다.

1. KST 날짜 안의 유효 10분 시점을 집계해 날짜별 Precision·Recall·F1 계산.
2. KST 날짜를 실제·예측 각각 한 개의 ‘하루 중 한 번이라도 Ice’ 값으로 바꿔 계산.
3. 정의된 날짜 지표만 일평균 후 지점 평균, 모든 날짜를 같은 가중치로 평균, 또는 노선별 지점 평균 후 노선평균.

1일 기대 시점 144개, 유효 짝의 최소 비율 100%는 `config/evaluation.json`의 **잠정 평가** 설정이다. 관측과 예측이 모두 무결빙이면 F1·Precision·Recall은 정의되지 않아 `null`로 둔다. 정답 양성인데 양성 예측이 없으면 F1=0, Recall=0, Precision=`null`이다. 관측 누락 또는 예측 누락은 유효 짝에서 제외하고, 미달 날짜는 날짜 평균에서도 제외한다. 평균에는 정의된 날짜·지점 수를 반드시 함께 저장한다. 기간 전체를 합친 혼동행렬 지표는 보조지표로 분리한다. 공식 평가 정의가 확인되면 설정과 집계 함수를 고정한다.

`tests/test_validation.py`의 인공 사례는 결빙 없음, 양성 예측 없음, 누락, KST 자정 경계, 지점별 평균 가중치, 보호 지점의 변형 ID를 확인한다.

### 입력 시각과 누수 방지

ASOS는 1시간, RWIS·AWS는 대체로 10분이다. 모델 입력 결합에서는 각 예측 시점에 이미 관측 가능한 ASOS/AWS 시각만 후방 as-of 정렬하고 유효 시간차를 기록한다. 주변 RWIS를 쓸 경우 매 보류 지점을 참조 집합에서 제거한다. AWS의 285,823개 지점 없는 빈 레코드는 제외한다. 자정 중복 2,776쌍은 수치 정규화 후 모두 동등함을 확인했으며, 각 일별 파일에서는 파일명 날짜의 행만 유지해 경계 중복을 제거한다(`src/weather_inputs.py`). 누적 강수량 차분은 같은 KST 날짜와 같은 지점 안에서만 계산하며 자정 초기화와 누락을 구분한다. 사용 가능한 동일 시각 자료 범위는 운영진 확인 전 잠정 사항이다.

기상 융합 개발 기준은 각 RWIS 위치의 최근접 AWS·ASOS 관측을 목표보다 엄격히 이전(최대 60분)인 시각에서만 결합한다. 기상 결측 대체·표준화와 Ridge 적합은 각 외부 LOSO 회차의 13개 학습 지점에서만 수행한다. 10분 예측 시점의 실제 발표 지연과 ASOS 제공 CSV 시각대는 확인 전 잠정이다. 비교 점수는 두 방법의 같은 ASOS 유효 시점에서 계산한다. 도로 정적 특징은 보호 지점의 동적 정답과 무관한 지도·위치 자료에서만 얻고, 현재 개발 14곳의 해당 노선 중심선 거리는 최대 22.3m로 확인했다.

공식 3개 지점의 최종 평가는 모델·전처리·임계값·평가 정책을 확정한 뒤 한 번 수행한다. 현재 공식 지점 성능이나 모델 성능을 산출하지 않았다.

### 개발용 첫 직접 분류기의 실제 검증 설정

10분 결빙 분류 기준선은 보호 3개소를 제외한 14개 외부 관측소 LOSO에서 실행했다. 임계값은 각 외부 학습 관측소 13곳의 내부 3분할 OOF 점수로 선택하고 보류 지점 정답을 사용하지 않았다. 현재 임계값 목적은 **내부 전체 10분 통합 F1**이며 공식 일별 점수 목적과 다르다. 클래스 가중 로지스틱의 decision score는 보정 확률로 해석하지 않는다. 하루 144개 유효 짝 조건, 무양성 날짜 null, 날짜·지점 평균은 모두 잠정이다. 두 AWS 입력 변형에서 F1 정의 날짜가 1,794대 240으로 달라 일별 평균을 모델 선택에 그대로 쓰지 않는다. [실제 개발 결과](../research/ICE_BASELINE_REPORT.md)에 공통 실제 Ice 날짜 110개의 보조 비교와 지점별 결과를 기록했다.
