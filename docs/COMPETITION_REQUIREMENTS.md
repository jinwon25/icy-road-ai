### 대회 요구사항 대조 — 2026-09-23

근거는 사용자가 전달한 문제 설명·문제 개요 전문과 [AIDA 공식 문제 페이지](https://aida.kisti.re.kr/competition/main/problem/PROB_000000000004604/detail.do)다. 공개 페이지의 텍스트에는 문제명·제공 ZIP·참가 일정이 확인되지만, 세부 평가 본문과 기준표 이미지는 현재 공개 텍스트에서 확인되지 않았다. 아래의 상세 수치·제출 항목은 **사용자가 전달한 문제 본문**에 근거한다. `도로기상관측장비 개요.jpg`, `결빙취약구간 평가 기준표.jpg`, `image.png`는 작업 폴더에 없어 그림의 세부 배점을 읽지 못했다.

기존 결빙취약구간 종합 평가표는 50점 이상을 지정하고 A 68점 이상, B 64–67점, C 50–63점으로 분류한다는 설명이 전달됐다. 기후특성 분야는 6점이다. 이는 **기존 종합 평가의 등급 경계**이며 새 기상학적 결빙 위험도의 임계값이나 배점으로 그대로 사용하지 않는다. 기존 지정 구간 자료가 없으므로 현재는 일치·불일치 비교를 할 수 없다.

전달된 문제 개요는 위험도를 결빙 발생 시 구간별 도로환경·지형에 따른 위험 수준으로 정의한다. 프로젝트 결과에서는 시점별 결빙 판정, 겨울 기간의 기상학적 결빙 취약도, 결빙 시 위험 영향 수준을 분리해 표시한다. 사고·교통량 자료가 없으므로 사고 발생·피해 확률로 해석하지 않는다.

일별 지표의 10분 시점 집계 방법, 무양성일, 불완전한 날짜, 관측소 간 평균, 코드 13·15의 평가 처리, 같은 시각 주변 자료 허용, 필수 회귀 변수·제출 CSV 열은 [운영진 질문](QUESTIONS_FOR_ORGANIZER.md)에 남겨 두었다. 답변 전 점수는 **잠정 평가**로만 표시한다.
