# 결과물 검토 안내

이 자료는 관측 장비가 없는 도로 구간의 노면온도를 추정하고 결빙 조건을 검토하는 연구 결과물이다. **온도 오차 감소는 확인했지만 결빙 탐지는 기온 기준선보다 낮은 평균 성능을 보였다.** 아래 순서는 성과와 한계를 빠르게 확인하기 위한 것이다.

## 5분: 결론과 근거

1. [보고서 초록](ANALYSIS_REPORT.md)에서 연구 질문과 핵심 결과를 읽는다. 로컬 v7 묶음에는 같은 원고의 `reports/analysis_report_v7.pdf`가 있다.
2. 보고서 3절의 온도 비교와 4절의 결빙 기준선 비교를 함께 본다.
3. 5절에서 새 지역 평가의 고정 절차와 미채택 이유를 확인한다.
4. 6절의 지도 해석과 7절의 미해결 근거를 확인한다.

## 15분: 산출물과 실행

묶음의 `demo/review/index.html`을 브라우저에서 열어 노선·겨울·구간 규모를 바꾼다. 일별 온도와 조건 노출의 단위를 확인한 뒤 관심 구간 CSV를 내려받는다. 500m와 1km는 같은 도로의 두 표현이며 독립 표본 수가 아니다.

Python 3.11 환경에서 묶음 루트를 작업 위치로 사용한다.

```powershell
python -m pip install -r requirements-notebook.txt
python scripts/review_submission_bundle.py --smoke --output local_review/reviewer.json
```

검사는 파일 해시, 포함 기준 예측 144행과의 일치, 노트북 실행을 확인한다. 패키지 설치 이후에는 포함 자료로 실행하며 외부 예측 API나 키가 필요하지 않다. 전체 연구 탐색의 입력까지 모두 포함된 것은 아니다. 검사의 실제 로그는 `validation/v7_delivery.json`과 연결된 파일에서 확인한다.

## 검토할 질문과 답

| 질문 | 답과 확인 위치 |
| --- | --- |
| 온도 13.66% 개선의 비교 대상은 무엇인가? | 같은 개발 9곳·두 겨울·310,091 유효쌍의 기존 기상 모델이다. 단순 기온의 온도 오차나 공식 점수 대비 개선율이 아니다. 보고서 3절 |
| 결빙 기준선보다 낮은데 왜 현재 판정을 유지했는가? | 지역·겨울·재현율·사건 보존의 자체 비악화 조건 때문이다. 공식 F1 최대화를 입증한 선택은 아니다. 보고서 4절 |
| 새 4지역의 F1 상승을 성과로 채택하지 않은 이유는? | 주 후보가 기존 탐지 8사건을 놓쳤고, 2지역 악화·관측 부족·좌표 불일치도 있었다. 보고서 5절 |
| 평가 지역 정답이 학습에 섞이지 않았는가? | 지역 제외 모델과 내부 선택 분할을 사용했다. 다만 같은 개발 지역을 반복 선택에 활용한 편향은 남는다. 보고서 2절 |
| 지도에서 높게 보이는 값이 실제 결빙확률인가? | 저온·수분 조건의 추정 노출 비율이다. 실제 결빙률·사고확률·공식 위험등급이 아니다. 보고서 6절 |
| 두 온도 열이 다른 이유는 무엇인가? | 새 온도 추정 모델과 유지한 결빙용 온도 모델이 다르다. [CSV 규약](CSV_CONTRACT.md) |
| 18행의 NA를 왜 남겼는가? | 허용 입력이 부족한 보호 예측이다. 비결빙으로 채우거나 정답을 보고 보완하지 않았다. 보고서 8절 |
| 센서 오류·제설 영향이 원인으로 확인되었는가? | API 이상은 재현했지만 정비·제설 원자료가 없어 인과 원인은 미확인이다. 보고서 7절 |
| 외부 자료와 AI 지원은 어디에 기록했는가? | `licenses/`, 문헌 검토, [AI_USAGE](../../AI_USAGE.md)에 실제 사용·보류·검산을 구분했다. |

## 발표를 준비할 때의 설명 순서

| 순서 | 전달할 주장 | 제시할 근거 |
| --- | --- | --- |
| 문제 | 제한된 센서로 도로 전체를 직접 관측할 수 없음 | 대상·기간·입력·보호 지점 |
| 접근 | 과거 노면 정답 없이 기상 이력으로 공간 추정 | 입력 구성·지역 제외 설계 |
| 성과 | 같은 개발 범위의 온도 MAE 감소 | 온도 비교 그림·표 |
| 검증 | 결빙 평균은 기준선 미달, 새 후보도 미채택 | 기준선·미탐·사건 손실 |
| 활용 | 구간별 추정과 입력 품질을 함께 탐색 | 지도·실제 화면·CSV |
| 다음 근거 | 현장 적용에는 센서·제설 이력과 독립 지역 필요 | 미해결 항목·검증 계획 |

실험 개수나 검산 횟수를 성능의 대체 근거로 제시하지 않는다. 점수 개선만 보여주는 발표보다 어떤 조건에서 결과가 유효한지 설명하는 편이 검토에 유용하다. 참가자의 직접 검토·최종 판단은 실제 수행 후 기록해야 하며 AI의 실행 기록으로 대신 기재하지 않는다.
