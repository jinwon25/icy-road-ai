# 결과물 검토 안내

## 최신: 주변 관측망과 풍속 개선을 통합한 v12

먼저 [24쪽 보고서](ANALYSIS_REPORT_V12_20261101.md)의 초록과13·14장을 봅니다. 풍속은 기존 대비 지역MAE11.27%, 지역·겨울10.41% 추가 개선했고 사전 조건·대표 재학습·별도 실행을 통과했습니다. [입력·실행 계약](WIND_NETWORK_20261101.md), [현재 묶음 검토](REVIEW_BUNDLE_V12_20261101.md), [실패한 다른 목표까지 포함한 비교](../research/WEATHER_NETWORK_20261101.md)를 연결합니다. 노면온도·결빙 성과로 바꾸어 해석하지 않습니다. 기존843구간 풍속 지도는 이전 모형입니다.

추가 4-4~4-6절에서 물리·알고리즘의 반증, [F1 우선·기존 v2 프로필](COMPETITION_PROFILES_20261101.md), 실제 기상 탐색을 확인합니다. `notebooks/followup_review_v11.ipynb`는 포함된 지표·감사·GUI 해시·F1 우선 CLI를 실행합니다. 기온 기준선의 더 높은 평균을 신규 독립 모델 개선으로 해석하지 않습니다.

이 자료는 관측 장비가 없는 도로 구간의 기온·습도·풍속·노면온도를 추정하고 결빙 조건을 검토하는 연구 결과물이다. **도로 기상·온도 오차 감소는 확인했지만 결빙 탐지는 기온 기준선보다 낮은 평균 성능을 보였다.** 아래 순서는 성과와 한계를 빠르게 확인하기 위한 것이다.

## 5분: 결론과 근거

1. [보고서 초록](ANALYSIS_REPORT_V11_20261101.md)에서 연구 질문과 핵심 결과를 읽는다. 로컬 v11 묶음에는 같은 원고의 `reports/analysis_report_v11.pdf`가 있다.
2. 3–4절의 노면온도·기상 개선과 5절의 결빙 기준선 비교를 함께 본다.
3. 6절에서 새 지역 평가의 고정 절차와 미채택 이유를 확인한다.
4. 8–10절의 공식 목록·위치 오차·기상 지도와 11절의 미해결 근거를 확인한다.

## 15분: 산출물과 실행

묶음의 `demo/review/index.html`을 브라우저에서 열어 노선·겨울·구간 규모를 바꾼다. 일별 온도와 조건 노출의 단위를 확인한 뒤 관심 구간 CSV를 내려받는다. 500m와 1km는 같은 도로의 두 표현이며 독립 표본 수가 아니다.

Python 3.11 환경에서 묶음 루트를 작업 위치로 사용한다.

```powershell
python -m pip install -r requirements-notebook.txt
python scripts/review_submission_bundle.py --smoke --output local_review/reviewer.json
```

검사는 파일 해시, 포함 기준 예측 144행과의 일치, 노트북 실행을 확인한다. 패키지 설치 이후에는 포함 자료로 실행하며 외부 예측 API나 키가 필요하지 않다. 전체 연구 탐색의 입력까지 모두 포함된 것은 아니다. 검사의 실제 로그는 `validation/v11_delivery.json`과 연결된 파일에서 확인한다.

## 발표를 준비할 때의 설명 순서

| 순서 | 전달할 주장 | 제시할 근거 |
| --- | --- | --- |
| 문제 | 제한된 센서로 도로 전체를 직접 관측할 수 없음 | 대상·기간·입력·보호 지점 |
| 접근 | 과거 노면 정답 없이 기상 이력으로 공간 추정 | 입력 구성·지역 제외 설계 |
| 성과 | 같은 개발 범위의 도로 기상·노면온도 MAE 감소 | 기준선·단순 대조·지역별 반례 |
| 검증 | 결빙 평균은 기준선 미달, 새 후보도 미채택 | 기준선·미탐·사건 손실 |
| 활용 | 구간별 추정과 입력 품질을 함께 탐색 | 지도·실제 화면·CSV |
| 다음 근거 | 현장 적용에는 센서·제설 이력과 독립 지역 필요 | 미해결 항목·검증 계획 |

실험 개수나 검산 횟수를 성능의 대체 근거로 제시하지 않는다. 점수 개선만 보여주는 발표보다 어떤 조건에서 결과가 유효한지 설명하는 편이 검토에 유용하다. 참가자의 직접 검토·최종 판단은 실제 수행 후 기록해야 하며 AI의 실행 기록으로 대신 기재하지 않는다.
