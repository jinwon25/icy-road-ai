## 후속 코드 수정

`review_submission_bundle.py`는 manifest의 `current_notebook`을 우선 실행합니다. 해당 필드가 없는 기존 v7은 `submission_review_v7.ipynb`, v6는 기존 노트북을 선택합니다. 명시한 노트북이 manifest 밖이거나 경로를 벗어나면 중단합니다. 선택한 경로를 실행 영수증에도 남깁니다. 이전 v7 ZIP 내부 도구는 봉인 상태를 유지합니다.

`review_official_updates.py`는 연결 실패·빈 목록·이전 상세 누락·참가서약 미검증을 성공으로 종료하지 않습니다. 실패 원문·요약은 보존하고 종료코드 2를 반환합니다. 두 변경은 모델·입력·평가 지표를 바꾸지 않습니다.

## 제출용 로컬 파일

`outputs/private/submission_channels_20261031/` 아래 문서자료·모델자료를 각각 한 폴더로 압축했습니다. 생성·검증 명령은 다음과 같습니다.

```powershell
python scripts/package_submission_channels.py --output outputs/private/submission_channels_20261031
```

기존 경로가 있으면 중단하여 덮어쓰지 않습니다. `submission_receipt.json`에 두 ZIP의 해시·크기·구성원 검증과 실행 검사 경로를 기록합니다. 원본 v7 보존·모델 자산 해시 일치와 최신 노트북 실행을 통과한 뒤 ZIP을 만듭니다. 제출 완료 기록은 만들지 않습니다.

| 업로드 칸 | 생성 파일 | 크기·구성 |
| --- | --- | --- |
| 문서자료 | `icy_road_documents.zip` | 422,449바이트, 문서·PDF·지도·기준표 7파일과 manifest |
| 모델자료 | `icy_road_model.zip` | 440,961,883바이트, 실행 자료 1,580파일과 manifest |

각 ZIP 안에는 이름이 같은 최상위 폴더 하나만 있습니다. 모든 구성원의 크기·SHA-256을 대조했습니다. 실행 전 manifest는 1,575파일이고 실행 영수증·로그·예측·이전 manifest 보존 후 최종 1,580파일입니다. 같은 수치가 다른 대상 파일 수인 것으로 혼동하지 않습니다.

수정 후 전체 검사 **404개·하위 검사 7개**, 새 문서를 포함한 Markdown 90개 검사와 예제 예측 144행·현재 v7 노트북 5코드 셀이 통과했습니다. 기존 pandas 향후 동작 경고 1건이 남습니다. 보호 예측 103,680행·NA 18행·중복 없음·정답 열 없음, 구간 요약 2,532행, 조건 기준 4종과 보호 봉인 47+549파일을 별도 확인했습니다.

v7의 핵심 자산 503파일과 원본 ZIP 해시를 보존했습니다. 문서 ZIP SHA-256은 `a8b2bed042de50b3decfccfab64910ee30357a8a9256e0403ed53a5436b520f2`, 모델 ZIP은 `094e6a10b502e41298f3d662afc18bf311e4a749ea5907e68640d63b5dae08d2`입니다. ZIP 생성 후 이 절에 최종 검사 결과를 덧붙였으므로 묶음 내부 점검 문서는 생성 당시 설명이고 최종 해시는 ZIP 밖 영수증을 기준으로 합니다.
