# 입상 목표의 모델 개선과 제출 후보 갱신

2026년 10월 24일 추가 작업입니다. 앞선 CSV 정리 이후 실제 모델 비교 56건과 최종 모델 적합 2건을 수행했습니다. 두 겨울 온도 모델을 개발 기준에 따라 채택하고 모델·전체 예측·지도·CSV·보고서·데모·재현 노트북을 함께 갱신했습니다. 대회 제출·외부 공개는 수행하지 않았습니다.

## 확인한 개선과 상충관계

외부 개발 9곳을 4개 지역으로 묶고, 평가 지역의 모든 지점을 **두 겨울 모두 학습에서 제외**했습니다. 기상 12변수와 HGB MSE·MAE 고정 평균 구조는 유지하고 학습 기간만 대조했습니다. 같은 310,091개 유효 온도 쌍의 결과입니다.

| 개발 평가 범위 | 첫 겨울 학습 MAE | 두 겨울 학습 MAE | 해석 |
| --- | ---: | ---: | --- |
| 두 겨울 통합 | 1.412816°C | 1.326890°C | 6.08% 개선 |
| 2024/25 겨울 | 1.201259°C | 1.247911°C | 3.88% 악화 |
| 2025/26 겨울 | 1.624894°C | 1.406063°C | 13.47% 개선 |
| 실측 -2~2°C | 1.267616°C | 1.209004°C | 4.62% 개선, 76,041쌍 |

4개 지역 모두 온도 MAE가 개선했습니다. 결과 확인 전에 저장한 [채택 기준](../../config/temperature_adoption_20261024.json) 5개를 모두 통과했습니다. 통합·지점 균등 오차 개선, 각 겨울과 결빙점 부근 악화 5% 이내, 4지역 중 3개 이상 비악화 조건입니다. 첫 겨울 대조군은 행 순서도 통일해 재적합했으므로 예전 1.200531과 소폭 다릅니다. 통합 1.326890을 예전 첫 겨울 1.200531과 직접 비교하지 않습니다.

결빙 탐지 개선은 입증하지 못했습니다. 최종 고정 온도·수분 규칙의 통합 일별 지점 F1은 0.026397 → 0.026554로 거의 같고, Recall은 0.781885 → 0.739628로 하락했습니다. ASOS 기온 ≤0°C 기준선의 통합 F1은 0.036392입니다. 첫 겨울에는 기온 기준선이 우세하지만 둘째 겨울에는 고정 온도·수분 규칙의 F1 0.009466이 기온 기준선 0.001424보다 높습니다. 지점·날짜 분모가 다르므로 FP/FN과 지표별 포함 수를 함께 제공했습니다. 최종 후보의 입상 가능성이나 공식 점수 우위를 확정하지 않습니다.

## 분류 실험과 채택하지 않은 이유

첫 겨울에서는 기존 7종과 과거 6/24시간 기상 이력의 새 2종을 비교했습니다. 외부 지역 G와 선택용 지역 H를 모두 제외한 모델로 임계값 64개·평활화 0/30/120분을 선택했습니다. 미정의 지점이 평균에서 사라지는 이점을 막기 위해 선택 시 전체 지점 수를 고정했습니다. 새 중첩 선택 F1은 0.012078로 기존 0.030633·기온 기준 0.071122보다 낮았습니다. 실제 결빙 347사건 중 탐지도 35건으로 기존 152건·기온 기준 296건보다 적었습니다.

두 겨울 확장 후에도 직접 분류기의 통합 F1은 무가중 0.002245·양성 가중 0.002671·지역 내부 선택 0.003872로 낮아 채택하지 않았습니다. 비교 모델은 20 + 16 + 20 = 56건이며 최종 적합 2건은 별도입니다. 분류 선택 실패를 새 점수 우위로 표현하지 않습니다.

첫 겨울 33408의 Ice는 6,340슬롯이지만 둘째 겨울은 14슬롯입니다. 원인이 기상·제설·센서 중 무엇인지는 확정하지 않았고 정답을 삭제·수정하지 않았습니다. 지역·겨울별 분포를 보고서에 포함했습니다.

## 개발 범위 변경과 보호 경계

보존된 공식 문제 설명은 두 겨울을 분석 대상으로 하며 보호 12410·33411·23402를 학습에서 제외합니다. 같은 시각의 미관측 위치 추정에 맞춰 **비보호 23곳의 둘째 겨울만 새 개발 자료로 재분류**했습니다. 이는 기존 시간 보류평가를 새 후보의 독립평가로 재사용해도 된다는 뜻이 아닙니다. 반복 개발 점수이며 새 독립 성능평가는 없습니다.

둘째 겨울 원본은 먼저 지점·시각을 검사한 뒤 허용 지점의 정답 열만 읽었습니다. 보호 정답·보호 과거 상태·보호 주변 참조는 읽지 않았습니다. 이전 봉인 47개와 보류 기록 549개 파일의 해시를 유지했습니다. [검증 규약의 변경 기록](../validation/VALIDATION_PROTOCOL.md) · [두 겨울 설정](../../config/two_winter_development_20261024.json)

CSV의 `current`는 새 온도·수분 규칙입니다. `previous_first_winter`는 같은 실험에서 첫 겨울로 재적합한 대조군입니다. `exports/manifest.json`의 `development_scope=two_winter`를 확인합니다. 과거 first_winter 표와 같은 점수로 취급하지 않습니다. [CSV 열·결측·집계 규약](CSV_CONTRACT.md)

압축을 새 폴더에 푼 뒤 Python 3.11 환경에서 실행합니다.

```powershell
python -m pip install -r requirements-notebook.txt
python -X utf8 scripts/check_notebook.py notebooks/two_winter_submission_review.ipynb
python -X utf8 code/predict.py --input data/weather_example.csv --output validation/my_prediction.csv
python -X utf8 code/train.py --output validation/my_refit
```

추론·검산·최종 재학습은 포함 자료로 실행합니다. 전체 탐색 재실행에는 원 비공개 작업 공간의 데이터 경로가 필요합니다. 과거 노트북·실험·기준선 재현 스크립트는 역사 자료이며 새 후보 지표의 진입점은 위 노트북입니다.

## 검증 근거와 남은 조건

별도 감사가 첫 단계 저장 모델 310,514행, 두 겨울 모델 예측 1,864,662건을 다시 계산했습니다. 과거 이력은 다른 rolling 구현으로, 오차·분류 지표는 별도 계산으로 대조했습니다. 원문 요약 해시와 모든 채택 기준을 확인한 뒤 최종 적합을 수행했습니다. 현재 추론은 외부 통신 없이 실행하며 CSV 수치·일별/겨울 합계·보호 예측 그룹 복원이 일치합니다.

추가로 공간 제외 예측 621,554행을 실제 제출 runtime으로 다시 실행했습니다. 최초 물리 규칙 집계에서 입력 부족을 0으로 두던 부분을 바로잡아 654행을 null로 유지하고 유효 쌍에서 제외했습니다. 해당 행의 관측 양성은 0건이며 주요 F1·Recall 수치는 같지만 유효 날짜 분모는 정정했습니다. 정정 전 감사는 보존하고 `audit_runtime.json`을 현재 근거로 삼습니다. 재학습 코드로 최종 두 모델을 다시 적합한 파일은 제출 모델과 SHA-256까지 동일했습니다. 이는 재현 검사이며 새 성능평가가 아닙니다.

실행 결과는 `validation/two_winter_*.json`, 연구 결과는 `research/two_winter/`, 원 작업 공간의 `outputs/private/award_ice_20261024_v1/` 및 `two_winter_models_20261024_v1/`에 있습니다. 최종 테스트·재학습 재현·노트북·ZIP 검증은 패키지 검증 영수증에 기록합니다.

최종 검증에서 테스트 300개, 저장소 파일 544개 검사, Markdown 65개 렌더·링크 검사, 실제 Jupyter 커널의 노트북 코드 5셀을 통과했습니다. 보호 지점 CLI 내보내기 103,680행은 현재 원 예측과 수치까지 정확히 일치했습니다. 브라우저의 슬라이더 4시점, 모바일 가로 넘침, 콘솔 오류·외부 요청 없음과 실제 출력 영상 144프레임을 확인했습니다. 보고서 6쪽과 지도·데모 화면을 렌더링해 시각 점검했습니다.

결과물 접수 날짜·방식과 최신 데모 답변은 아직 확인하지 못했습니다. 11월 6일은 확인한 참가신청 종료일이며 결과물 마감으로 단정하지 않습니다. 보호 정답을 개봉하거나 기존 개발 지점을 독립 평가로 재명명하지 않습니다.

## 참고 자료의 실제 적용

- [AIDA 공식 문제](https://aida.kisti.re.kr/competition/main/problem/PROB_000000000004604/detail.do): 보존된 문제 설명의 두 겨울·보호 3곳 경계를 적용. 최신 상세 본문 재접근 실패는 별도 기록합니다.
- [Roberts et al., 2017](https://doi.org/10.1111/ecog.02881): 임의 행 분할 대신 공간 그룹을 제외하는 설계에 적용했습니다.
- [Cawley & Talbot, 2010](https://jmlr.org/papers/v11/cawley10a.html): 중첩 선택과 반복 개발의 잔여 편향을 구분했습니다.
- [scikit-learn 임계값 선택](https://scikit-learn.org/stable/modules/classification_threshold.html): 적합·임계값 선택·외부 평가를 분리했습니다. 실행 환경 1.6.1은 변경하지 않았습니다.
- [Lipton et al., 2014](https://arxiv.org/abs/1402.1892): F1의 집계·임계값 의존성을 검토했습니다. 일반 이론의 임계값을 일별 지점 평균에 직접 대입하지 않았습니다.
- [RoadSurf 1.1, 2024](https://gmd.copernicus.org/articles/17/4837/2024/): 열·수분 상태와 입력 품질을 구별했습니다. 없는 제설·염분·도로 물성을 임의로 채우지 않았습니다.
