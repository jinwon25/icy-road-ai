## 완료한 연구와 판단 기준

기존 v2의 두 겨울 공간 제외 개발 MAE는 1.326890°C입니다. 열·기상 이력 61개 입력의 MAE600은 1.166611°C, 연결 ASOS 좌표의 태양 위치까지 포함한 63개 입력의 MAE600은 1.155715°C였습니다. 지점 좌표 태양 방식의 1.154782°C와 차이가 작아, 비교 전에 고정한 0.5% 이내 조건을 충족합니다. ASOS 좌표 방식은 정확히 같은 기상을 공유하는 138개 그룹을 유지할 수 있습니다.

61개 입력은 1,200회에서 1.154486°C, 2,400회에서 1.153656°C로 개선이 약 0.07%에 그쳤습니다. 63개 입력은 600·1,200·2,400회의 고정 대조, 1,200회의 추가 두 시드와 고정 평균을 비교했습니다. 가장 좋은 개별 시드를 선택하지 않았습니다. 최저 MAE와 0.5% 이내인 더 작은 모델을 우선하며, 앙상블은 추가 개선이 0.5% 이상일 때 채택하는 규칙을 적용했습니다. [최종 선택 기준](../../config/extended_final_selection_20261024.json)

회귀는 HGB·LightGBM·CatBoost·XGBoost·자체 MLP, 잔차·가중치·손실·규제·입력 제거·이력·태양·지형을 포함해 71개 설정을 완료했습니다. 63개 입력의 추가 두 시드는 MAE 1.144428·1.148113°C로 기존 여섯 기준을 통과했습니다. 기존 52개 입력에서 MSE·MAE 고정 평균이 소폭 개선된 근거에 따라 [63개 입력의 동일 손실 조합](../../config/solar_loss_pair_20261024.json)도 비교했습니다. 정정 전 입력의 결과를 정정 후 결과처럼 표현하지 않습니다. ## 결빙의 별도 검증

열·기상 4개 설정 40모델과 지형 포함 2개 설정 20모델의 지역 이중 제외 분류 실험이 완료되었습니다. 평균 F1 및 최저 겨울 F1에 따른 임계값 선택을 비교했습니다. F1 향상·Precision·Recall·각 겨울·각 지점·기존 사건 보존을 모두 만족한 방법은 없습니다. 648개 기상 규칙과 10개 고정 조합 역시 채택 기준을 통과하지 못했습니다.

지형을 포함한 양성 가중 모델의 최저 겨울 기준 선택은 통합 F1 0.031370으로 v2의 0.026554보다 높지만, Precision·Recall·일부 지점·탐지 사건 보존에 실패했습니다. 같은 입력 가용 범위의 ASOS 기온 기준선은 0.036601이며 평균 F1·Recall에 강점이 있지만 Precision·둘째 겨울·일부 지점에 약점이 있습니다. v2가 모든 기준선보다 우수하다고 주장하지 않습니다.

지형 분류 저장 모델 20개, 내부 임계값 점수 516행, 선택 8건, 기간별 F1 21건은 별도 날짜별 계산으로 검산했습니다. 열 분류 40개·점수 1,028행·선택 8건·F1 33건도 검산을 통과했습니다. 감사 도구의 첫 실행은 TP/FP/FN 열 순서 차이로 멈췄으며, 데이터나 점수 대신 비교할 열 정렬만 정정했습니다. 원 실험·선택·예측은 변경하지 않았습니다.

## 현재 실행 계약

- `estimated_road_temp_c`: 새 온도 회귀의 추정값.
- `icing_reference_temperature_c`: 유지한 v2 결빙 판정에 실제 사용하는 온도.
- `predicted_ice`: 기존 저온·수분 조건 판정. 새 온도만으로 역산하지 않음.
- `temperature_component_spread_c`: 현재 구성 모델 간 범위. 단일 모델이면 0이며 오차가 0이라는 의미가 아님.
- `weather_history_available_features`: 유효 과거 기상 특징 개수. 부족한 이력을 미래 값으로 채우지 않음.

예제는 과거 12시간을 포함한 216행에서 이력을 구성한 뒤 하루 144행만 출력합니다. 전체 지점의 두 겨울 이력으로 실행한 같은 날짜와 정확히 일치했습니다. 학습 범위 내 실행 예제를 독립 평가라고 하지 않습니다. [CSV 열 규약](CSV_CONTRACT.md)

구간 공간 파일에는 현재 평균 추정 온도를 반영하고 Shapefile에 `t_mean_c`를 추가했습니다. 저온·수분 조건 지도와 현재 평균 온도 지도를 구분합니다. GeoPackage·Shapefile 8개 파일의 모든 내보낸 숫자 속성을 CSV와 검산했습니다. 네 지도에 도로명·북쪽·축척을 표시하고 같은 색상 범위를 적용했습니다.

## 결과물과 재현성 검산

허용 23곳·두 겨울 원시 794,545행 중 유효 온도 학습 쌍은 793,149행입니다. 포함 자료에서 `code/train.py`를 두 번 실행해 새 온도 모델과 기존 결빙용 두 모델의 파일 해시가 모두 일치했습니다. 최종 온도 모델 SHA-256은 `1dfef8f22c986e4581422910151aa8b350a4906058f8d2dba78e7392ac876840`입니다.

138개 기상 그룹 2,384,640행 전체 추론에서 기존 결빙 판정·기준 온도가 행별로 일치했습니다. 보호 3곳 103,680행 중 입력 부족 18행은 NA입니다. CSV 11종은 숫자·결측·식별자·그룹 연결·날짜 및 일별 합계를 전량 검산했습니다. 독립 검증 지점 수를 공유 그룹·겹치는 구간 수로 부풀리지 않습니다.

데스크톱 1280px·모바일 390px에서 실제 HTML 시각 슬라이더와 두 온도·판정 값을 대조했습니다. 외부 요청·브라우저 오류·가로 넘침은 없었고 작은 모바일 그래프 글씨를 수정 후 재검사했습니다. 12초 영상은 실제 CLI 출력 144프레임의 시각화이며 화면 녹화가 아닙니다. 지도 4개, 영상 시작·중간·끝, 보고서 8쪽을 직접 검수했습니다.

테스트 325개와 7개 하위 검사가 통과했습니다. 보존된 과거 폴더까지 수집한 최초 pytest 실행은 이름 충돌로 실패해 로그를 남겼고, `pytest.ini`의 수집 범위를 현재 `tests/`로 고정한 뒤 해당 범위 전체를 실행했습니다. 동결 코드의 pandas 향후 변경 경고 1건은 기록하며 코드를 바꾸지 않았습니다.

현재 후보의 검증 기록은 `validation/refit_comparison.json`, `validation/extended_inference.json`, `validation/extended_maps.json`, `validation/extended_browser.json`, `reports/current/render_receipt.json`, `validation/extended_delivery.json`입니다. 실제 Jupyter 커널의 5개 셀·CSV 내보내기·저장소·문서 검사는 마지막 기록에, 압축 구성 전체 해시 검사는 상위 폴더의 `submission_candidate_20261024_v3.receipt.json`에 남깁니다. 실행 노트북은 기본 실행에서 재학습하지 않습니다.
