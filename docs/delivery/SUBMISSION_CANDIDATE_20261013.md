# 제출 후보 패키지와 추가 판정 검증

모델·10분 예측·구간 지도·기준표·보고서·실행 데모를 하나의 비공개 후보로 통합했습니다. 새 열·수분 가설은 기존 사건 손실 등으로 채택하지 않았습니다. 실행용 대표 후보를 준비한 것과 새 지점 성능 입증·최종 모델 승격·공식 제출을 구별합니다.

## 이번 판단

저온 판정에 MSE/MAE 추정의 평균·최솟값·최댓값을 적용하고, 온도 경계 -0.5/0/0.5°C와 이슬점 여유 0/1°C를 조합한 18개 고정 가설을 비교했습니다. 현재 평균 후보를 중복 대조로 더해 총 19비교입니다. 모델을 새로 학습하지 않고 감사된 이중 공간 제외 예측을 사용했습니다.

다른 세 공간 그룹의 내부 예측에서 144 및 1슬롯 조건의 Precision·Recall·F1 비악화, FP·FN 비증가, 양성 지점 TP 유지, 기존 탐지 사건 손실 0을 모두 요구했습니다. 네 그룹 모두 적격 후보가 없어 기존 3종 평균 판정을 유지했습니다. 개발 외부 그룹의 최고값으로 내부 선택을 바꾸지 않았습니다.

| 판정 | 일별 F1 평균 | Precision 평균 | FP | FN | 기존 탐지 사건 손실 |
| --- | --- | --- | --- | --- | --- |
| 기존 온도 3종 평균 | 0.030231 | 0.055359 | 20,889 | 4,982 | 0 |
| 평균 -0.5°C·이슬점 여유 1°C | 0.031240 | 0.055881 | 18,628 | 5,052 | 3 |
| 최댓값 0°C·여유 1°C | 0.031117 | 0.054130 | 19,769 | 4,983 | 1 |
| 기상12·현재 2종 평균 | 0.030633 | 0.052803 | 20,255 | 4,952 | 0 |

144유효슬롯 조건의 반복 개발 지표입니다. 보호 3곳의 공식 점수가 아닙니다. 비교 범위는 첫 겨울 개발 9곳 155,257행이며 유효 상태는 155,118행입니다. F1이 가장 높았던 새 조합도 미탐 증가와 사건 3개 손실이 있어 채택하지 않았습니다. 기존 평균 후보의 Precision 하락도 계속 기록합니다.

`thermal_consensus_20261013_v1/`에 설정·내부 선택·판정·일별 90,720행·지점 756행·사건 정체성을 저장했습니다. 별도 검산에서 외부 규칙 2,949,883값, 내부 규칙 8,849,649값, 이중 제외 24맥락, 지표별 분모와 선택 판단이 일치했습니다. 각 판정의 기존 분류 fallback은 21행입니다.

## 실행용 대표 후보와 데이터 경계

비공개 `outputs/private/submission_candidate_20261013_v1/`에 거리 없는 기상12·MSE/MAE300의 고정 1:1 평균을 준비했습니다. 허용된 첫 겨울 23곳의 유효 노면온도 397,126행으로 실행용 2모델을 새 적합했습니다. 개발 검증 점수는 이전 공간 제외 예측의 결과이며 전체 적합 모델의 재대입 점수를 계산하지 않았습니다.

전체 적합 모델은 보호·이미 개봉한 평가·둘째 겨울 정답을 사용하지 않습니다. 둘째 겨울의 공공 기상은 추론에만 사용합니다. 보호 지점의 기존 정적 위치만 읽었고 과거 보호 예측·정답은 새 점수 계산에 열지 않았습니다. 새로운 독립 평가나 최종 승격이 아닙니다.

같은 AWS 후보 순서와 ASOS를 쓰면 거리 없는 입력이 같아 공통 예측으로 중복을 줄일 수 있습니다. 위치 색인은 좌표·규모·겨울·기상 그룹을 별도로 유지합니다. 구간마다 같은 정답을 복제해 평가한 것이 아닙니다.

이번 1km 결과는 구간 중점 추정입니다. 이전 1km의 500m 길이 가중 집계와 다르므로 두 결과의 차이를 모델 개선량으로 해석하지 않습니다. 지도는 추정 저온·수분 조건 노출이며 실제 Ice·사고확률·공식 A/B/C 위험등급을 뜻하지 않습니다. 교량·터널 코드 비율도 실제 시설 범위나 현재 상태의 검증이 아닙니다.

## 입력 계약과 재현 문제 수정

미래·중복·비정규 시각, 노면온도·상태 정답 열, 잘못된 습도·음수 강수, 무한대 입력을 거부합니다. 숫자 결측값을 NaN으로 정리하고 오래된 AWS 입력을 제거합니다. 유효 ASOS가 없거나 수분 3열이 모두 없으면 판정을 null로 둡니다. 기존 분류 fallback을 모두 포장한 것은 아니므로 개발 판정의 fallback 21행과 새 실행 후보의 예측 거부를 구별합니다.

처음 실제 CSV 실행에서 기본 C파서의 마지막 비트 차이가 트리 분기를 바꿔 하루 144행 중 온도 5행이 달라졌습니다. 실패한 코드·출력을 보존하고 `float_precision='round_trip'` 읽기를 별도 추가했습니다. 모델·공간 예측·기존 감사는 바꾸지 않았습니다. 수정된 실제 CLI의 하루 출력이 원래 Parquet 기반 결과와 일치했습니다. 무손실 CSV와 Parquet 결측 보존을 검사하는 새 테스트도 추가했습니다.

공통 기상 특징 33,384,960값을 별도 NumPy 시간 탐색으로 검산했습니다. 엄격한 이전 시각·60분 허용 규칙이 일치했고 추론 7,153,920값·보호 예측 103,680행도 일치했습니다. 대표 2모델을 다시 적합한 103,680값이 같았습니다. 이번 신규 적합은 실행용 2건, 검산 재적합은 2건입니다. 기존 47개·549개 고정 파일과 세 평가 봉인을 유지했습니다.

보호 CSV 103,680행과 한 구간 34,560행 내보내기를 실제 명령으로 실행했습니다. HTML의 네 시각 선택·모바일 가로 넘침·콘솔 오류·외부 요청을 헤드리스 브라우저로 검증했습니다. 접속 시도는 0건입니다. 설치가 필요한 환경 구성 단계와 접속 없는 추론 단계를 구별합니다.

## 남은 제출 조건

- 공식 최종 CSV 열·행키·파일명·결측 표기와 결과물 제출 날짜·방법은 추가 공지가 필요합니다. 연구 CSV를 공식 승인 양식으로 부르지 않습니다.
- 부분 날짜 최소 유효 관측량, 오경보만 있는 날의 Recall 정책, 전 기간 미정의 지점의 평균은 명시 답변이 없습니다.
- 새 지점에서 후보 개선의 재현, 센서·제설·염분 이력, 공식 이정·시설 대응, 검증된 최종 위험등급은 남아 있습니다.
- 원본 GIS·공공 기상 캐시의 전체 재구축은 원본 작업 공간을 필요로 합니다. 압축본의 대표 모델 재학습·포함 기상 입력 추론·개발 지표 검산은 포함 자료로 실행합니다.

원본 ZIP·신청서·서명·인증정보·Git 이력·보호 정답·이미 개봉한 평가 정답은 패키지에 포함하지 않습니다. 허용 개발 학습 표와 파생물은 참가 권한 내 비공개로 취급합니다. 대회 제출·공개·문의 발송은 수행하지 않았습니다.
