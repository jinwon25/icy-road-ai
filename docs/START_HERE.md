## 먼저 확인할 결과

노면온도 MAE는 학습 제외 3지점 평균 0.978°C입니다. 같은 103,131개 관측쌍에서는 기본 12특성 회귀보다 MAE가 14.6% 낮았습니다. MAE는 오차 절댓값의 평균이며 작을수록 관측 온도에 가깝습니다.

결빙 정밀도는 0.0195, 재현율은 0.5936, F1은 0.0326입니다. 실제 Ice가 관측된 부곡교에서 각 지표를 계산할 수 있는 날짜만 평균했습니다. 정밀도에는 44일, 재현율에는 19일, F1에는 47일이 포함됐습니다. 정밀도는 결빙으로 판정한 것 중 실제 Ice의 비율, 재현율은 실제 Ice 중 찾아낸 비율입니다. 전체 관측의 TP·FP·FN을 합쳐 한 번 계산한 비율과 다릅니다. 온도 추정의 개선과 낮은 결빙 탐지 성능을 함께 읽어야 합니다.

중복 기상 입력을 합친 기준 조합에는 3구간·2개 범위가 남았습니다. 결빙이 확인된 신규 구간 수가 아니라 추가 계측·시설 확인 후보 수입니다. 기존 공개 목록과 75개 선정 기준의 민감도를 함께 제시했습니다. 현장 기록은 미측정 상태입니다.
