# 처음 읽는 사람을 위한 안내

이 프로젝트는 **관측 장비가 없는 도로의 온도와 결빙 여부를 기상·도로환경 자료로 추정**합니다. 2026 DATA·AI 분석 경진대회의 전북 고속도로 문제를 다룹니다. 실험 점수와 공식 대회 성적을 구별합니다.

## 먼저 구별할 세 가지 결과

| 결과 | 무엇을 답하는가 | 읽을 때 주의할 점 |
| --- | --- | --- |
| 노면온도 추정 | 도로 표면이 몇 °C인가? | 온도 오차가 작아져도 결빙 판정이 자동으로 좋아지지는 않음 |
| 결빙 판정 | 10분마다 센서의 Ice 상태를 맞히는가? | 노면온도·물기뿐 아니라 관측 특성·제설 등 미확보 요인도 영향을 줄 수 있음 |
| 구간 탐색 지도 | 어느 구간이 어떤 기상 조건에 노출되는가? | 검증된 사고 확률이나 공식 위험등급이 아님 |

예를 들어 모델이 노면온도를 -1°C로 잘 추정해도 도로가 건조하다면 결빙이 아닐 수 있습니다. 반대로 관측 자료에는 노면온도가 0°C보다 높은 시점의 Ice 코드도 있습니다. 원인을 확인하지 않고 정답을 고치거나 지점을 제외하지 않습니다.

## 어떤 자료를 쓰는가

대상은 서해안·통영-대전중부·호남 고속도로의 두 겨울입니다. 기간은 2024년 11월–2025년 2월과 2025년 11월–2026년 2월이며, 결과의 시간 간격은 10분입니다. 도로 센서의 온도·상태를 학습 정답으로, 과거 기상과 지형·도로환경을 입력으로 사용합니다.

현재 개발은 허용된 23개 지점에서 수행합니다. 비교할 때는 그중 9개 지점을 네 지역으로 묶어 한 지역 전체를 학습에서 제외합니다. 임계값이나 방법을 고르는 내부 검증에서는 두 지역을 동시에 제외합니다. 가까운 지점이나 같은 지역의 정답을 알고 있는 모델로 평가하는 일을 막기 위한 절차입니다.

공식 보호 지점 12410·33411·23402의 정답은 추가 학습·선택·참조에 사용하지 않습니다. 과거에 완료해 봉인한 평가 기록은 보존하고, 새 후보를 그 정답에 맞추어 튜닝하지 않습니다. 이미 여러 차례 비교한 개발 지역의 결과는 **반복 개발 점수**이며 새 독립 평가가 아닙니다.

## 수치와 용어 읽기

| 용어 | 쉬운 설명 |
| --- | --- |
| RWIS | 도로의 노면온도·상태 등을 측정하는 도로 기상 관측 장비 |
| ASOS / AWS | 기상청의 종관 / 자동 기상 관측 체계. 도로 센서와 위치·관측 범위가 다름 |
| MAE | 실제 온도와 추정 온도 차이의 절댓값 평균. 작을수록 좋고 단위는 °C |
| Precision, 정밀도 | 결빙이라고 알린 것 중 실제 결빙의 비율. 낮으면 오경보가 많음 |
| Recall, 재현율 | 실제 결빙 중 찾아낸 비율. 낮으면 미탐이 많음 |
| F1 | 정밀도와 재현율을 함께 보는 값. 이 프로젝트는 날짜별 계산 후 지점별 평균을 사용 |
| TP / FP / FN | 맞힌 결빙 / 잘못 알린 결빙 / 놓친 결빙 |
| 임계값 | 모델 점수가 이 값 이상일 때 결빙으로 판단하는 경계 |
| OOF, 지역 제외 예측 | 평가할 지점을 학습하지 않은 모델로 만든 예측 |
| 사건 | 같은 지점에서 10분 간격으로 연속 관측된 결빙. 한 시점뿐인 사건도 포함 |
| HGB | 여러 작은 결정나무를 순서대로 학습하는 모델 계열 |
| SHA-256, 봉인 | 파일의 지문을 기록해 모델·입력·예측이 나중에 바뀌지 않았는지 확인하는 방법 |
| NA | 입력이나 정답이 부족해 값을 정하지 못함. 비결빙을 의미하지 않음 |

F1은 이 저장소에서 전체 10분 행을 한꺼번에 합친 값과 다릅니다. 날짜별로 계산하고 지점별로 평균하므로, 일부 지점의 긴 결빙 기간만 잘 맞혀도 전체 평균은 낮을 수 있습니다. 원래 탐지하던 사건을 새 모델이 놓치는지도 별도로 검사합니다.

### 일별 F1이 높아져도 탐지는 줄 수 있는 예

아래는 이해를 위한 가상 예이며 실제 실험 수치가 아닙니다. 두 날 모두 관측은 완전하다고 가정합니다.

| 날짜 | 실제 결빙 | 기준선 | 새 후보 |
| --- | --- | --- | --- |
| 첫날 | 2개 시점 | 모두 탐지·오경보 없음 → F1 1.000 | 1개만 탐지·오경보 없음 → F1 0.667 |
| 둘째 날 | 없음 | 오경보 있음 → F1 0 | 경보 없음 → F1 미정의 |
| 일별 평균 | 같은 정답 | 두 날짜 평균 0.500 | 정의되는 한 날짜 평균 0.667 |

새 후보는 오경보를 없앴지만 실제 결빙도 하나 놓쳤습니다. 정답과 경보가 모두 없는 날짜를 F1 평균에서 제외하면 위처럼 평균은 오를 수 있습니다. 따라서 **F1, 평가에 포함된 날짜 수, 놓친 결빙과 사건을 함께 확인**합니다. 실제 후속 실험의 분모 변화는 [새 4지역 보고서의 기존 지역 진단](research/BLIND_ICING_20261025.md#f1-상승은-어디에서-생겼는가)에 설명했습니다.

## 버전 이름과 폴더 읽기

온도 모델은 v3, 결빙 판정은 v2이며 최신 제출 검토 묶음은 [v7](delivery/REVIEW_BUNDLE_V7_20261026.md)입니다. 모델 번호와 묶음 번호는 다릅니다. v7은 모델·예측을 보존하고 보고서·문서의 구성과 검토 경로를 개선했습니다. 새 성능이나 대회 접수 완료를 뜻하지 않습니다.

`outputs/private/`는 이 컴퓨터의 비공개 산출물 경로입니다. GitHub에는 제공 데이터·모델·예측·ZIP을 올리지 않습니다. 원본 없는 합성 검사와 실제 자료를 사용하는 모델 재현을 구별합니다.

최근 성능 연구는 [기온 잔차·관측 지연·입력 정보량](research/RESIDUAL_AND_INFORMATION_20261025.md), 새 공간 검증은 [4지역 일회 평가](research/BLIND_ICING_20261025.md), 자료 품질은 [원문 진단](research/RWIS_CAUSE_AND_ADDITIVE_20261025.md)에 있습니다. 같은 개발 지역의 재탐색과 처음 보는 지역의 평가를 구별하고, 미채택 결과도 보존합니다.

날짜가 붙은 문서는 당시의 조건과 판단입니다. 과거의 ‘다음 작업’이나 수치를 현재 결과로 읽지 않습니다. 현재 보고서는 [분석 보고서 원고](delivery/ANALYSIS_REPORT.md), 상세 상태는 [진행 현황](STATUS.md)에서 확인합니다.
