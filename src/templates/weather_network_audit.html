주변 AWS 관측망 점검

도로 위치와 주변 기상 관측소가 어떻게 연결되는지 확인합니다. 두 겨울의 고정 예시 16시각에서 실제로 사용할 수 있었던 과거 관측, 결측, 관측소 간 차이를 보여 줍니다. 도로의 실제 기상·노면온도·결빙 정답은 화면에 포함하지 않았습니다.

좁은 화면에서는 표를 좌우로 밀어 모든 열을 볼 수 있습니다. 관측 시각은 목표 시각보다 엄격히 이전이며 15분 이내입니다. 변수별 결측을 제외하고 가중치를 다시 합계 100%로 맞춥니다. 거리 하한 1km·거리 제곱 역수를 사용합니다. 관측소 간 범위는 예측 오차·예측구간·결빙 확률이 아닙니다.

두 겨울 전체 입력의 연결 품질

겨울 시작 연도평균 유효 AWS 수평균 유효 개수평균 가중 거리 km평균 관측소 범위

선택 도로의 기존 입력 달력에서 집계했습니다. 유효 개수는 1/Σ정규화가중치²이며 단순 관측소 수와 다릅니다. 평균 범위·거리는 해당 통계가 정의된 시각만으로 계산합니다. 입력 가용성은 도로 추정 정확도를 보장하지 않습니다.

이 자료는 최대 4 AWS의 공간 정보를 추가한 개발 비교의 입력 점검용입니다. 전체 시계열 예측이나 현장 안전경보가 아닙니다. 입력 출처: 대회 제공 기상청 AWS, 기상 API의 허용 개발 도로 좌표. 도로 23곳은 모델의 학습·개발 범위이며 보호 3곳과 이미 평가한 별도 4곳은 제외했습니다.
